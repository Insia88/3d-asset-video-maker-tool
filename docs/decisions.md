# 현재 채택한 범위와 기록 규칙

## 2026-10-04 · 뷰티 ETF 프로젝트

| 항목 | 채택한 규칙 |
|---|---|
| 참고 목표 | 직접 관찰한 고유 장면·샷·정지 이미지 25,000개 |
| 선정 범위 | 3D만, 뷰티 우선 또는 미감이 좋고 귀여운 입체 조형 |
| 미감 | 큰 머리·짧은 몸, 둥근 소품, 따뜻한 작은 공간, 명확한 재질 역할 |
| 장면 단위 | 전체 이미지·모델 시트 한 장은 한 단위; 소품·패널 수로 분할하지 않음 |
| 중복 | 원본 ID·파일/픽셀 해시, 같은 기본 조형의 색상·복장·미세 구도 변형을 통합 |
| 출처 | 공식 채널·원작·큐레이션을 분리하고 실제 확인한 라이선스·모델 표시만 기록 |
| 3D 판정 | 실제 화면의 스타일 판정; 편집 가능한 메시·리깅 확인은 별도 |
| 생성 순서 | 수집 완료 후 Higgsfield MCP에서 기본 마스터 생성·Element 등록 |
| 비용 기록 | 모델·실제 작업 ID·사용량을 성공 응답에 따라 기록; 확인되지 않은 결제 우선순위를 보장하지 않음 |
| 금융 내용 | 실제 ETF 선택 뒤 운용사·공시 원문의 구성·비중·비용·기준일 확인 |
| 공개 저장 | 분석·출처·집계·프롬프트·도구, 로컬 근거는 원본 해시와 출처로 추적 |

초기 넓은 수집의 실사·2D·혼합 비교 자료는 최신 3D 목표 수에서 제외한다. 변경된 범위의 완료 수는 초기 넓은 집계와 직접 비교하지 않는다. 진행률은 각 스냅샷의 실제 감사 수로 확인한다.

### 원본 비교에 따른 대표 수정

숲 미니어처 `SCM5124011-I001`을 `SCV5124015-I001`의 실제 전체 이미지와 비교한 결과, 사각 바닥·굽은 시내·짧은 다리·오른쪽 오두막·침엽수의 기본 공간이 같아 기존 대표로 통합했다. 연결된 `SCM5124017-I001`도 같은 최종 대표로 바로 연결한다. 이전 선정 하나를 제외하며 원작 관찰과 수정 이유는 [부드러운 캐릭터·꽃·미니 공간 분석](research/2026-10-04/45_3D_부드러운캐릭터_꽃과미니공간_직접분석.md)에 보존한다.

큰 얼굴 조형 `SCM4987506-I001`은 기존 `SC0041-I001`과 비교해 민머리·큰 귀·둥근 코·돌출 색 곡선/별 장식의 기본형이 같아 대표로 통합했다. 과일시장·책상 방·지구 장면은 일반 주제의 유사성만으로 합치지 않고 주요 기하와 공간 관계를 직접 비교했다. 이 판단은 [입체 꽃·유리 외피·작은 무대 분석](research/2026-10-04/95_3D_입체꽃_유리외피_작은무대_직접분석.md)에 기록한다. 대표 수정 뒤 전역 감사와 색인을 다시 생성한다.

앞으로 범위·단위·미감·생성 순서를 바꾸면 결정 날짜와 새로운 규칙, 집계에 미치는 영향을 이 문서에 추가한다.
