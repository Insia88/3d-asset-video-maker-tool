## Higgsfield에서 이어가기

한 컷에는 한 가지 행동을 둔다. 모아가 크림통에 손을 뻗는 장면, 뚜껑이 열리는 장면, 블록이 바구니에 들어가는 장면을 나누어 만든다. 선택한 마스터 이미지를 이미지 입력으로 넣고, 장면의 시작과 끝에서 같은 실루엣이 유지되는지 확인한다. 여러 동작과 큰 카메라 회전을 한 번에 넣으면 소품의 수와 형태를 비교하기 어려워진다.

전신 기준 이미지는 캐릭터를 다시 만들 때 사용하고, 각도별 시트는 형태를 대조할 때 사용한다. 각도별 시트를 그대로 움직이면 네 캐릭터가 한꺼번에 움직이는 장면이 될 수 있으므로, 실제 컷에는 선택한 단일 인물 이미지를 넣는다. 화장대 장면에서는 모아와 향수병이 비슷한 높이로 보이는 현재 비율을 이어간다.

Higgsfield Elements에는 모아, 화장품, 바구니, 화장대 장면의 이미지 참조가 등록되어 있다. Element 참조를 지원하는 모델에서는 등록된 항목을 사용할 수 있다. 이번 이미지 생성에 사용한 GPT Image 2.5의 파생 이미지는 이미지 작업 ID를 직접 참조했다. 정확한 작업 ID와 Element ID는 함께 저장한 manifest에서 찾을 수 있다.

## 화면에 정보를 얹는 순서

기업명·비중·상품명은 생성 이미지에 넣지 않고 편집에서 얹는다. 실제 상품을 정한 뒤 운용사의 자료에서 구성종목, 편입 비중, 비용과 기준일을 확인한다. 바구니의 다섯 블록은 구조를 설명하는 비유이며, 실제 ETF의 종목 수나 비중을 뜻하지 않는다.

모아의 몸과 제품이 겹치지 않는 여백에 자막을 두고, 한 번에 두 줄 이내로 읽히게 한다. 창가 장면의 제목은 밝은 창을 피해 오른쪽 벽의 여백을 우선 사용한다. 제품이나 투자 수치를 설명할 때에는 화면을 안정적으로 유지한다.

## 원본과 생성 기록

다섯 PNG는 3D 스타일의 정지 이미지이며 편집 가능한 메시나 리깅 파일은 아니다. foundation_assets_manifest.json에는 실제 생성 프롬프트, 사용 모델, 파생 참조, 이미지 치수와 해시를 담았다. media의 개별 잠금 기록과 design의 색·재질 기준을 함께 사용하면 후속 장면을 같은 기준으로 대조할 수 있다. 이 제작 에셋은 외부 참고자료 조사 수에 포함하지 않는다.
