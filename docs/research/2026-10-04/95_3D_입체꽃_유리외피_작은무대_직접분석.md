# 입체 꽃·유리 외피·작은 CG 무대의 실제 관찰

공식 공개 3D 검색 고유 후보 202개 중 기존 원본 ID·해시 중복 30개를 뺀 새 이미지 172개를 29개 관찰판에서 모두 직접 관찰했다. 순수 3D 57개 선정, 그 외 115개 제외다. 실제 정지 이미지 한 장을 한 단위로 기록했다.

## 제작에 옮길 구조

- 꽃은 두꺼운 말림 꽃잎·앞뒤 겹침·굵은 줄기/받침을 먼저 고정한다. 자연형 꽃 사진을 CG라고 가정하지 않고 닫힌 기하/재질/빛의 실제 일관성을 확인한다.
- 투명 꽃과 유리 외피는 두께/겹침/굴절 면을 나눈다. 가는 표면 무늬에서 기술 기능을 추론하지 않으며 금융 설명 정보는 후반에 검증된 내용으로 따로 배치한다.
- 작은 제품/작업 공간은 잘린 벽/바닥·한 큰 가구·소수의 소품 좌표를 고정한다. 원작 전체 이미지 한 장을 한 단위로 유지한다.
- 큰 얼굴/짧은 몸의 동물과 둥근 물/잎 무대는 같은 재질/조명 체계를 유지한다. 자연 촬영형 숲/공예 배경에 작은 CG 주체만 섞인 화면은 전체 순수 3D 수량에서 제외한다.
- 같은 기본 컵/꽃/인물/가판의 색·표정·구도·소품 위치 변화는 대표에 합친다. 새로운 제품 기하나 큰 공간 관계가 확인된 전체 장면을 남긴다.

새 원본 전체를 직접 관찰하고 자연 식물/실내/인물의 촬영형 표면, 큰 평면 광선/기하 문양/정보 그래픽, 어두운 산업 미감을 제외했다. 검색의 3D 표기만으로 제작 방식이나 편집 가능한 모델을 인정하지 않는다. 선정한 3D는 실제 관찰한 시각 스타일이며 생성 모델·메시·리깅/제작 도구는 미확인이다. 정지 이미지에서 실제 움직임은 관찰하지 않았다.
