# Icons8 3D 식물과 미니어처 소품 관찰

3D Sugary 공개 원작 I8S0215–I8S0327 **113장**의 실제 미리보기 픽셀을 직접 관찰했다. 이 가운데 독립 순수 3D 조형 **67개**를 선정했다. 기본형·세트 구성물의 가까운 변형 **42개**, 충분한 입체를 확인하지 못한 **2개**, 입체는 있으나 이번 귀여운 뷰티·미니어처 미감의 관련성이 약한 **2개**는 목표 수량에서 제외했다. 이미지 전체를 1단위로 기록하며 꽃잎·창·물체·관찰판 패널의 수는 추가 단위로 계산하지 않는다.

이 구간까지 Icons8 담당 원장은 **327장 실제 관찰 / 185개 독립 선정**이다. 본 문서는 113장 구간을 고정해 설명하며, 이전 [포근한 캐릭터·제품 소품](<77_Icons8_%ED%8F%AC%EA%B7%BC%ED%95%9C3D%EC%BA%90%EB%A6%AD%ED%84%B0%EC%99%80%EC%A0%9C%ED%92%88%EC%86%8C%ED%92%88_%EC%8A%88%EC%B9%B4%EB%8B%B4%EB%8B%B9.md>)·[부드러운 소품](<79_Icons8_%EB%B6%80%EB%93%9C%EB%9F%AC%EC%9A%B43D%EC%86%8C%ED%92%88_%EC%8A%88%EC%B9%B4%EB%8B%B4%EB%8B%B9.md>)의 선정 수를 반복해 합산하지 않는다. 전체 프로젝트의 최신 집계는 [집계와 검증](<06_%EB%B9%84%EC%A3%BC%EC%96%BC_%EC%A7%91%EA%B3%84%EC%99%80_%EA%B2%80%EC%A6%9D.md>)에서 확인한다.

## 출처와 실제 확인 범위

[Icons8 공식 3D styles](<https://icons8.com/illustrations/styles/3d>)에서 **3D Sugary** 분류를 확인했다. [해당 스타일 목록](<https://icons8.com/illustrations/style--3d-sugary>)의 정상 공개 UI에서 Load next 50 / Load last 46을 사용해 446개 카드의 원작 링크·표시 제목·실제 이미지 주소를 발견했다. **446은 발견 정보이며 관찰 완료 수가 아니다.** 금융 기호·로고·단순 표정 변형을 우선 목록에서 빼고 식물, 부드러운 원료형 조형, 작은 제품·가구를 골랐다. 이미 관찰한 I8S0037 꽃다발의 동일 원작 링크는 새 후보 ID를 만들기 전에 제외했다.

113장 모두 관찰판에서 실제 부피·곡면·베벨·겹침·안쪽 면·재질을 확인했다. 판이나 휴대폰처럼 정면 카드만으로 충분한 체적을 읽기 어려운 경우에는 공식 스타일명만으로 선정하지 않았다. I8S0291·0300·0316·0321과 기존 I8S0020·0037·0074·0086·0092·0150은 개별 원본도 실제로 대조했다. 여러 그림을 나란히 보여주는 관찰판은 연구용 배열이며 새 원작 이미지가 아니다.

I8S0291 개별 상세에서 제목 **orchid**와 3D Sugary 스타일 링크를 확인했다. 작가명은 표시되지 않았고 작가 링크가 `/illustrations/author/undefined`여서 **작가 미확인**으로 남겼다. 다른 원작에 작가 정보를 전파하지 않는다. 생성형 AI 모델·렌더러·편집 가능한 메시·리깅·실제 움직임은 이 구간에서 모두 미확인이다. 제목의 *bacteria*, *science*와 같은 주제 표현은 제작 도구나 과학적 정확성의 근거가 아니다. 스타일 분류와 실제 전체 입체 모습이 시각 참고를 뒷받침하며, 실제 CG 제작 스택을 입증하지는 않는다.

## 중복과 경계 판정

- **표면·기호·표정 변화:** 집 I8S0221·0306·0307·0312는 I8S0059, 시계 I8S0242는 I8S0207, 손톱/얼굴이 바뀐 손 I8S0289는 I8S0074에 묶었다. 뷰티 관련성이 직접적이어도 같은 기본 손 형상은 새 수량을 만들지 않는다.
- **각도·상태 변화:** 나비 I8S0284는 I8S0283의 측면, 비어 있는 모래시계 I8S0244는 I8S0166, 붙은 플러그 I8S0311은 I8S0310의 연결 상태다. 상태별 비교는 보존하고 추가 단위는 0으로 처리했다.
- **기존 세트·기본 형상 조합:** 바구니 I8S0255, 카트 I8S0319, 운동 공간의 아령을 분리한 I8S0320, 기존 원뿔 플라스크를 포함한 I8S0301의 쌍 구성은 각각 대표에 묶었다. 기어 개수·건물 높이·새 채움으로 수량을 늘리지 않는다. 이 통합은 보수적 시각 분류이며 같은 메시 파일 사용을 입증한 뜻은 아니다.
- **새 연결 구조:** I8S0280은 기존 코끼리 머리 I8S0086과 달리 전체 몸·다리 연결이 보인다. I8S0300은 기존 나사 뚜껑 원통 I8S0020과 달리 좁은 목과 큰 원뿔 바닥이 보인다. I8S0291은 기존 세 줄기 꽃다발 I8S0037과 달리 큰 화분·휘어진 한 줄기가 전체 실루엣을 만든다. 각 전체 구성을 새 대표 1로 선정했다.
- **입체 확인 부족:** I8S0224 휴대폰과 I8S0268 삼각 조각은 해당 정면 미리보기에서 충분한 측면 체적을 확인하지 못해 0이다. 실제 2D 제작이라고 단정한 판정은 아니다.
- **미감 범위 제외:** I8S0316·0321의 판은 부푼 테두리와 하단 체적이 보이지만 단순 인터페이스/경기장 표식이 중심이어서 이번 뷰티·귀여운 새 조형 우선순위에서 제외했다.

별도 검토자가 I8S0291·0285·0321과 기존 I8S0037을 각각 원본으로 직접 관찰했다. I8S0291의 새 화분 전체 구조 선정, I8S0285의 닫힌 파스텔 캡슐을 추상 원료/마스코트 형태로 선정, I8S0321의 미감 제외에 동의한 의견을 [원장](<../../../data/projects/finfluencer-beauty-etf/references/index.json>)의 `independent_cross_review`에 보존했다. I8S0285를 실제 미생물·성분 효능·과학 사실의 근거로 사용하지 않는다. 워터마크는 출처 표시이며 원작 메시·리깅·툴 확인이 아니다.
