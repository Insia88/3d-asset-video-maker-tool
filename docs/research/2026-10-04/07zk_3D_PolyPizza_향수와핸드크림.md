# Poly Pizza — 향수와 작은 스킨케어 용기

향수 검색의 공개 렌더 11개와 핸드크림 원작 1개를 **보드 2개에서 모두 직접 관찰**했다. 독립 순수 3D 기본형 **8개**를 추가했다. 이전에 본 향수 원본 1개, 원통 제품의 색·뚜껑·반복 배치 변형 2개, 미감 선택에서 보류한 일반 분사 용기 1개는 추가하지 않았다. PP00133–PP00144에 기록했다.

이번 표본까지 Poly Pizza 원장은 **실제 렌더 관찰 144개 / 선택한 독립 순수 3D 기본형 91개**다. 검색 결과 수나 모델 라이브러리 전체 수를 완료 수로 사용하지 않았다.

뷰티 ETF 영상의 제품 바스켓에는 구형 향수, 낮은 크림 통, 원통 립스틱, 잘록한 튜브처럼 서로 다른 실루엣을 배치하는 편이 분류를 쉽게 만든다. 실제 기업 제품의 로고나 금융 수치를 생성 이미지 안에 맡기지 않고 별도 검증된 편집 요소로 붙인다. 참고 원작의 표면 문구와 디자인을 그대로 복제하지 않고 무표기 독자 조형으로 재설계한다.

[Perfume bottle 상세 원문](<https://poly.pizza/m/aJbcT0Vrldz>)은 Oct 11, 2017, OBJ/GLTF, CC-BY 3.0을 표시한다. 계정 Poly by Google은 공개 출처 표시이며 실제 개인 원작자의 이름까지 확인한 것은 아니다. [ultimateX의 Hand Cream](<https://poly.pizza/m/g8wMYFdo1d>)은 Nov 12, 2021, Low Poly Hypercasual games, OBJ/GLTF, CC-BY 3.0과 제작자 ArtStation 링크를 표시한다. 두 원문의 실제 3D 제작 프로그램과 생성AI 사용 여부는 미확인이다. 나머지 검색 카드의 개별 최초 공개일과 권리는 미검증으로 남겼다.

원본/실제 관찰 근거는 `evidence/3d_images/plus/poly_pizza/pp005/`, `pp006/`와 `shots_plus_poly_pizza.jsonl`에 있다. 향수 11개를 이전 선택 기본형 598개와 교차한 해시 후보 네 쌍은 실제 원본을 대조했다. 한 쌍은 같은 원본이라 이미 제외했고, 나머지 세 쌍은 펌프 병/원숭이, 장식 병/마스카라, 코/면봉의 서로 다른 조형으로 확인했다. 해시만으로 선택 수량을 자동 늘리거나 줄이지 않았다.

정상 공개 UI와 표시된 원본 렌더만 조사했다. API 요청·API 키/앱 생성·로그인·메시 다운로드·구매·이미지/영상 생성은 모두 0이다. 정지 렌더에서 카메라 속도·컷·애니메이션을 측정했다고 기록하지 않았다.
