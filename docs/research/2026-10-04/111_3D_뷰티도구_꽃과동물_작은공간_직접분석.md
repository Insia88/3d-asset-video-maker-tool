# 뷰티 도구·꽃과 둥근 동물·작은 CG 공간의 실제 관찰

공식 공개 3D 검색 고유 후보 167개 중 기존 원본 ID·해시 중복 90개를 뺀 새 이미지 77개를 13개 관찰판에서 모두 직접 관찰했다. 순수 3D 42개 선정, 그 외 35개 제외다. 실제 정지 이미지 한 장을 한 단위로 기록했다.

## 제작에 옮길 구조

- 드라이어의 노즐/손잡이·굽은 케이블과 꽃의 겹친 꽃잎을 두꺼운 조형으로 설계한다. 각 부분의 옆면과 안쪽 그림자가 입체성을 설명한다.
- 큰 머리/짧은 몸의 동물과 닫힌 다면 동물을 다른 기본 비례로 나눈다. 같은 기본형의 작은 색/자세·액세서리 차이는 대표 하나로 통합한다.
- 작은 집·토이 방·놀이 무대는 벽/지붕/바닥과 큰 가구의 좌표를 먼저 잠근다. 한 원본 안의 여러 제품이나 인물을 분할해 세지 않는다.
- 접힌 종이·라벨/화면은 입체 소품의 부수 표면 표시인지, 별도의 넓은 2D 정보층인지 구별한다. 앞 캐릭터만 입체인 불확실한 배경은 전체 선정에서 보류한다.
- 사실형 피부·직물/식물·공예 질감은 실제 제작 모델이나 사진 매핑을 증명하지 않는다. 경계 자료는 전체 원본을 독립 검토하고 관찰 사실과 구현 추정을 분리한다.

13개 전체 이미지 관찰판의 새 원본 77장을 직접 관찰했다. 선정은 실제 화면의 CG 시각 스타일에 관한 판정이다. 개별 생성 모델·메시·리깅과 정지 이미지의 실제 움직임은 미확인이다. 원본 전체를 한 단위로 유지하고 유사 기본형을 실제 전체 이미지 비교 후 대표 통합한다. 추가로 5개 전체 원본 기본형 비교판과 1개 픽셀 근접 후보판을 직접 확인했다. 10개 변형은 기존 대표에 합치고 형태가 다른 근접 후보는 유지했다.
