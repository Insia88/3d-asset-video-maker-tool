## 크림 용기: 열린 내부 구조를 한 장면으로

CG1407-S01은 어두운 보라색 유리 크림 용기, 큰 흰 뚜껑, 금속 나사산, 분홍 내용물, 낮은 수면의 파문과 뒤쪽 두 튜브를 묶은 전체 제품 장면이다. 밝은 뚜껑과 어두운 용기 표면의 대비로 개구부가 잘 보인다. 열린 용기의 내부와 외부를 한 화면에서 이해할 수 있다는 점이 유용하다.

뚜껑을 닫은 구도, 튜브를 생략한 구도, 용기 확대, 다른 공개 해상도는 같은 제품·세트의 변형으로 CG1407-S01에 통합했다. Blender UI가 보이는 네 자료는 jar·lid·tube·waterplane의 모델링 실체를 뒷받침하지만 순수 3D 완성 단위에 포함하지 않았다. Photoshop과 Substance 3D Painter는 도구 목록 표기만 확인했으며 실제 사용 단계까지 검증했다고 쓰지 않는다.

뷰티 ETF 영상에서는 독자 크림 용기의 나사산과 뚜껑·한 덩어리 내용물을 먼저 고정한다. 용기는 제품군을 보여주는 시각 소품으로 사용하고, 수면·보조 튜브가 정보 중심을 가리지 않게 배치한다. 특정 제품의 효능이나 ETF 편입을 이 이미지에서 추론하지 않는다.

## 스킨케어 제품군: 서로 다른 용기 실루엣과 발판의 깊이

CG1410-S01은 튜브, 길쭉한 병, 짧은 펌프, 정사각 크림통, 드로퍼를 아이보리 재질로 맞춘 전체 제품군이다. 각 제품의 폭·높이·뚜껑 모양이 다르고, 사선 빛과 그림자가 볼륨을 분명하게 만든다. 제품군 내부의 여섯 용기를 여섯 개 참고 단위로 나누지 않고 전체 진열 한 단위로 기록했다.

CG1410-S07은 두 아이보리 병을 붉은 입체 발판과 수직 벽에 배치한다. 발판의 두께, 떨어진 높이, 벽과 바닥의 연결이 분명해 단순 배경색 변화보다 공간 구조가 달라진다. 이 구조를 두 번째 단위로 선별했다. 녹색 부분 진열, 단독 펌프, 누운 용기 탑뷰, 부유 포즈, 회색 재질 비교는 같은 기본 제품군의 일부·자세·카메라·재질 변형으로 통합했다.

제작자 원문은 Blender Cycles, HDRi와 세 광원 구성, 플라스틱·유리·무광 셰이더를 설명한다. 이는 제작자의 공개 진술이다. 실제 Blender 파일이나 노드를 열지 않았으므로 광원 수, 셰이더 값, 렌즈를 직접 측정한 것으로 바꾸지 않는다. 생성 AI 사용을 입증하는 모델명·생성 기록은 확인하지 못해 전통 CG 비교 자료로 둔다.

독자 뷰티 제품군을 제작할 때 원통·직육면체·튜브의 실루엣을 분리하고 무표기 표면을 사용한다. 작은 발판의 높이와 깊이를 ETF 기업군·공급망 역할의 구분에 적용할 수 있다. 원작 글자·브랜드 제품을 그대로 생성하는 규칙으로 사용하지 않는다.

## 재게시와 제작 근거의 처리

CG1408의 노란 Jake 전신 렌더는 기존 CG043의 검정 X 눈·긴 주둥이·혀·허리 양손·림광까지 같은 이미지였다. 두 실제 이미지를 직접 비교했고 dHash 4/aHash 0 결과를 보조 근거로 사용했다. 같은 캐릭터 이름이라는 이유로 합친 것이 아니다. 압축과 해상도 차이가 있어 원본 파일의 SHA256 동일성을 주장하지 않는다.

CG1409는 공개 확대 UI로 11자료를 읽은 뒤, Shahzad 본인 원문의 11자료를 보관하고 실제 화면을 대조했다. 완성 렌더와 회색 모델 비교 전체가 같은 작품이므로 제작 설명이 구체적인 CG1410을 대표 출처로 채택했다. 공개 재게시의 허가·계약 여부는 확인하지 않았고 게시자의 신원을 최초 제작자로 확정하지 않는다. 서로 다른 게시처를 독립 수량에 더하지 않는다.

## 추적 근거

각 행에는 원문 URL, 공개 이미지 URL과 SHA256, 실제 원본 이미지와 관찰 보드, 시각 설명, 대표 병합 ID, 제작 출처 상태를 기록했다. CG1407·CG1408은 보드 각 3개, CG1409·CG1410도 보드 각 3개를 실제 관찰했다. 기존 759/760개 대표와의 해시 후보 검사를 병행했고, 후보는 실제 이미지로 판단했다. 해시 후보 0이 전 세계 이미지의 독창성을 증명하지는 않는다.

- 원장: `shots_plus_3d_images.jsonl`, CG1407–CG1410.
- 원본·보드·수동 판정: `evidence/3d_images/plus/CG1407`–`CG1410`.
- 이 배치의 관찰은 정지 자료다. 영상 컷·시간·BPM·음향을 분석한 자료로 표시하지 않는다.
