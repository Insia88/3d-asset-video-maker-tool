# 3D 기본형의 실제 비교와 대표 통합

파스텔 동물·꽃잎·작은 무대 배치의 새 전체 이미지 83장을 직접 관찰한 뒤, 기존 대표와 비교했다. 신규 묶음은 독립 순수 3D 52개를 선정하고 31개를 제외했다. 제외에는 같은 기본형 변형 20개가 포함된다. 비교판 9개와 픽셀 근접 후보판 2개를 전체 이미지로 확인했다. 검색 결과 번호·픽셀 해시의 근접만으로 대표를 바꾸지 않았다. 이 문서의 비교 원본은 추가 완료 수로 중복 집계하지 않는다.

## 같은 기본형으로 통합한 과거 기록

| 기존 기록 | 유지하는 대표 | 실제 전체 화면에서 확인한 관계 |
|---|---|---|
| SCM4618889-I001 · SCV4618886-I001 | SCV4618884-I001 | 큰 둥근 머리·짧은 몸·느슨한 니트·턱에 손·생각 구체·낮은 받침의 머리/옷·작은 포즈 변형. 서로 다른 검토자가 네 원본을 직접 비교했다. |
| SCM3553146-I001 | SCM3553145-I001 | 분홍 고양이 머리·흰 크림·세로 주름 컵 기본형의 작은 팔/발·표정·주변 별 변형. |
| SCM5203950-I001 | SCM5203949-I001 | 큰 다면 후드·짧은 몸/작은 손발·다면 초록 섬의 색·표정·약한 구도 변형. |
| SCM4594772-I001 | SCM4594771-I001 | 긴 귀·큰 머리·짧은 몸/넓은 뒷발의 토끼 기본형에서 귀 굽힘·눈/표면 광택을 바꾼 변형. |

과거 선정 수는 다섯 개 줄었다. 원본 ID·URL·해시·기존 관찰은 삭제하지 않고 `excluded_near_variant`와 유지 대표의 `duplicate_of`로 연결했다. 대표를 참조하는 새 기록도 마지막 유지 대표에 직접 연결한다.

## 재사용할 판정 순서

1. 전체 원본의 앞/옆 면·접지·외피 두께와 주요 공간을 실제로 본다.
2. 같은 원본 ID·파일 해시·동일 픽셀을 먼저 확인한다.
3. 가까운 픽셀·원본 ID와 의미상 비슷한 기존 대표를 후보로 찾아 전체 이미지를 함께 본다.
4. 주요 기하/좌표가 같은 색·표정·옷·작은 포즈 변형은 대표에 묶는다. 다른 큰 외피/공간 구조는 독립 형태로 남긴다.
5. 털·니트·종이·작은 화면이 경계에 있으면 서로 다른 검토자가 원본을 직접 확인한다. 제작 방식이 불확실하면 완료 수에서 보류한다.
6. 원본 관찰과 출처를 보존하고 판정 이유·유지 대표·집계 변화를 기록한다.

소품의 작은 인쇄·디스플레이 표면은 전체 CG 공간의 일부로 읽을 수 있다. 별도 넓은 사진 배경·평면 설명층이 지배하는 혼합 화면과 구별한다. 이번 작은 휴대폰 화면의 같은 CG 인물은 부수적인 소품 텍스처로 독립 교차 검토한 뒤 선정했다. 실제 제작 툴·편집 가능한 메시·리깅·생성 모델과 움직임은 이 정지 이미지 관찰에서 추론하지 않는다.
