# 큰 머리와 짧은 몸의 순수 3D 마스코트

[공개 cute 검색](<https://poly.pizza/search/cute>)의 실제 렌더 22개를 2개 보드에서 직접 관찰하고 10개를 선별했다. 기존 J-Toastie 기본형 10개는 후보 발견 단계에서 제외했고 관찰 완료 수에 넣지 않았다. 제목에 cute가 있더라도 실제 일반 항공기·일반 동물 비례·긴 팔다리·강한 뾰족 돌기는 현재의 귀엽고 따뜻한 뷰티 조형 선별에서 제외했다.

큐브 새는 기존 PP00321의 큰 네모 머리/작은 네모 몸 대표로 합쳤다. 같은 작가의 다른 고양이 렌더도 색·목줄·앉은 자세에 따라 늘리지 않고 PP00476의 유사 기본 비례로 보수적으로 통합했다. 같은 메시라는 주장과 구분되는 기본형 통합이다. 10개는 서로 다른 선별 구조이며 표정·색 변형 수가 아니다.

이미지 18개는 공개 페이지 자산 묶음으로 보관했다. 4개는 서버가 이미지 바이트를 일반 이진 MIME으로 보내 자산 묶음이 거절했지만, 실제 공개 DOM의 동일 이미지 URL을 일반 비로그인 요청으로 받아 HTTP200·Pillow 이미지 검증을 확인한 후 관찰했다. 로그인·권한 우회·비공개 API는 사용하지 않았다.

원장 `shots_plus_poly_pizza.jsonl`, 실제 원본과 보드 `evidence/3d_images/plus/poly_pizza/pp021/`, 개별 날짜·형식·라이선스 `pp021_selected_metadata.json`에 연결되어 있다. 정지 렌더이므로 애니메이션·카메라 이동·BPM은 측정하지 않았다. 새 생성 작업은 수행하지 않았다.

새 원본 22개와 이전 선별 722개를 SHA·dHash·aHash로 비교한 큐브 새/흰 화분 1쌍을 실제 원본으로 직접 대조했다. 얼굴·부리·발이 있는 새와 열린 입구의 화분은 다른 구조이므로 해시 오검출로 기록했다. 새 큐브 새는 기존 기본형으로 이미 통합되어 완료 수에 더하지 않았다.
