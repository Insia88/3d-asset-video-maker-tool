# 둥근 캐릭터·따뜻한 작은 CG 거리의 실제 관찰

공식 공개 3D 검색 고유 후보 121개 중 기존 원본 ID·해시 중복 48개를 뺀 새 이미지 73개를 13개 관찰판에서 모두 직접 관찰했다. 순수 3D 59개 선정, 그 외 14개 제외다. 실제 정지 이미지 한 장을 한 단위로 기록했다.

## 제작에 옮길 구조

- 큰 머리/짧은 몸의 제품 마스코트는 기본 얼굴·외피·손/신발 좌표를 고정한다. 각도·표정·옷을 바꾼 같은 기본 캐릭터는 대표에 합친다.
- 작은 가게/골목/해변은 지붕·차양·벽·길·큰 식물 좌표와 둥근 재질 체계를 묶는다. 같은 장소의 색/차량/소품 재배치는 추가 대표로 세지 않는다.
- 두꺼운 안경·확대경·원형 외피·니트는 역할별 재질을 분담한다. 자연 질감만으로 사진을 판단하지 않고 전체 광원·부피와 독립 사진/평면 레이어를 확인한다.
- 작은 회로판·청진기·지도·캔버스는 화면 속 조형 소품으로 읽는다. 정지 이미지에서 실제 기능·동작·효능이나 금융 수치를 추론하지 않는다.
- 교실·정원·작업장·시트의 인물/소품은 전체 원본 하나로 남긴다. 입체 주체와 큰 평면 지도·도표가 혼합된 화면은 순수 3D 목표에서 제외한다.

3D 스타일 필터의 공개 원본을 실제 전체 이미지로 관찰했다. 필터 이름만으로 실제 제작 방식·메시·리깅을 인정하지 않는다. 선정한 CG는 시각 스타일 판정이며 개별 생성 모델/편집 가능한 메시/도구는 미확인이다. 정지 이미지의 실제 움직임은 관찰하지 않았다. 서로 다른 검토자가 경계 원본을 직접 확인한 의견을 반영했다.
