# IconScout 스파 공간·수건·둥근 소품의 입체 구성

공식 Spa 3D Icons 검색에서 새로 확인한 실제 미리보기 77장을 직접 개별 관찰하고 20장을 선정했다. 기본 조형이 겹치는 색·자세·작은 소품 변형 43장은 대표 원작으로 묶었고, 현재 뷰티·귀여운 미감의 우선순위가 낮은 14장은 제외했다. 팩 표지는 집계하지 않았으며 여러 도구가 함께 있는 이미지도 한 장이 한 단위다.

선정 원작 20개와 추가 비교 원작 2개는 개별 공개 페이지의 제작자와 제공 형식 문구를 직접 확인했다. 이 자료는 공식 3D 디자인 에셋 미리보기이며 원작의 AI 제작/특정 모델은 미확인이다. 사이트의 AI 편집·생성 버튼을 원작 제작의 증거로 사용하지 않았다. 제공 형식 표기는 실제 메시 파일을 열어 검증한 결과와 구분한다.

## 작은 스파 공간을 만드는 구조

- 작은 나무 사우나의 닫힌 바깥과 나무 벽 코너/낮은 벤치의 안쪽은 서로 다른 공간 관계다. 실제 문 열림이나 내부 움직임을 관찰한 것은 아니다.
- 나선 수건 원통과 접힌 수건의 두꺼운 고리 단면은 독립적인 둥근 구조다. 수건 수·색·작은 꽃/촛불·받침 변화는 기본 조형을 대표화해 늘리지 않는다.
- 둥근 욕조/림 위 수건, 큰 꽃잎이 촛불 아래를 감싸는 받침, 여러 막대가 유리 입구에 들어가는 디퓨저는 부품의 관계를 보여 준다. 큰 제품과 작은 캐릭터의 공간을 설계할 때 옮길 수 있는 분석자의 제안이다.
- 닫힌 CG 거품·불꽃·물방울·증기 부품이 정지한 원작에 실제 유동/열/낙하 동작을 부여하지 않는다. 원작의 스파/관리 제목을 성분·효능·시설 운영이나 특정 금융 사실의 증거로 쓰지 않는다.
