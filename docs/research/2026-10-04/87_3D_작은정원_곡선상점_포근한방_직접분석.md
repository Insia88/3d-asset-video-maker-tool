# 작은 정원·곡선 상점·포근한 CG 방의 실제 관찰

공식 공개 3D 검색 고유 후보 104개 중 기존 원본 ID·해시 중복 18개를 뺀 새 이미지 86개를 15개 관찰판에서 모두 직접 관찰했다. 순수 3D 48개 선정, 그 외 38개 제외다. 실제 정지 이미지 한 장을 한 단위로 기록했다.

## 제작에 옮길 구조

- 잘린 벽·바닥의 두께와 가구의 접지를 먼저 만든다. 하나의 방을 완성한 뒤 카메라를 옮기는 방식으로 제품 소개 화면의 공간 연속성을 확보한다.
- 곡선 외피 상점과 작은 진열대는 두꺼운 창/차양·한 조리대·소수의 제품만으로 실루엣을 만든다. 빈 무대를 남겨 이후 편집 자막을 안정적으로 배치한다.
- 복층 공간은 침실/거실/계단의 기능과 좌표를 고정한다. 같은 방의 색이나 시점 변화는 독립 기본형 수량으로 늘리지 않는다.
- 복셀 정원은 나무·가구·인물·창 밖 풍경까지 같은 격자 체계를 이어간다. 사진형 바깥 탁자나 자연 배경을 조합한 화면은 전체 순수 3D 범위에서 제외한다.
- 둥근 재료 단면과 작은 섬의 관계 구조는 제품/원료 소개의 조형 참고로 사용할 수 있다. 시각 자료만으로 실제 기업·ETF·성능 관계를 주장하지 않는다.

새 원본 전체를 직접 관찰하고 사진형 사람·음식·직물·매장·자연 배경과 평면 도면/삽화를 제외했다. 검색 분류가 3D여도 화면의 실제 깊이·두께·같은 조명과 재질을 확인한 뒤 선정했다. 단순한 공간의 여러 방/가구/인물은 한 전체 이미지 단위로 기록했다. 3D는 관찰한 시각 스타일이며 개별 생성 모델·실제 메시·제작 도구·리깅은 미확인이고 움직임은 정지 이미지에서 미관찰이다.
