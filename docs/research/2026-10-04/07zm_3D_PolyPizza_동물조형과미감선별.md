# Poly Pizza — 동물 조형의 미감 선별

공개 원작 묶음 세 개의 **렌더 25개를 보드 3개에서 모두 직접 관찰**했다. 여우·시바견·알파카·돼지·퍼그·양의 독립 기본형 **6개**를 선택했다. 색·뿔·무늬·기본 동물 구조의 변형 9개와 미감 방향이 약한 기본형 10개를 제외했다. PP00156–PP00180에 기록했다. Poly Pizza 누적은 **실제 관찰 180개 / 선택 기본형 102개**다.

여기서 완구형 참고는 모든 동물이 큰 머리·작은 몸이라는 뜻이 아니다. 선택한 모델도 얼굴보다 몸을 크게 만든 구조가 있으며, 실제 비례와 부속을 원장에 구분해 적었다. 서로 다른 제작 파일의 기본 구조를 통합한 경우와 정확히 같은 이미지 원본이 확인된 경우도 구별한다.

원문은 첫 묶음의 FBX/OBJ/glTF/Blend와 12개 이상의 동작, 농장 묶음의 FBX/GLTF와 run/idle/jump/walk, 공룡 묶음의 FBX/OBJ/Blend와 Attack/Jump/Run/Walk를 설명한다. 이는 제작자의 공개 주장이다. 실제 메시·Blend 파일을 검사하거나 동작을 재생·측정한 것은 아니다. 실제 제작 프로그램과 생성AI 사용 여부는 미확인이다. CC0 표시와 묶음 업데이트 날짜 2022-07-09/2022-07-10은 공개 원문에서 확인했고, 개별 최초 공개일은 미검증이다.

독자 마스코트에 차용할 구조는 시바의 큰 말린 꼬리, 퍼그의 짧은 주둥이, 양의 단순 털 몸통이다. 귀·꼬리·얼굴을 같은 캐릭터에 모두 늘려 붙이는 대신 주요 특징 한두 개로 제한한다. 뷰티 제품 소품과 함께 사용할 때는 서로 다른 동물로 장면마다 안내자를 바꾸지 않고 하나의 독자 조형을 고정한다.

근거는 `shots_plus_poly_pizza.jsonl`과 `evidence/3d_images/plus/poly_pizza/pp008/`, `pp009/`, `pp010/`의 실제 원본 및 관찰 보드다. 3D 모델 총수와 애니메이션 수를 참고 완료 수로 환산하지 않았다. 공개 UI 렌더만 확인했으며 API·로그인·키 생성·메시 다운로드·구매·생성은 모두 0이다.
