# JD99 — 귀여운 동물·로봇·작은 입체 세계

검토일 2026-10-04. [제작자 공개 포트폴리오](<https://jdts9901.artstation.com/projects>)의 59개 작품 링크를 확인한 뒤 39개 상세 페이지를 각각 열었다. 해당 페이지의 실제 공개 이미지 110장을 10개 식별자 보드로 전부 직접 관찰해 독립3D 참고단위 49개를 채택했다. 나머지 61장은 같은 기본형의 색/의상/각도, 2D콘셉트·UV맵·실제거리 참고사진·초기 블록아웃·방향에 맞지 않는 무기/흡연 역할 등으로 제외했다. 포트폴리오 링크 수, 실제 상세검토 페이지 수, 관찰 이미지 수, 독립 단위 수를 각각 구분한다.

## 공개 제작 근거

프로필은 Blender 작업이 가능한 Freelance 3D Artist로 소개한다. 작품 본문은 고객2D참고/글설명에 기반한 모델링과 로우폴리·단일PBR·토폴로지를 자주 명시한다. 일부 단일 이미지 안에 실제 컬러 모델과 클레이/와이어를 함께 제시하므로 메시 실체와 완성 디자인을 대조할 수 있다. AI 사용 증거는 확인되지 않아 전통 CG 비교자료로 기록한다. 게시일은 미검증이다.

[PunchKun](<https://jdts9901.artstation.com/projects/bg6gmm>)은 원숭이·작은 인형 모델의 8,448faces/14,490tris, [WIP Chibi](<https://jdts9901.artstation.com/projects/Ov2vg6>)는 10,634faces/19,466tris를 밝힌다. [Cowboy Capybara](<https://jdts9901.artstation.com/projects/gRmRgK>)는 7,603faces/14,487tris와 핸드페인트·부드러운 형태를 명시한다. 이는 제작자 명시값이며 직접 메시를 측정한 값이 아니다.

[Seasonal Axolotl](<https://jdts9901.artstation.com/projects/6vnD2V>)은 같은 세트 기본형의 계절별 색/소품을 설명한다. [StarTown](<https://jdts9901.artstation.com/projects/BkBG1r>)은 고양이 로봇 기본형과 의상 변형을 명시한다. [Voxel Zoo](<https://jdts9901.artstation.com/projects/8vWDzE>)는 Roblox용 서로 다른 동물 모델을, [작은 피겨](<https://jdts9901.artstation.com/projects/3Ex8Kv>)는 고객의 글설명에 기반한 개별 미니어처를 설명한다. 정지 관찰에서 실제 애니메이션 동작/속도를 측정하지 않았다.

## 집계와 제외 판정

CG253의 세 계절 아홀로틀은 기본 비례가 같고 색/스카프/선글라스/꽃장식이 바뀌므로 한 디자인 시트만 남겼다. CG261 네 로봇 의상, CG288 토끼 세 의상, CG292 Labubu 세 색/의상도 각각 기본형 한 단위다. CG291 Boo 팬캐릭터 의복과 CG282 기존/새 의복 버전도 한 디자인으로 묶었다. 팬캐릭터를 재현 자산으로 복제하지 않는다.

CG254는 전체 동물 배열을 추가 단위로 더하지 않고, 개별 시트에 제시된 서로 다른 몸/귀/꼬리 구조의 동물 9개만 남겼다. CG264 학생 4명과 CG265 역할 5명은 같은 인물군의 한 디자인 시트 각각 한 단위로 보수적으로 묶었다. CG271은 제작자가 별도 모델 납품을 설명하고 독립 시트도 있는 꼬마/물고기 2개를 남겼다. CG263 전체 차량 배열은 제외하고 선택한 개별 완성 차량 3개만 남겼다.

CG269/270/271/272/273/274/275/276/277/279/280/282의 UV/재질맵은 평면 제작 근거라 집계에서 제외했다. CG264의 2D콘셉트와 CG278/281의 실제 거리 참고사진도 제외했다. CG278/281 초기 건물 블록아웃은 완성 귀여운 공간으로 채택하지 않았다. CG247 무기 세트, CG290 전신 기술전투복, CG295 어두운 흡연 캐릭터는 3D 여부와 별개로 적용 방향에서 제외했다.

CG294는 치즈 친칠라·운동돼지·쌀통 레서판다·소나무 다람쥐·딸기우유 소의 다른 구성 5개를 남겼다. 분홍 결정/곡괭이 조합 A05는 최신 귀여운 생활/뷰티 방향에서 제외했다. 한 미니어처 안의 동물 여러 마리나 치즈 조각을 따로 더하지 않았다.

## Higgsfield 자산 설계 제안

아래는 실제 정지 조형에서 도출한 제작 제안이며 영상에서 실측한 속도값이 아니다.

1. 고유 뽀짝 안내자 한 기본형을 정면/옆/뒤와 표정 시트로 확정한다. 큰 얼굴·귀/모자 특징 하나·작은 팔다리·주색 두세 개를 잠근다.
2. 몸의 무광, 눈/얼굴화면의 유광, 제품의 유리/크림을 분리한 자산으로 만든다. 처음부터 여러 제형·털·빛을 동시에 흔들지 않는다.
3. 미니어처의 바닥·큰 제품·작은 안내자를 세 층으로 묶는다. 제품의 크기와 손/발 접촉을 고정한 뒤 작은 고개 기울임/손짓 하나와 카메라 전진 하나를 시험한다.
4. ETF 구성은 여러 원작 캐릭터를 복제하는 방식 대신 새 제품/가치사슬 소품이 담긴 작은 바구니로 설명한다. 실제 구성·비중·위험·출처와 한글 글자는 후편집으로 합성한다.
