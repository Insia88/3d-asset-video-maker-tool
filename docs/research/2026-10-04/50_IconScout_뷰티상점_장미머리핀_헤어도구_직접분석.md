# IconScout 뷰티 상점·장미 머리핀·헤어 도구

공식 Beauty 3D Icons 검색에서 새로 확인한 실제 미리보기 78장을 직접 개별 관찰하고 7장을 선정했다. 기본 조형이 겹치는 색·자세·작은 소품 변형 67장은 대표 원작으로 묶었고, 현재 뷰티·귀여운 미감의 우선순위가 낮은 4장은 제외했다. 팩 표지는 집계하지 않았으며 여러 도구가 함께 있는 이미지도 한 장이 한 단위다.

선정 원작 7개는 개별 공개 페이지의 제작자와 3D 파일 제공 형식 문구를 직접 확인했다. 이 자료는 공식 3D 디자인 에셋 미리보기이며 원작의 AI 제작/특정 모델은 미확인이다. 사이트의 AI 편집·생성 버튼을 원작 제작의 증거로 사용하지 않았다. 제공 형식 표기는 실제 메시 파일을 열어 검증한 결과와 구분한다.

## 뷰티 세계를 만드는 구성

- 줄무늬 원통과 작은 앞치마는 상점의 기호와 작업 소품을 두꺼운 조형으로 묶는다. 실제 점포/착용자 사진을 관찰한 자료가 아니다.
- 장미/리본 머리핀은 작은 제품을 큰 장식과 엮는다. 두 핀이 교차하는 한 장은 한 단위이며, 같은 핀의 색/장식/각도 변화는 대표화한다.
- 둥근 트리머 몸통, 네 개의 원형 교체 헤드, 긴 컬링 원통은 서로 다른 작동 부품의 구조를 읽히게 한다. 개별 부품 수만큼 참고 단위를 늘리지 않는다.
- 큰 핑크 구형 향수병은 작은 노즐과 큰 구의 비율을 강조한다. 투명 유리/금속/라벨이 달라진 같은 구형 병은 변형으로 묶었다.

[공식 Beauty 3D Icons 검색](<https://iconscout.com/3d-icons/beauty?page=4>)과 각 항목의 원작 페이지를 이용했다. 실제 관찰물은 450×450의 공개 PNG/WebP 래스터 미리보기이며 전체 형태를 직접 보았다. 정지 이미지에서 카메라/움직임을 관찰했다고 주장하지 않는다. 카메라 제안과 금융·뷰티 적용은 분석자의 해석이다.
