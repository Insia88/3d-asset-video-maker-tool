# winter-dome: 미니어처 3D 설명 영상의 화면 문법

분석 대상: 로컬 관찰 근거<br>
기준일: 2026-10-04<br>
관찰: 원본 메타데이터, 0.5초 간격 120프레임, 장면 변화 후보 전후 62프레임. 음성을 청취한 분석은 포함하지 않는다.

## 핵심 판단

이 영상은 **하나의 생활 공간을 반복해서 보여주면서, 문제 → 설치 → 고객 경험 → 이용 시간 → 운영 부담 → 사업 효과로 설명을 진전시키는 미니어처 제안 영상**이다. 차용할 핵심은 인형이나 돔의 외형보다, 관객이 이미 익힌 공간에 새 정보만 추가하는 방식이다.

뷰티 ETF에서는 같은 장치를 **소비자가 쓰는 화장품 → 그 뒤의 브랜드·제조·유통 → 여러 기업을 담는 투자 구조 → 그 구조의 비용과 위험**으로 바꿀 수 있다. 화장품이 동전으로 변하는 장면 하나로 수익을 약속하는 구성보다, 제품 뒤에 어떤 기업 활동이 존재하는지 보여주는 구성이 금융 설명에 적합하다.

## 2. 측정 방법과 해석 범위

- 2fps 접촉 시트는 전체 60초의 공간·인물·카피 변화를 확인하는 데 사용했다. 캡처의 시간 표시는 0.5초 샘플링 구간의 시작이며 컷 경계가 아니다.
- 원본 30fps에서 FFmpeg scene > 0.12로 화면 변화 후보 31개를 검출했다.
- 후보 전후 약 0.2초의 프레임을 대조했다. 한 전환의 시작·종료, 큰 움직임, 자막 변경도 후보가 될 수 있어 검출 개수를 컷 수로 쓰지 않는다.
- 8.433/8.600초의 전환 후보를 한 장면 전환으로, 19.667~21.067초의 선반 선택 구간을 한 설명 단위로 보수적으로 묶었다.
- 아래 30개는 **관찰한 서로 다른 화면·설명 단위**다. 완성 편집 프로젝트를 읽어 확정한 30개 하드컷 목록이라는 뜻은 아니다.
- 후보 간 평균 간격은 약 1.874초, 중앙값 약 1.867초다. 이 값은 자동 변화 후보 간격으로만 사용하며 평균 샷 길이나 자막 노출 시간으로 바꾸지 않는다.

원본과 분석 프레임은 로컬 관찰 근거에 연결된다.

| V 음성 | 청취 분석 없음 | 금융 용어를 말할 때 충분한 호흡을 확보 |
| W 플랫폼 | 9:16에 적합한 세로 초점과 큰 제목 | 최종 제출 비율 확인 후 안전 영역 명세 |
| X 시그니처 | 같은 미니어처 공간·재질·광원 규칙의 반복 | 반복 가능한 뷰티 산업 세트를 잠금 |
| Y 180초 적용 | 하나의 60초 장면을 3배 늘이면 반복성이 커짐 | 소비→산업→ETF판단 세 장으로 기능을 바꿈 |
| Z 한계 | 제작 provenance·음성·사업 수치 미검증. 모션은 시퀀스 샘플 기반 | 관찰·해석·제작 제안을 구분해 사용 |

## 5. 속도감의 실제 원인

### 같은 공간이 기억 비용을 줄인다

편의점, 좌석, 돔의 관계를 알면 이후 컷마다 장소를 다시 이해할 필요가 없다. 빨라진다는 느낌의 일부는 이동량보다 **이미 이해한 배치의 재사용**에서 나온다. ETF에서도 매 컷 전혀 새로운 환상 공간을 만들면 정보가 누적되지 않는다. 뷰티 산업의 브랜드·제조·유통 노드를 고정하고 선택·연결·확대만 바꾸는 편이 좋다.

### 크기 변화가 질문을 바꾼다

전경은 “어떤 공간인가”, 탑뷰는 “어떻게 배치되는가”, 손·상품 근접은 “무엇을 하는가”, 숫자 카드는 “얼마인가”를 다룬다. 이 질문이 바뀌는 순간 컷을 바꾸면 편집에 이유가 생긴다. 소품을 더 보여주기 위해 카메라를 계속 돌리는 방식으로는 같은 설명 효과가 나오지 않는다.

### 시간대 변주는 규칙이 보여야 작동한다

35~47초의 다섯 이용 장면은 돔이 유지되고 인물·시간·음식이 바뀐다. 비교 기준이 고정되어 있어 서로 다른 내용을 빠르게 읽을 수 있다. 기업·ETF 비교에서도 화면 위치, 라벨 역할, 단위를 유지해야 한다. 비교마다 다른 카메라와 재질을 쓰면 비교 정보보다 장식이 먼저 보인다.

### 읽기 구간은 움직임을 낮춘다

시간대 표와 큰 비율을 설명하는 구간은 배경을 흐리게 한다. 화면 사건을 줄여 문자를 보게 한다는 원리는 차용할 수 있다. 다만 금융 숫자를 흐리게 처리하거나 너무 작은 각주에 의존하면 핵심 근거가 사라진다. 배경만 억제하고 데이터·단위·기준일은 선명하게 유지한다.

## 6. 그대로 가져오지 않을 요소

| 원본에서 관찰된 요소 | ETF에서 생길 문제 | 바꿀 표현 |
|---|---|---|
| 코인 더미+상승 화살표 | 산업 관심이 실제 투자 수익을 보장하는 인상 | 상승·하락을 포함한 변동 경로 또는 선택 기준 |
| 작은 글씨의 큰 수치 근거 | 작은 화면에서 기준·단위를 확인하기 어려움 | 숫자와 기준일을 같은 읽기 레이어에 배치 |
| 매장 간판 문자 변화 | 공식 로고·상품명을 AI가 왜곡 | 로고·ETF명은 생성 이후 합성 |
| 낮·밤·타 구도의 제품·인물 변화 | 기업·종목 토큰의 동일성이 흔들림 | 마스터 이미지·정확한 3D 에셋을 재사용 |
| 다섯 시간대마다 비슷한 식사 장면 | 3분 영상에서는 의미의 반복 | 반복 장면에 다른 판단 항목을 맡김 |
| 수익·효익 중심 종결 | 비용·집중위험·변동성이 밀림 | 효익 이후 동일한 비중의 반례·비용·위험 설명 |

18~20초 주변에는 간판의 영문/표식이 안정적이지 않은 프레임이 보인다. 이는 생성형 작업에서 자주 생기는 결과와 닮았지만, **이 파일이 생성형 AI로 제작됐다는 provenance 증거는 아니다.** 여기서는 관찰된 문자 일관성 문제로만 기록한다.

## 7. Higgsfield에 옮기기 쉬운 제작 단위

아래는 원본 도구를 역추적한 결과가 아니라, 관찰한 화면 문법을 구현하기 위한 제안이다.

| 단위 | 키 이미지에 잠글 내용 | 영상에서 움직일 내용 | 후반 합성할 내용 |
|---|---|---|---|
| 소비재 전경 | 화장대/제품, 고정 광원, 제품 개수 | 짧은 접근 또는 제품 한 개의 회전 | 질문 제목 |
| 산업 분해 | 브랜드·제조·유통의 노드와 위치 | 한 방향의 분해·연결 | 기업 역할 라벨 |
| ETF 묶음 | 고정 크기의 트레이와 토큰 | 토큰의 짧은 이동·정렬 | ETF명·지수명·비중 |
| 집중도 비교 | 동일 좌표·토큰 크기 기준 | 선택되는 토큰만 짧게 강조 | 실제 구성 데이터 |
| 비용·위험 | 정지 데이터 영역과 배경 | 배경의 미세한 움직임 또는 완전 정지 | 수치·단위·출처·기준일 |
| 마무리 | 최초 제품과 산업 전체의 관계 | 짧게 전체 구도로 되돌아감 | 최종 질문·판단 기준 |

모델·프리셋 명칭만으로 이 움직임이 정확히 구현된다고 보장하지 않는다. 실제 영상 실행 단계에서 해당 모델의 입력·길이·비율·참조 이미지·끝 프레임 지원을 확인한다. 현재 연구 단계에는 생성 실행이 필요하지 않다.

## 8. 180초 편집에 적용할 잠정 시간 설계

| 구간 | 관객이 답할 질문 | 화면 행동 |
|---|---|---|
| 0–12초 | 화장품의 인기가 투자와 어떻게 연결되는가? | 익숙한 제품에서 기업의 활동으로 짧게 시야 확대 |
| 12–45초 | 뷰티 산업에는 어떤 역할의 기업이 있는가? | 브랜드·제조·유통을 같은 공간에서 나눔 |
| 45–78초 | ETF는 무엇을 묶는가? | 여러 기업을 담는 구조. 상품 확정 이후 정확한 구성 반영 |
| 78–115초 | 비슷한 뷰티 ETF는 무엇이 다른가? | 동일 기준의 비교 화면. 데이터 읽기 시간 확보 |
| 115–155초 | 테마가 좋아 보여도 왜 손실이 가능한가? | 집중도·가격·실적·공통 위험의 관계 |
| 155–175초 | 투자 전에 무엇을 확인할 것인가? | 지수·구성·비용·거래 특성의 핵심 기준 |
| 175–180초 | 이 설명에서 무엇을 기억할 것인가? | 최초 제품과 전체 산업 구조로 돌아가 한 문장 |

시간 설계는 제출 영상의 확정 대본이 아니다. 최종 ETF가 선택되지 않았으므로 상품명·비중·보수·성과 수치는 넣지 않았다. 채널 분석이 제시하는 화법·자막 규칙을 합친 뒤 180초 대본과 내레이션 실측으로 확정한다.
