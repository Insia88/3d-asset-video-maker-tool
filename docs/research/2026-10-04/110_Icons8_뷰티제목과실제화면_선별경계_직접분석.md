# Icons8 3D Hygge: 뷰티 제목과 실제 화면의 선별 경계

[공식 3D Hygge 컬렉션](<https://icons8.com/illustrations/style--3d-hygge>)에서 가구·화장품 바구니·선물 상자 후보 7개를 좁혀 정상 보존된 전체 미리보기 5개를 한 검토판에서 직접 관찰했다. **추가 선정은 0개**이다. 같은 열린 상자와 내용물의 시점/리본 변형 1개는 대표 관계로 보존하고 나머지 4개는 사진형/평면 혼합 경계 또는 현재 귀여운 조형 우선순위로 제외한다.

쇼핑 바구니의 원작 제목에는 cosmetics가 있지만 실제 화면은 큰 스마트폰 화면, 헤드폰, 목 베개와 인쇄 패키지다. 제목과 태그로 제품 정체나 전체 순수3D를 확정하지 않는다. 선물 상자도 상자의 부피만큼 큰 인쇄 카드/패널이 화면의 주 정보여서 이번 목표에서는 제외했다.

[원작](<https://icons8.com/illustrations/illustration/3d-hygge-coffee-table-and-chair-1>)

- 제외 근거: 공식 3D 분류는 확인했으나 물리 목재 가구 촬영/현실적 렌더의 경계가 남고 귀여운 독립 조형 우선순위가 낮다.

## 출처와 관찰 범위

화장품 바구니와 열린 상자 두 원작의 개별 상세 페이지에서 제작자 Icons 8과 3D Hygge 분류, PNG 제어를 직접 확인했다. 일반 가구 2개는 실제 목록 링크와 미리보기를 관찰했고 개별 제작자/형식은 미확인으로 남긴다. 네이티브 보존에 실패한 소파와 닫힌 빨강 선물 상자 2개는 픽셀 관찰 완료에 포함하지 않으며 대체 다운로드로 우회하지 않았다. 공개 홈 목록 46개 및 스타일의 409 마케팅 숫자는 발견 정보일 뿐 이번 완료 수량이 아니다.

공식 스타일 분류와 실제 픽셀에서 보이는 깊이/재료, 개별 AI 제작 증거를 구분한다. 개별 생성 모델·툴·편집 가능한 3D 메시·움직임은 미확인이며 실제 생성 실행은 0이다.
