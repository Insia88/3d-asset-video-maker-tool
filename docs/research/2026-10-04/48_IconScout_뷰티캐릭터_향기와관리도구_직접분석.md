# IconScout 뷰티 캐릭터·향기·관리 도구의 입체 구성

공식 Beauty 3D Icons 검색에서 새로 확인한 실제 미리보기 76장을 직접 개별 관찰하고 8장을 선정했다. 기본 조형이 겹치는 색·자세·작은 소품 변형 62장은 대표 원작으로 묶었고, 현재 뷰티·귀여운 미감의 우선순위가 낮은 6장은 제외했다. 팩 표지는 집계하지 않았으며 여러 도구가 함께 있는 이미지도 한 장이 한 단위다.

선정 원작 8개는 개별 공개 페이지의 제작자와 3D 파일 제공 형식 문구를 직접 확인했다. 이 자료는 공식 3D 디자인 에셋 미리보기이며 원작의 AI 제작/특정 모델은 미확인이다. 사이트의 AI 편집·생성 버튼을 원작 제작의 증거로 사용하지 않았다. 제공 형식 표기는 실제 메시 파일을 열어 검증한 결과와 구분한다.

## 뷰티 세계를 만드는 구성

- 큰 눈의 작은 패션 인형은 사람을 촬영하지 않고도 뷰티 세계의 사용자를 보여 주는 캐릭터 참고다. 원작에서 실제 인물/특정 유명인을 확인하지 않았다.
- 원통 브러시·속눈썹 도구·둥근 마사지 도구는 헤드/판/손잡이의 구조가 서로 달라 독립적인 제품 범주를 읽히게 한다. 가는 털과 힌지의 실제 움직임은 미관찰이다.
- 낮고 넓은 향수 몸통과 긴 목의 둥근 플라스크는 단순 색/캡 변화보다 큰 몸통 비율 차이가 있다. 꽃과 내용물이 함께 있는 플라스크도 한 장 한 단위다.
- 두꺼운 상점 핀과 UV 해 부조는 제품/공간의 설명 기호다. 실제 점포 위치, 제품 차단 효과, 투자 성과의 증거로 해석하지 않는다.

## 관찰 범위와 출처

[공식 Beauty 3D Icons 검색](<https://iconscout.com/3d-icons/beauty?page=3>)과 각 항목의 원작 페이지를 이용했다. 실제 관찰물은 450×450의 공개 PNG/WebP 래스터 미리보기이며 전체 형태를 직접 보았다. 정지 이미지에서 카메라/움직임을 관찰했다고 주장하지 않는다. 카메라 제안과 금융·뷰티 적용은 분석자의 해석이다.

`references_visual_iconscout_search3.jsonl`에 원본 URL/ID, SHA256, 실제 이미지/보드, 제작자·형식 확인 수준, 선정·변형 제외를 보존했다. 기존 원본 ID/SHA가 일치한 네 후보는 준비 단계에서 제외했다. 새 76장 중 같은 기본 조형 변형 62장, 현재 미감 우선순위 제외 6장은 추가 집계하지 않았다. 하나의 대표가 선정되지 않았어도 변형을 새로운 단위로 만들지 않는다.
