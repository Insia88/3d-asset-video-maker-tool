# 작은 약방 — 개별 원작자와 입체 용기

[Witch Cottage Pack](<https://poly.pizza/bundle/Witch-cottage-pack-Nv92uZNma4>)의 실제 공개 렌더 **34개**를 보드 **3개**에서 모두 직접 관찰했다. 따뜻한 작은 공간과 용기에 사용할 독립 구조 **14개**를 선별했다. 돌·바닥·수련 잎/꽃의 기존/부분 구조 **4개**는 통합했고, 일반 도구·파손 연출·사진 같은 표면을 포함한 **16개**는 선택에서 제외했다. PP00354–PP00387에 기록했다.

이 묶음은 2x_Helix가 여러 작가의 모델을 모은 큐레이션이다. 묶음 작성자를 모든 모델의 원작자로 적지 않았다. 실제 공개 카드에서 Zoe XR, Jakers_H, Ming Chan, Don Carson, Hunter Paramore, mario tofani, Ginsta, Georg Bossenz, Vaporworks, Quaternius 등의 작성자 표기와 개별 라이선스를 확인했다. Poly by Google 항목은 아카이브 출처이며 개인 제작자까지 검증한 것으로 쓰지 않았다. 카드의 작성자명이 실제 현재 계정 운영이나 직접 업로드까지 증명하지는 않는다.

약방의 효과는 용기와 도구가 공간 속 관계로 읽힌다는 점이다. 독자 뷰티 장면에서는 하나의 용기를 중심에 놓고 같은 두께의 탁자·작은 책·화분을 배치할 수 있다. 원작의 마법 도구나 식물을 그대로 복제하는 대신 둥근 용기와 짧은 지지 다리, 밝은 소재 체계를 따로 설계한다.

검은 고양이 PP00355는 사진 같은 털/눈/수염 표면이 주가 되는 모델이라 최신 순수 3D 미감 후보에서 제외하고 hybrid 비교로 남겼다. 이 제작 경로를 사진측량으로 확정하지 않았다. 파손 창문·지팡이·낚싯대·일반 선착장·일반 자연 나무도 실제 관찰을 남기되 미감 선택에서는 제외했다. 바닥 PP00364와 기존 욕실 PP00050은 원본을 직접 대조해 같은 타일 바닥 기본 구조로 합쳤다.

전체 묶음 업데이트는 2024-03-01이며 개별 최초 공개일·제작 프로그램·생성AI 사용은 미검증이다. 라이선스는 CC-BY 3.0/CC0 혼합이므로 개별 원장에 따로 기록했다. 34개 중 22개는 정상 공개 UI 이미지 묶음으로 보관했고, 일반 MIME으로 반환된 나머지 12개는 UI에서 읽은 정확한 공개 원본 주소의 무인증 HTTP 200 응답과 실제 이미지 헤더를 확인해 조사 근거로 보관했다. 접근 제한이나 로그인을 우회하지 않았다.

근거는 `shots_plus_poly_pizza.jsonl`과 `evidence/3d_images/plus/poly_pizza/pp017/`의 원본/보드다. 이전 선택 682개와 SHA256·dHash·aHash를 교차해 낚싯대와 립 펜슬/작은 브러시의 후보 2쌍이 나왔고, 세 원본을 직접 대조하여 가는 세로 배치 때문에 생긴 오탐으로 판정했다. 이 재대조는 새 참고 수량에 넣지 않았다. API·키 생성·로그인·메시 다운로드·구매·새 생성은 0이다.
