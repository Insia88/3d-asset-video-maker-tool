# IconScout 작은 동물의 귀·주둥이·외곽 조형

공식 Cute Animal 3D Icons 검색에서 새로 확인한 실제 미리보기 69장을 직접 개별 관찰하고 21장을 선정했다. 기본 조형이 겹치는 색·자세·작은 소품 변형 48장은 대표 원작으로 묶었고, 현재 뷰티·귀여운 미감의 우선순위가 낮은 0장은 제외했다. 팩 표지는 집계하지 않았으며 여러 도구가 함께 있는 이미지도 한 장이 한 단위다.

선정 원작 21개는 개별 공개 페이지의 제작자와 3D 파일 제공 형식 문구를 직접 확인했다. 이 자료는 공식 3D 디자인 에셋 미리보기이며 원작의 AI 제작/특정 모델은 미확인이다. 사이트의 AI 편집·생성 버튼을 원작 제작의 증거로 사용하지 않았다. 제공 형식 표기는 실제 메시 파일을 열어 검증한 결과와 구분한다.

## 작은 동물의 실루엣

- 늘어진 귀·길고 두꺼운 귀·큰 둥근 귀와 주둥이는 작은 얼굴을 읽게 하는 서로 다른 외곽 구조다. 실제 메시를 열어 본 것이 아니라 공개 미리보기의 입체 외형을 직접 비교했다.
- 사슴의 가지뿔·사자의 방사형 갈기·고슴도치의 가시는 큰 얼굴/몸 바깥 실루엣을 만든다. 같은 얼굴의 색/표정·표면 줄무늬는 독립 조형으로 늘리지 않는다.
- 카멜레온은 두꺼운 가지/짧은 발/고리 꼬리로 작은 공간 관계를 만든다. 정지 미리보기의 혀 위치를 실제 움직임으로 기록하지 않는다.
- 털 동물의 머리 계열은 양 얼굴 한 장을 대표로 남겼다. 식품/동물 이름을 화장품 성분·효능으로 연결하지 않고, 뷰티 미니공간의 조형 적용을 분석자의 제안으로 구분한다.
