# Runway 공개 작품의 실제 관찰 원장

작품마다 표시한 실제 순서 표본을 직접 읽고, 같은 연속 장면과 반복을 수동 병합했다. 1fps 표본과 자동 컷 후보의 중간 대표+6초 맥락 표본을 구분한다. 구간은 근사값이며 실시간 전체 재생·오디오 청취를 뜻하지 않는다. 검정 화면, 단순 크레딧, 반복 후보는 완료 수에서 제외한다. 생성 모델과 실제 CG/합성 비율을 화면만으로 역추정하지 않는다.

Higgsfield 제작 제안: 원형 산업 세트의 동일 키 이미지로 시작해 제품의 이동·바구니 진입·공장 공개를 각각 한 동작의 I2V로 만들고, 모든 컷의 재질·광원·배경 축을 참조 이미지로 고정한다. 이는 관찰을 바탕으로 한 제작 제안이며 작품의 원래 생성 프롬프트를 복원한 것은 아니다.
