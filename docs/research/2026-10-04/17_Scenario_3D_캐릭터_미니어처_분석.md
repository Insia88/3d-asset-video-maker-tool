## 출처의 정확도

이 예시들의 생성형 모델 출처는 공식 Knowledge Base의 게시 사실에 근거한다. 개별 모델명 연결은 이미지 직전의 모델 항목으로 기록했고, 실제 실행 모델·프롬프트·파라미터·3D 메시 여부는 미확인이다. 분명한 입체 표현과 편집 가능한3D 자산은 같은 의미가 아니다. 모션과 뷰티/금융 적용은 분석자의 제안이다.

[Cutesy3D 소개](<https://www.scenario.com/models/cutesy-3d>)는 Flux.1 multi-LoRA·Deacon·둥근 장난감 캐릭터를 설명하지만 해당 소개의 시각은 모델 제목 포스터라 목표 집계0이다. Use it가 연 비로그인 앱에서는 전체 Explore가 가입 모달로 제한된다. 제한된 갤러리/프로젝트 생성/자동 모델 생성은 실행하지 않았다.

## 공식 Sketch-to-Render 추가 예시

[공식 제작 문서](<https://help.scenario.com/articles/4604382336-sketch-to-render>)의 실제 최종 렌더 예시 두 장을 추가 직접 관찰했다. UI 보드/비교 보드는 한 장 한 단위이며 입력 썸네일이나 비교 패널을 추가로 세지 않는다. 따라서 Scenario 전체 직접 원본 관찰은 15장, 선정 3D는 13장이다.

### SCX004-I001 — Cutesy 3D / Enhance 예시

흰 배경의 큰 머리 소년이 보라색 뿔 달린 봉제 괴물의 어깨를 감싸고 서 있다. 소년의 큰 검은 눈·통통한 볼·파란 잠옷·작은 슬리퍼와 괴물의 베이지 배·파란 눈테·분홍 코·작은 발톱이 분리된다. 화면은 Enhance 결과를 보여주는 공식 UI 예시이며 좌측 작은 입력 이미지와 주 이미지는 한 보드로 취급한다.

연한 파스텔 의상과 보라 인형, 큰 눈과 짧은 팔다리가 귀여운 동반 캐릭터를 만든다. 매끈한 얼굴과 봉제 털의 대비가 작은 이미지에서도 읽힌다. 뷰티 세계의 진행 캐릭터가 작은 제품/원료 캐릭터와 함께 설명하는 한 장의 시작 이미지 문법.

Higgsfield 적용: 두 주체를 함께 고정하고 한 번의 눈 깜박임/작은 고개 끄덕임만 적용. 팔 접촉·뿔·발 수는 별도 시트에서 고정.

출처 정확도: 공식 문서는 Cutesy 3D, Flux LoRA+ControlNet Sketch, Enhance 3D Rendered/Balanced/4x 흐름을 설명한다. 원본 화면에 해당 Enhance 옵션이 보인다. 개별 실행 로그는 미확인.

### SCX009-I001 — Sketch-to-Render Cat Boy 비교 보드

왼쪽 흑백 선화와 오른쪽 세 가지 입체 렌더 결과가 같은 고양이 소년 자세를 나란히 보여준다. 붉은 고양이 귀 후드·갈색 상의·회색 바지·두꺼운 빨간 운동화·주황 줄무늬 꼬리·큰 초록 눈을 공통으로 유지하며 얼굴·옷의 표면 질감과 음영이 조금씩 다르다. 보드 전체를 한 이미지 한 단위로 집계한다.

큰 초록 눈과 둥근 볼, 고양이 귀·굵은 꼬리·두꺼운 신발이 귀여운 비례를 만든다. 따뜻한 바탕과 붉은 후드가 전체 캐릭터를 하나의 색군으로 묶는다. 사용자 캐릭터의 양갈래/선글라스/진주를 시트와 렌더 버전 사이에서 유지하는 비교 보드 문법.

Higgsfield 적용: 영상 시작 이미지는 보드에서 한 결과를 따로 고정해 사용. 보드 전체를 움직여 여러 캐릭터가 동시에 변형되지 않도록 한다.

출처 정확도: 공식 Sketch-to-Render 문서의 Cat Boy 비교 예시. 보드의 개별 세 렌더가 어느 실행 모델/파라미터인지 화면상 확정할 수 없어 미확인.
