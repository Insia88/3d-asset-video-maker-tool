# Tiny Treats — 둥근 용기와 작은 가구

[Charming Kitchen Set](<https://poly.pizza/bundle/Charming-Kitchen-set-DsYQKb1K4M>)의 공개 카드 55개 중 구조 후보 **32개만 선별하여 보드 3개에서 실제 렌더를 모두 직접 관찰**했다. 둥근 용기·작은 가구·완구 소품의 새 기본형 **14개**를 추가했다. 색·길이·코너·기존 소품/내용물/분리 부품 **13개**는 대표 통합했고 일반 도구/설비/판 **5개**는 선택에서 제외했다. PP00388–PP00419에 기록했고, 다른 23개 모델은 관찰 완료 수에 포함하지 않았다.

| 구조 계열 | 대표 ID | 직접 관찰과 적용 규칙 |
|---|---|---|
| 둥근 열린 용기 | PP00389, PP00394 | 굵은 다각형 손잡이의 머그, 두꺼운 흰 냄비와 짧은 두 손잡이. 머그 색상 3개와 냄비 뚜껑 분리 부품은 추가하지 않음. |

이 표본은 생활 소품을 짧고 두껍게 정리해 같은 입체 세계에 맞추는 참고다. 뷰티 매장의 제품 진열/작업 공간을 설계할 때 도구를 새로 많이 넣기보다, 용기의 손잡이와 작은 선반 두께, 기기의 둥근 모서리를 같은 기준으로 유지할 수 있다. 원작의 색을 바꾸는 복제 대신 자체 용기와 가구의 비례를 설계한다. 식기/기기를 화장품 성분이나 효능으로 해석하지 않았다.

[공식 작가 사이트](<https://www.isalousberg.com/game-assets/>)가 연결한 [Tiny Treats 원작 페이지](<https://tinytreats.itch.io/charming-kitchen>)는 OBJ/FBX/GLTF·gradient atlas·.blend 소스를 안내하고 생성AI 미사용을 표시한다. 이는 관련 제작자 팩의 공개 주장 확인이며 개별 라이브러리 모델의 버전 일치나 실제 소스/제작 과정 검사가 아니다. 공식 팩의 CC0와 라이브러리의 CC-BY 3.0/CC0 혼합 표시는 다르므로 둘 다 보존했다. 실제 사용권을 새로 판정하거나 라이브러리 표시를 덮어쓰지 않았다. Poly 묶음 업데이트는 2025-04-13, 개별 최초 공개일은 미검증이다.

근거는 `shots_plus_poly_pizza.jsonl`과 `evidence/3d_images/plus/poly_pizza/pp018/`의 원본 32개/보드 3개다. 기존 욕실 선반·컵·세면대 원본도 대조해 표면 변경과 새 조립을 구분했다. API·로그인·키 생성·메시 다운로드·구매·새 이미지/영상 생성은 0이다.

## 원본 교차 확인

기존 선별 696개와 새 원본 32개의 SHA·dHash·aHash를 비교하여 7개 쌍이 후보로 나왔다. 후보의 실제 원본 쌍을 2개 비교 보드에서 직접 관찰했고 모두 서로 다른 구조였다. 숟가락과 향수/핀셋/동물, 도마와 코/브러시/가로등의 단순 배치 유사성 때문에 검출된 경우였다. 해시만으로 중복을 제거하지 않았다. 기존 욕실 선반·컵·세면대 원본도 직접 비교하여 선반과 컵은 대표로 통합하고 다른 사각 싱크 구조는 유지했다.
