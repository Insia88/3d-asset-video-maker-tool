# 모발 다발의 단면과 깊은 개구부

[PICS의 Pantene 개별 원작](<https://cgipics.co.uk/work/pantene/>)에서 정지 원본 10개와 4초 모발 개발 영상의 실제 PTS 표본 8개를 직접 관찰했다. 세로로 꼬인 모발과 큰 방울의 접촉, 관 다발의 열린 단면, 깊은 깔때기 개발 렌더를 전체 대표 3개로 선정했다. 기존 기본형·부분 비교 6개는 통합하고, 원환의 제작 층이 불분명한 한 장과 큰 평면 주석이 들어간 한 장은 제외했다. 영상의 연속 표본 수를 완료 수로 합치지 않았다.

## 개별 제작 공시와 관찰 범위

원문은 PICS와 Grey London이 Pantene Pro-V를 위해 제품과 모발을 개발하고, Houdini로 사실적인 모발 시뮬레이션을 만들었다고 설명한다. 촬영처럼 보이는 모발 표현은 저자의 CGI 제작 의도이며 실제 촬영이라고 해석하지 않는다. 관찰은 각 외피의 두께·단면·깊이·가림과 광원 정합을 다룬다. 실제 `.hip` 프로젝트나 편집 메시, Houdini 실행·물리 엔진·AI 모델/프롬프트는 확인하지 않았다.

광고의 영양 공급·손상 개선·윤기/강도 설명은 임상·생물 구조의 검증 자료가 아니다. 업로드 경로나 사이트 footer 연도로 개별 최초 공개일을 추정하지 않았으며 공개일은 미확인이다. 여러 Vimeo 플레이어는 발견만 했고 이번 영상 관찰 수는 0이다. 같은 네이티브 모발 영상이 두 DOM 노드에 있어도 원본은 한 번만 기록했다.

CG1806 원본은 1920×1080, 25fps, 4.0초다. 실제 decoder PTS 0.00·0.52·1.04·1.56·2.08·2.60·3.12·3.64초의 전체 표본 8개를 관찰했다. 금발 가닥의 넓은 파동과 작은 이동이 연속되며, 독립적인 새 지지·세계 구조는 확인되지 않는다. CG1584-S54의 긴 물결 모발 대표에 질감·근접/움직임 비교로 통합했다. 실제 전 프레임이나 실시간 재생·음향을 확인한 것은 아니며, 표본 사이의 정확한 컷 부재를 단정하지 않는다.
