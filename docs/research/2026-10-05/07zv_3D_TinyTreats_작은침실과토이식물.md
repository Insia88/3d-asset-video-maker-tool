# Tiny Treats: 따뜻한 작은 침실과 토이 식물

공개 원작 미리보기에서 침실 7장, Poly Pizza에서 식물/용기 후보 15개를 직접 관찰했다. 침실은 1개 독립 공간, 식물과 용기는 5개 독립 기본형을 선별했다. 방의 색·가구 펼침과 벽 부품 시트는 같은 공간으로 통합했고, 식물의 색·크기·쌓기·기존 다육/뾰족 잎 구조도 새 수량에 합치지 않았다.

## 작은 침실: CG1399

[작가 공식 포트폴리오](<https://www.isalousberg.com/game-assets/>)가 연결하는 [Playful Bedroom 공개 페이지](<https://tinytreats.itch.io/playful-bedroom>)의 실제 미리보기 7장을 2개 보드에서 확인했다. 파랑·분홍·초록 방은 같은 물체와 배치이므로 한 대표다. 가구와 장난감을 펼친 비교 시트는 내부 소품을 따로 세지 않았다. 모듈 벽체의 화살표 설명 도판은 완성 순수 3D 참조 집계에서 제외했다.

대표 CG1399-S03에는 파란 벽 두 면, 두꺼운 갈색 바닥, 짧은 침대와 봉제 곰, 작은 서랍, 책상·컴퓨터·둥근 의자, 블록·공·돼지저금통이 있다. 작은 디테일보다 낮고 넓은 가구와 둥근 손잡이가 먼저 읽힌다. 독자적인 뷰티 매장/화장대 디오라마에서는 이 비율과 물체 간 간격을 차용할 수 있다.

원작자는 low-poly 3D, gradient atlas, OBJ·FBX·GLTF와 Blender 소스를 설명하며 생성 AI 미사용을 표시한다. 공개 미리보기만 관찰했고 유료 메시 파일은 열지 않았다. 원문의 CC0와 유료 다운로드 표기를 보존했으며 실제 사용권의 범위를 새로 판정한 것은 아니다. 게시 최초일·렌즈·애니메이션·BPM은 미검증이다. 이전 선별 716개와 새 미리보기 7개의 SHA·dHash·aHash 교차 비교에서는 후보가 없었다. 해시는 구조 관찰을 대체하지 않는다.

## 토이 식물과 작은 용기: PP00452–PP00466

[공개 House Plants 묶음](<https://poly.pizza/bundle/House-Plants-set-Kpj32c7VmF>)의 구조 후보 15개를 2개 보드에서 관찰했다. 묶음 113개 중 나머지 98개는 관찰 완료 수 0이다. [원작자 House Plants 원문](<https://tinytreats.itch.io/house-plants>)은 3D·교환 파일 형식·gradient atlas·Blender 소스·AI 미사용·CC0를 표시한다. 설명에 쓰인 식물/화분 스타일 총수는 실제 선별 수로 사용하지 않았다.

| 대표 | 실제 구조 | 차용 규칙 |
|---|---|---|
| PP00452 | 짧은 원통과 굵은 위 손잡이·짧은 사선 주둥이 | 가는 손잡이보다 몸체와 일체처럼 읽히는 큰 토이 비율 |
| PP00453 | 두 줄기 끝의 굵은 별 모양 잎 묶음 | 복잡한 자연 잎 대신 최소 덩어리로 식물 실루엣 구성 |
| PP00460 | 굵게 말린 입구와 짧은 다면체 화분 | 크림 용기의 두꺼운 입구와 짧은 몸체 구조 참고 |
| PP00462 | 얇은 입구에서 아래로 좁아지는 흰 용기 | 최소 윤곽으로 다른 용기 구조를 구분 |
| PP00466 | 낮은 흰 그릇과 둥근 기둥·구슬 마디 선인장 | 가시를 과장하지 않는 작은 토이 정원 조형 |

기존 다육 PP00075, 뾰족 잎 PP00243, 가지 선인장 PP00239의 원본을 직접 대조했다. 새 다육 조합과 뾰족 잎은 이전 기본형으로 합쳤다. 선인장 묶음은 가늘고 뾰족한 가지보다 구슬·기둥 덩어리가 모인 다른 구조라 유지했다. 화분 색·크기와 쌓기는 대표 하나로 통합했다. 가는 단독 가지·덩굴·잎과 일반 모종삽은 미감 우선 후보에서 제외했다.

관찰 기록은 `shots_plus_3d_images.jsonl`과 `shots_plus_poly_pizza.jsonl`, 근거는 `evidence/3d_images/plus/CG1399/`와 `poly_pizza/pp020/`에 연결되어 있다. 생성 AI 확인 자료와 전통 CG 비교 자료를 분리하고 있으며, 생성 작업은 수행하지 않았다.

식물 원본 15개와 이전 선별 717개를 해시 교차 비교한 후보 4쌍도 실제 원본 쌍 비교 보드에서 직접 관찰했다. 식물/면봉·브러시·가로등, 화분 쌓기/단일 컵은 서로 다른 구조였고 모두 해시 오검출로 기록했다.
