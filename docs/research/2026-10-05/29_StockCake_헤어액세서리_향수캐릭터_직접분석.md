# StockCake — 헤어 액세서리·향수 캐릭터

[StockCake 공식 공개 MCP 안내](<https://stockcake.com/info/mcp>)의 read-only 검색으로 clay hair clip / clay eyeshadow / clay powder puff / perfume character를 확인했다. 주제별 공개 페이지1–5, 페이지당12개 제한을 지켰다. 같은 원본 ID는 준비 단계에서 하나로 묶었다. 원본 이미지를 직접 관찰한 뒤 명확한 순수 core3D 조형/디오라마와 미감·귀여움을 기준으로 선정한다. 사진/평면 혼합형은 비교 기록만 남기고 선정 수량에서 제외한다.

현재 고유 후보 3개 중 **실제 개별 관찰 3개, 3D 선정 1개, 제외 2개**다. 남은 0개는 미관찰이며 집계하지 않는다. 이미지 한 장은 한 단위이며 캐릭터 수/패널 수로 늘리지 않는다.
