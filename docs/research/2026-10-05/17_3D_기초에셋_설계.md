# 뷰티 ETF 영상의 3D 기초 에셋

작은 화장대에서 시작해 제품을 만드는 기업과 여러 기업을 담는 ETF 바스켓으로 공간을 넓힌다. 귀여운 캐릭터는 질문과 장면 연결을 맡고, 설명의 중심은 제품·기업·바스켓의 관계다. 3분 전체에 동일한 캐릭터·제품·공간을 재사용한다.

## 공통 시각 규칙

큰 기본 도형, 둥근 모서리, 작은 생활 소품을 사용한다. 제품과 캐릭터의 바닥 접촉 그림자를 유지하고, 한쪽 뒤에서 들어오는 따뜻한 빛으로 같은 공간에 묶는다. 캐릭터의 무광 크림 재질, 제품의 보라·민트 유리, 바스켓의 투명 유리는 역할이 다르다. 반짝임은 제품과 바스켓에 집중하고 모든 물체를 같은 유광으로 만들지 않는다.

크림 `#F5EBDD`, 라벤더 `#B9A1DA`, 민트 `#A7CDBE`, 살구 `#EEB4A2`, 원목 `#9B6D4D`를 기본색으로 쓴다. 어두운 선글라스는 `#292335`로 고정한다. 이는 제작 제안이며 PLUS 공식 브랜드 색상 분석과 구분한다. 공식 로고·브랜드 자막은 검증한 원본을 후반 편집에서 적용한다.

주요 장면은 세로 9:16로 설계하며 캐릭터·핵심 제품·바스켓을 화면 중앙에 둔다. 상단과 하단은 자막에 쓸 여백으로 남긴다. 이미지에 기업명·수익률·상품명·한글 설명을 생성하지 않는다. ETF의 실제 구성과 비용은 별도 1차 자료 검증 후 편집에서 표시한다.

## 움직임으로 옮길 순서

캐릭터 외형과 제품 실루엣을 먼저 고정한 뒤 같은 공간의 단일 마스터 컷을 만든다. 그 컷을 I2V 입력으로 사용하고 한 번에 하나의 동작을 지정한다. 예를 들어 마스코트가 스패출러를 천천히 들거나, 카메라가 화장대에서 바스켓 쪽으로 짧게 이동하는 식이다. 새로운 제품·배경·인물을 영상 프롬프트에서 추가하지 않는다.

빠른 느낌은 캐릭터가 매 순간 복잡한 행동을 하는 것으로 만들지 않는다. 짧은 카메라 이동, 제품 근접→세트 전체의 크기 전환, 모양이 이어지는 컷 연결, 후반 자막의 정확한 타이밍으로 구성한다. 설명을 읽는 순간에는 카메라를 안정시킨다.

## 힉스필드 MCP 세팅에 필요한 결과

3D 이미지 참고 수집이 완료된 뒤 마스터 이미지를 생성하고 원본 해상도·모델·프롬프트·미디어 ID·SHA-256·비율을 에셋 원장에 기록한다. 실제 이미지 결과를 열어 캐릭터의 모자·안경·손·신발·제품 수·바스켓 내부가 일치하는지 확인한 후 재사용본으로 잠근다.

먼저 단일 캐릭터 BE-M01을 만들고 실제 완성 이미지에서 캐릭터 Element를 등록한다. 이후 각도·표정과 캐릭터가 등장하는 공간은 같은 Element를 입력으로 파생한다. 여러 각도 보드를 첫 캐릭터 입력으로 사용하지 않는다. 제품과 화장대도 검증한 마스터 이미지를 기준으로 별도 재사용 Element에 등록하며 실제 상태가 완료인 항목만 사용한다.

생성 시점에 공식 모델의 참조 Element 지원·세로 비율·이미지 참조 역할을 다시 확인한다. 연결 계정의 폴더·이미지 작업 ID·Element ID는 성공 응답에서 얻은 실제 값을 사용하고, 독립된 제품·바스켓 작업만 묶어서 생성한다. 같은 공간의 탑뷰는 BE-M04 이후 그 마스터에서 파생한다. 비용 확인과 재사용 Element 등록은 작업의 선후 관계를 따라 진행하며 생성 성공 전에는 에셋이 준비됐다고 표현하지 않는다.

이와 별도로 편집 가능한 기초 공간은 3D Jutsu에서 가구·제품 단상·바스켓·기업 블록을 분리된 오브젝트로 구성할 수 있다. 이미지의 3D 시각 스타일과 실제 편집 가능한 3D 모델은 구분한다. 완성된 장면은 커밋된 리비전을 확인하고 3D 뷰어로 전달한다.
