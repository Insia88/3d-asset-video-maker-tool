# Animal Kit — 순수 3D 확인과 미감 선택 보류

[madtrollstudio의 Animal Kit](<https://poly.pizza/bundle/Animal-Kit-J1PqAonfYb>) 실제 공개 렌더 **25개**를 보드 **3개**에서 모두 직접 관찰했다. 모델의 입체 볼륨은 확인했지만 최신 요청의 귀엽고 뽀짝한 뷰티 미감에 맞는 새 구조는 **0개**로 선별했다. PP00329–PP00353에 실제 관찰 사실과 선택 보류 이유를 남겼으며, 라이브러리의 25개 모델 표시를 완료 선택 수량으로 바꾸지 않았다.

새·개·토끼·말·사슴은 대체로 길쭉한 몸과 작고 보통 크기의 머리, 길고 가는 다리를 가진다. 곰·들소는 몸이 두껍지만 어두운 표면과 일반 동물 비례가 강하다. 상어와 새 날개는 날카로운 지느러미/깃털 구조가 분명하고, 개구리도 긴 관절 다리의 일반 해부 구조에 가깝다. 코기의 발이 짧아도 전체 몸/얼굴 구조가 일반 동물에 가까워 큰 머리·짧은 몸의 안내자로 자동 선택하지 않았다.

원작자는 Blender 제작과 별도 텍스처를 명시한다. 이것은 실제 3D 제작 근거의 공개 주장이며, 소스·메시·텍스처 파일 검사는 아니다. 생성AI 사용 여부는 미검증이다. 묶음 업데이트는 2024-03-12, 공개 라이선스는 CC-BY 3.0이다. 일반 3D 동물을 귀여운 조형으로 일괄 분류하지 않고 실제 이미지에서 비례와 재질을 판정했다.

근거는 `shots_plus_poly_pizza.jsonl`과 `evidence/3d_images/plus/poly_pizza/pp016/`의 실제 원본·보드다. 모두 선택 보류이므로 새 선택 수량에 추가하지 않았고, 추가 영상 재생·메시 다운로드·API·로그인·구매·생성도 수행하지 않았다.
