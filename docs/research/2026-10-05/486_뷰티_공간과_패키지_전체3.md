## 중복 검수와 실제 관찰 범위

공식 마스터 32,009행의 출처 URL·원본 이미지 URL·파일 SHA를 후보 55개와 다시 대조했고 일치는 0이었다. 55개 원본의 SHA·이미지 규격을 다시 검증하고, RGBA 바이트에 너비·높이를 붙인 SHA도 고정했다. 선행 RGBA 값이 있는 자료는 일치를 검사했으며 나머지 11개는 최종 기술 검증에서 처음 계산했다. 기술 해시 계산은 추가 관찰 수가 아니다.

기존 비교 자료는 실제 연 29개 파일이다. 기존 전체 참고 이미지 25개와 기존 영상의 단일 디코더 프레임 4개를 구분했다. 비교판 7장과 기록된 개별 이미지 열람을 사용했다. 첫 프레임만으로 구조가 불명확했던 기존 영상 2개는 별도 sequence 판 2장·총 19개 PTS 표본을 직접 확인했다. CG1780은 0~5.5초 12표본, CG1794는 0~3초 7표본에 한정하며 전체 영상의 연속 재생·음성 확인이 아니다. 기존 프레임은 새 참고 수에 추가하지 않았다.

dHash 탐색은 공식 집계에 적격인 기존 정지 이미지 캐시 8,675개의 부분집합에 한정된다. 검색 후보·준비판 수를 관찰 수로 대체하지 않았다. 기존 10,123개 전체 픽셀·구성을 실제로 전수 대조했다는 보장은 하지 않는다. 의미상 판단은 실제 원본에서 본 큰 외피·지지·접촉·공간 관계의 대조 범위에 한정된다.
