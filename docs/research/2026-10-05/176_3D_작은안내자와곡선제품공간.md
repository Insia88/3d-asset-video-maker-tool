# 작은 포근한 안내자와 곡선 제품 공간 직접 분석

핀플루언서 지원용 약 3분짜리 뷰티 ETF 영상의 작은 안내자·제품 외피·기업 공간 관계를 설계하기 위한 실제 전체 이미지 관찰이다. 아래 적용은 제작 제안이며 금융 사실·제품 효능의 근거가 아니다.

고유 발견 73개에서 기존 출처 ID 23개·기존 원본 해시 3개를 제외하고 새 전체 이미지 47개를 8개 관찰판에서 모두 직접 봤다. 순수 3D 대표 8개를 선정했다. 제외는 우선순위 13개, 촬영·CG 경계 17개, 혼합 7개, 평면 2개다. 내부 인물·소품은 별도 단위로 세지 않는다.

## 원작과 판정 근거

[공식 공개 MCP 안내](<https://stockcake.com/info/mcp>)의 검색 결과에 type=3d를 요청했지만 실제 화면에서는 카지노·실사·평면 종이 구성이 다수 섞였다. 검색 표식을 완료 근거로 삼지 않았으며, 원본 해시를 대조하고 각각의 전체 화면을 관찰했다. 선정 8개는 공식 get_image에서 개별 AI 제작 주장 true를 확인했다. 생성 모델명·메시·리깅·다운로드 에셋은 확인하지 않았다.

기존 선정 이미지 5,053장의 작은 명암 해시를 이용해 각 선정 후보의 가까운 한 쌍을 준비했고 8쌍 전체를 두 관찰판에서 직접 비교했다. 주요 기본형과 공간 관계가 달라 8개를 유지했다. 이는 해시 이웃 검토이며 모든 의미 변형이 없음을 보장하지 않는다.

## 제작에 옮길 구조

- 두꺼운 곡선 아치와 여러 층 정원: 화장품 외피를 열면 기업 역할이 각각의 작은 공간으로 드러나는 전환에 적용한다. 실제 ETF 보유 기업과 비중은 별도 운용사 원문을 확인한 뒤 표시한다.
- 두 작은 인물의 손 접촉과 하나의 구름 받침: 여러 기업을 하나의 묶음으로 설명하는 관계에 적용한다. 종목 내부 개수는 화면 캐릭터 수로 확정하지 않는다.
- 작은 안내자가 큰 물체를 두 손으로 잡는 자세: 대표 제품 등장에 적용한다. 기타와 음악 무대는 비율·접촉 관계만 참고하고 뷰티 용기로 재설계한다.
- 둥근 목재 바닥·두 벽·작은 선반: 제품 설계와 판매 공간을 한 번에 보여 주는 미니어처 좌표로 사용한다. 정지 이미지의 움직임은 관찰하지 않았으므로 카메라 이동은 별도 제안이다.
