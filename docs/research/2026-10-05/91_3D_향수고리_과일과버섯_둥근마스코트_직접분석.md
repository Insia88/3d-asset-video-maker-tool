# 향수 고리·과일과 버섯·둥근 CG 마스코트의 실제 관찰

공식 공개 3D 검색 고유 후보 164개 중 기존 원본 ID·해시 중복 30개를 뺀 새 이미지 134개를 23개 관찰판에서 모두 직접 관찰했다. 순수 3D 74개 선정, 그 외 60개 제외다. 실제 정지 이미지 한 장을 한 단위로 기록했다.

## 제작에 옮길 구조

- 둥근 제품 마스코트는 큰 얼굴·짧은 팔다리·소수의 돌출 소품으로 기본 실루엣을 만든다. 같은 기본 몸에 색/표정/포즈를 바꾼 이미지는 하나의 대표로 합친다.
- 투명 과일/젤/향수 고리는 바깥 두께·안쪽 색·굴절 그림자를 분리한다. 제품 주변 전체 고리 배열과 한 조명 체계를 먼저 고정한 뒤 움직임을 설계한다.
- 버섯 집·작은 시장·곡면 전시 무대는 문/창/선반/길의 좌표가 읽히는 닫힌 입체 공간으로 만든다. 화면 속 집/과일/캐릭터를 각각 별도 참고 단위로 세지 않는다.
- 사진형 이끼/숲/주방에 CG 캐릭터를 올린 화면은 전체 순수 3D 수량에서 제외한다. 섬유 표현 자체만으로 제외하지 않고 비율·두께·접지·주변 공간의 일관성을 함께 확인한다.
- 과일/꽃/재료 조형은 제품 설명의 시각적 비유로 적용한다. 원본 미감에서 실제 효능·수익·ETF 구성/기업 관계를 추론하지 않는다.

새 원본 전체를 직접 관찰하고 평면 삽화·사진형 숲/제품/공예와 혼합 화면을 제외했다. 검색의 3D 표기를 실제 제작 방식의 증거로 쓰지 않고 화면의 깊이·두께·같은 재질/조명을 확인했다. 선정한 3D는 관찰한 시각 스타일이며 생성 모델·메시·리깅은 미확인이다. 정지 이미지에서 실제 움직임은 관찰하지 않았다.
