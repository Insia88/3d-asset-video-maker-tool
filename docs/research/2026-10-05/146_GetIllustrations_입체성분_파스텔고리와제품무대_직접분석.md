## 제품을 놓을 빈 공간이 먼저

GIA002는 큰 아치와 안쪽 구체/고리/반원의 수직 관계가 주체이고 GIA010은 큰 문/작은 문/낮은 사각 바닥이다. GIA028의 원형 오목 방, GIA059의 아치 통로/안쪽 세로 블록은 닫힌 외곽과 내부 자리의 연결이 다르다. 제품을 넣을 공간을 먼저 고정한 뒤 작은 성분 친구를 배치하는 구조로 옮길 수 있다. 해당 원작의 실제 공간 기능/움직임을 확인한 것은 아니다.

GIA036의 오목 받침·위/아래 토큰, GIA043의 높은/낮은 곡선 무대, GIA068의 높은 판/뒤 반원/위 원통은 서로 다른 높이와 접점을 제공한다. 같은 큰 받침에서 색·토큰 종류/위치만 바뀐 원작은 대표에 묶었다. 작은 제품/기업 칸의 우열이나 실제 비중을 원작의 높이에서 추론하지 않는다.

## 보송함과 크림의 부피

GIA047의 긴 끝을 가진 크림 방울, GIA018의 큰 타원/말린 작은 덩어리, GIA062의 조밀한 주름 링/부드러운 중심 덩어리는 제품 질감을 크게 보여주는 참고다. 실제 섬유/원료·유체 물성이나 원작 움직임은 미확인이다. 정지 외피와 반복 주름을 먼저 잠그고 이후 따뜻한 창가의 부드러운 명암을 시험한다.

GIA013의 고리를 관통하는 캡슐/낮은 받침, GIA037의 큰 컵/작은 손잡이·겹친 뚜껑, GIA014의 큰 몸/작은 구체/큰 반구는 귀여운 제품형 비례다. 눈을 억지로 추가하기보다 큰 제품과 작은 토큰의 크기 차이로 친근함을 만든다. 실제 원작에 창가·봉제 재료·따뜻한 역광이 있었다고 기록하지 않는다.

## 연결 조형과 금융 설명

영상 제안: GIA073의 위/아래 반원 외곽과 양옆 작은 고리 구조에 서로 다른 제품/기업 칸을 놓는다. 카메라가 물러나면 칸이 하나의 큰 바구니에 연결된 관계가 보인다. 제품→기업→ETF의 실제 편입 정보/비중은 별도 확인한 원문에 맞추며 이 원작은 해당 금융 관계를 증명하지 않는다. 이 고리/축을 실제 원료 흐름이나 메커니즘으로 주장하지 않는다.

## 대표 통합 기준

큰 아치 GIA012→002, 나선 GIA055→003, 컵 GIA061→037, 크림 방울 GIA066→047, 교차 고리 GIA051→033, 아치 통로 GIA076→059처럼 기본 외곽과 주 접점이 같은 색/무늬 변형은0이다. 부분 위치/작은 토큰 추가나 같은 큰 받침의 단면/방향 변경도 보수적으로 통합했다. 실제 메시 동일성을 확인한 것은 아니며 직접 관찰한 구성상의 대표화 판단이다.

## 상품 주장과 직접 확인 범위

공식 팩은 Human designers/원본 OBJ 포함과 PNG/Sketch/Figma/AdobeXD 제공을 설명한다. 개별 원작76개도 File types: XD,Sketch,Figma,PNG,OBJ를 표기한다. 이는 제작/상품 주장이다. 설명의 Cinema4D/Blender는 OBJ 호환 예시여서 실제 제작 소프트웨어 확인으로 기록하지 않는다. 개별 인간 작가 이름·AI 제작 모델/편집 이력은 미확인이고 별도 AI Studio/custom work 문구는 기존 원작 제작 증거로 쓰지 않는다.

공개 hero URL/저장 파일명 .png와 실제 인코딩을 구분했다.76개 실제 미리보기는 **WEBP RGB1200×1200**, 배경/워터마크 포함이다. 상품 PNG/OBJ·투명 alpha·편집 파일/네이티브 뷰어는 미확보/미검증이며 생성 실행0이다. 일반 홍보 SVG/PNG/AI와 개별 상품 형식도 분리했다.
