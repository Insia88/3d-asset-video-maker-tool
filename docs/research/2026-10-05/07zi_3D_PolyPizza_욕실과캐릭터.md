# Poly Pizza — 파스텔 욕실과 작은 캐릭터

공개 원작 묶음 두 개에서 실제 개별 렌더 **80개**를 **7개 보드**로 직접 관찰했다. 파스텔 욕실 기본형 20개와 귀여운 캐릭터 기본형 23개, 합계 **43개**를 추가했다. 색·크기·소품 조합·머리 확대/전신·진화 변형 31개와 미감 우선 기준에서 선택하지 않은 기본형 6개는 추가 수량에서 제외했다.

앞선 화장품 표본을 합치면 `shots_plus_poly_pizza.jsonl`에는 PP00001–PP00123, 실제 공개 렌더 123개 / 독립 순수 3D 기본형 77개가 기록되어 있다. 이 수는 라이브러리 전체 관찰 수가 아니며, 별도 제작자 원장이나 다른 에이전트 결과를 합친 전역 합계도 아니다.

## 파스텔 욕실

[Isa Lousberg의 Bubbly Bathroom Set](<https://poly.pizza/bundle/Bubbly-Bathroom-Set-eSvpFVB4Ft>)은 작고 편안한 욕실용 stylised low-poly 3D 원작이라고 설명한다. 제작자 본문은 OBJ/FBX/GLTF 지원과 single gradient atlas 1024×1024를 명시한다. Poly Pizza의 해당 제작자 프로필은 웹 아카이브 이관·비활성 안내가 있으므로 [공식 작가 사이트](<https://www.isalousberg.com/game-assets/>)가 연결한 [Tiny Treats 원작 페이지](<https://tinytreats.itch.io/bubbly-bathroom>)로 출처를 교차했다. 원작자는 생성AI 미사용과 .blend 소스 제공을 명시한다. 이는 제작자 주장 확인이며 실제 메시·텍스처 파일·제작 과정 검사 결과는 아니다. 묶음의 업데이트 날짜 2024-09-06은 확인했고, 개별 기본형 최초 공개일은 미검증이다.

실제 35개 렌더를 직접 관찰하여 PP00044–PP00078에 기록했다. 둥근 파스텔 펌프 병은 분홍·연청·노랑을 한 기본형으로, 칫솔의 분홍/청색을 한 기본형으로, 세 장 타월 스택과 그 안의 각 타월 확대를 한 기본형으로 통합했다. 같은 열린 컵에 기존 칫솔을 넣은 PP00074도 새로운 소품 기본형으로 추가하지 않았다.

| 선택 계열 | 대표 ID | 실제 관찰과 활용 규칙 |
|---|---|---|
| 용기·칫솔 | PP00045, PP00046, PP00059, PP00067, PP00070 | 둥근 칫솔, 짧고 두꺼운 펌프, 캡 병, 넓은 크림 통, 열린 컵. 색과 높이만 바뀐 같은 용기 계열은 통합. |
| 세면대·욕조 | PP00077, PP00078 | 청색 상판과 작은 노란 손잡이, 둥근 세면대 및 물/거품이 든 두꺼운 욕조. 부드러운 곡면과 작은 수도꼭지의 완구 비례. |

이 묶음은 뷰티 제품을 하나씩 놓는 데서 나아가 같은 세계를 만들기에 적합하다. 자체 무표기 화장품 가게를 설계할 때 펌프·크림 통·작은 선반과 둥근 식물을 같은 소재 규칙으로 구성할 수 있다. 공개 원작의 색만 교체한 복제물로 사용하는 대신 소품 비율과 조립 구조를 별도로 설계한다.

## 큰 얼굴의 캐릭터

[Quaternius의 Ultimate Monsters Bundle](<https://poly.pizza/bundle/Ultimate-Monsters-Bundle-5oyGWAmOB6>)은 FBX/glTF와 여러 애니메이션을 포함한다고 설명한다. 본문의 50 Monsters 주장과 모델 탭의 45 Models 표시는 실제 완료 수로 환산하지 않았다. 공개 화면에 개별 렌더로 표시된 45개 이미지를 모두 직접 관찰했고, 걷기·공격·표정 애니메이션은 재생/측정하지 않았다. 실제 공개 렌더는 709×418이며 일부는 머리 확대만 보인다.

캐릭터 기본형 23개를 선택했다. 작은 버섯 캐릭터는 머리 확대 PP00079와 전신 PP00116을 합쳤다. 선인장은 PP00087/PP00112, 외계인은 PP00088/PP00117, 청록 설인은 PP00090/PP00120, 청록 이빨 생물은 PP00092/PP00119를 각각 통합했다. 같은 기본 캐릭터의 가시·왕관·큰 입·진화 변형도 별도로 추가하지 않았다. 가면·악마·무기/적 캐릭터의 인상이 강한 여섯 기본형은 직접 본 사실을 남기고 미감 선택에서는 제외했다.

| 조형 원리 | 대표 ID | 화면에서 확인한 것 |
|---|---|---|
| 둥근 한 덩어리 | PP00080, PP00081 | 분홍 물방울과 울퉁불퉁 초록 볼륨, 튀어나온 큰 눈. 실제 머리/몸 구분 없이도 읽히는 단순 마스코트. |
| 동물의 큰 얼굴 | PP00084–PP00086, PP00093 | 삼각 귀 고양이, 둥근 비둘기, 작은 볏 닭, 넓은 부리 청색 새 머리. 이 이미지로 전신 비례를 확인했다고 쓰지 않음. |
| 작은 날개 구조 | PP00095–PP00097, PP00100, PP00101 | 작은 중심 몸과 양쪽으로 뻗는 날개, 벌의 줄무늬, 별 모자, 다른 용/잎 모양 실루엣. 같은 캐릭터의 진화 장식은 통합. |
| 큰 머리·짧은 몸 | PP00111, PP00112, PP00114–PP00117, PP00120, PP00123 | 개구리·선인장·원숭이·공룡·버섯·외계인·설인·토끼. 전신 렌더에서 작은 다리와 큰 얼굴이 직접 보임. |
| 추상 안내자 | PP00091, PP00106, PP00119 | 꼬부라진 모자, 큰 보라 머리와 두 팔, 청록 긴 얼굴 등 서로 다른 기본 실루엣. |

뷰티 ETF 영상에서는 귀여운 모양 하나를 선정한 뒤 표정과 소재 체계를 고정하는 것이 좋다. 장면마다 얼굴을 새로 만들면 설명자는 달라 보이고 자산 관리도 복잡해진다. 참고 수량에서도 같은 캐릭터의 표정·색·전신/머리 확대를 늘리지 않았다. 실제 생성 단계는 별도의 독자 마스코트 구조와 무표기 뷰티 소품으로 이어져야 한다.

## 근거와 접근

- `shots_plus_poly_pizza.jsonl`: 개별 렌더의 실제 관찰·선택·통합/미감 제외 이유.
- `evidence/3d_images/plus/poly_pizza/pp002/`: 욕실 35개 렌더와 직접 관찰한 3개 보드.
- `evidence/3d_images/plus/poly_pizza/pp003/`: 캐릭터 45개 렌더와 직접 관찰한 4개 보드.
- 각 `source_manifest.json`: 원작 묶음 URL, 실제 원본 렌더 URL, SHA256, 관찰 근거.

정상 공개 UI와 본문에 표시된 렌더만 사용했다. API 요청·API 키/앱 생성·로그인·메시 다운로드·구매·새 이미지 또는 영상 생성은 모두 0이다. CC0는 사이트와 제작자가 표시한 출처 주장으로 기록하며, 새 권리 동의나 모델 파일 검증을 수행했다고 주장하지 않는다.

이전 직접 관찰한 순수 3D 기본형들과 SHA256·dHash·aHash도 교차했다. 욕실 35개는 기존 549개와 후보 0이었다. 캐릭터 45개는 기존 569개와 후보 세 쌍이 나왔으나 원본을 모두 직접 대조해 중복이 아님을 확인했다. 같은 보라색 배경이 가면 캐릭터와 브러시, 원숭이와 향수 병의 해시를 비슷하게 만든 사례이므로 해시만으로 자동 제외하지 않았다.
