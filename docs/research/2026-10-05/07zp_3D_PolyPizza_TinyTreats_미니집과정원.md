# Tiny Treats — 작은 집과 둥근 정원

공개 렌더 **55개**를 보드 **6개**에서 모두 직접 관찰했다. 작은 집·정원에 사용할 새 기본 구조 **19개**를 선별했고, 모듈의 길이·방향·단수·색과 기존 소품 구조를 반복한 **34개**, 단순 바닥 모듈 **2개**는 새 수량에서 제외했다. PP00253–PP00307에 기록했다. 화장품 자체가 아니라 귀엽고 작은 입체 공간을 구성할 참고다.

[Isa Lousberg의 공식 사이트](<https://www.isalousberg.com/game-assets/>)가 연결한 [Homely House](<https://tinytreats.itch.io/homely-house>)와 [Pretty Park](<https://tinytreats.itch.io/pretty-park>) 원작 페이지는 CC0, OBJ/FBX/GLTF와 gradient atlas, .blend 소스를 안내하고 생성AI를 쓰지 않았다고 명시한다. 전통 CG 참고로 구분하되 이 사실은 제작자의 공개 주장 확인이며 실제 파일·제작 과정 검사 결과는 아니다. Poly Pizza의 해당 프로필은 웹 아카이브 이관·비활성 안내가 있어 원작자 사이트를 별도로 교차했다. 개별 최초 공개일은 미검증이고 Poly 묶음 업데이트는 둘 다 2024-09-06이다.

두 묶음의 장점은 곡면 두께와 색의 밝기를 같은 세계 안에서 유지한다는 점이다. 향후 독자 장면에서는 작은 매장을 중심에 놓고 같은 두께의 나무·꽃·안내자를 배치하면, 제품을 설명하는 공간과 캐릭터가 연결된다. 원본을 색만 바꿔 복제하는 대신 지붕과 용기의 비례, 꽃잎과 캐릭터 얼굴 구조를 새로 설계한다.

근거는 `shots_plus_poly_pizza.jsonl`과 `evidence/3d_images/plus/poly_pizza/pp013/`, `pp014/`의 실제 원본·보드다. 기존 매트 PP00051과 새 매트를 직접 대조해 얇은 둥근 매트의 외곽/무늬 변화로 통합했다. 작은 집 27개는 이전 선택 기본형 658개와 SHA256·dHash·aHash 교차에서 원본 중복 후보가 0이었다. 공원 28개는 이전 670개와 후보 16쌍이 나와 추가 좌우 대조 보드 3개에서 모두 직접 확인했다. 지면 블록과 원숭이/세면대/핀셋, 나무와 돼지/아이스크림, 가로등과 면봉/브러시는 실제 조형이 다르므로 모두 해시 오탐으로 판정했다. 이 대조의 재캡처·쌍·보드는 새 수량에 넣지 않았다. 해시는 모듈 변형 통합을 대신하지 않는다.

라이브러리 본문의 모델 수와 실제 완료 수는 구분했다. 모델 다운로드·로그인·구매·API·키 생성·새 이미지/영상 생성은 모두 0이다. CC0와 생성AI 미사용은 원작자 출처 주장으로 기록한다.

교차 묶음의 PP00303 새와 PP00068 욕실 오리는 원본 직접 대조에서 같은 조형으로 확인하여 대표 통합했다. 이 배경 변경 사례는 해시 후보에 잡히지 않았으므로, 해시 오탐 해소와 별개로 실제 조형 중복을 수동 점검했다. 집 12개와 공원 7개, 합계 19개가 최종 추가 수량이다.
