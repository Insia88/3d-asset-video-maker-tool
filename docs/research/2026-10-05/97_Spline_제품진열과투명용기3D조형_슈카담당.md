> 공개본에는 원본 이미지·영상과 로컬 관찰판을 포함하지 않는다. ‘로컬 관찰 근거’는 저장소에 재배포하지 않는 로컬 관찰 자료를 가리킨다. 공개 출처 링크와 관찰·제작 제안은 보존하며, 문서별 과거 수량보다 [프로젝트 감사 집계](<../../../data/projects/finfluencer-beauty-etf/audit.json>)와 [스냅샷 매니페스트](<../../../manifests/snapshot.json>)의 집계가 최신 기준이다.

# Spline 제품 진열과 투명 용기 3D 조형 관찰

SPC0025–SPC0040 공개 미리보기 **16장**의 전체 픽셀을 직접 관찰해 독립 순수 CG 스타일 전체 장면 **3개**를 선정했다. 기존 기본형 변형 **4개**, 사진/큰 평면 구성 혼합 **6개**, 전체 CG 스타일 또는 개별 출처 확인이 부족한 **3개**는 목표 수량에서 제외했다. 이 배치 저장 후 Spline 누적은 **40장 관찰·15개 선정**이다. 프로젝트 최신 합산은 [집계와 검증](<06_%EB%B9%84%EC%A3%BC%EC%96%BC_%EC%A7%91%EA%B3%84%EC%99%80_%EA%B2%80%EC%A6%9D.md>), 개별 판정은 [Spline 원장](<../../../data/projects/finfluencer-beauty-etf/references/index.json>), 앞 구간은 [작은 공간과 귀여운 조형](<93_Spline_%EC%9E%91%EC%9D%80%EA%B3%B5%EA%B0%84%EA%B3%BC%EA%B7%80%EC%97%AC%EC%9A%B43D%EC%A1%B0%ED%98%95_%EC%8A%88%EC%B9%B4%EB%8B%B4%EB%8B%B9.md>)에 연결한다.

## 원작·관찰·제작 표시의 구분

[공식 Community](<https://community.spline.design/>)의 정상 [cosmetic 검색](<https://community.spline.design/search?query=cosmetic&sort=trending>)과 공개 정렬 UI에서 실제 카드의 원작·작성자·미리보기 링크를 읽었다. 여러 정렬에서 반복되는 원작 URL을 먼저 통합한 뒤 신규 16장만 관찰했다. 제목·태그·검색 카드 총수·판 패널 수는 선정 수량을 대신하지 않는다.

| 확인 방식 | 범위 | 결과 |
|---|---|---|
| 실제 미리보기 전체 픽셀 | 16장 모두 구도·닫힌 체적·앞뒤 면·접합·그림자·전체 배경 | 실제 관찰16, 선정3 |
| 정상 개별 상세 | 작성자·제작 표시·iframe·현행 라이선스 | 15개 확인: Made in Spline14, Made in Hana1 |
| 개별 상세 접근 실패 | SPC0032 원작 링크가 Community 홈으로 이동 | 카드 실제 관찰은 보존, 제작/권리 미확인·선정0 |
| 실제 공개 렌더 | SPC0025 제품 코너·SPC0040 제품 작업 모듈 | 미리보기와 같은 씬, 추가 단위0 |
| 독립 원본 교차 관찰 | SPC0025·0027·0040 | 선정 근거 보강, 수량 증가0 |

SPC0035는 개별 페이지가 **Made in Hana** 및 `/ui/` iframe으로 표시했다. 갤러리가 Spline Community라는 이유로 모든 자료의 제작 표시를 Made in Spline로 통일하지 않았다. SPC0032는 정상 상세가 홈으로 이동해 현행 라이선스를 확인하지 못했으며 로그인/권한/우회 경로를 시도하지 않았다.

성공한15개 상세의 현재 **CC BY 4.0** 표시를 각 원장에 기록했다. 공개 표시 작성자와 모든 모델 부품의 법적 권리자 확인은 같지 않다. 미리보기 URL의 시각 문자열은 파일 URL 정보이며 정확한 작품 공개일로 변환하지 않았다. 개별 공개일은 `3 years ago`, `2 years ago`, `6 months ago`, `4 months ago`, `1 year ago`, `27 days ago` 등 실제 상대 표시만 기록했다. 생성형 AI 모델·리깅·원본 메시 취득은 모두 미확인이다.

SPC0025의 작가는 원통형 투영 텍스처와 Spline library의 두 모델 사용을 설명했다. 이는 개별 제작 설명으로 기록하며 모든 부품의 원저작자나 AI 모델을 확인했다는 뜻은 아니다. SPC0040 공개 렌더에는 주변 병·튜브·작은 선물도 보였지만 중심 모듈과 같은 무대의 소품이므로 별도 집계하지 않았다. 정지 관찰에서 동작 길이·속도·카메라 키프레임을 측정한 것으로 쓰지 않는다.

## 변형 통합과 비교 제외

- SPC0034는 **I8S0005** 스포이트 병, SPC0036은 **I8S0163** 닫힌 상자/뚜껑, SPC0037은 **I8S0017** 둥근 슬리브/사선 립스틱, SPC0039는 **SPC0027** 원통/두꺼운 뚜껑 대표로 통합했다. 다른 작가·색·라벨·재질·비례가 같은 기본 형태를 새 독립 단위로 만들지는 않는다. 동일 메시나 저작자 관계를 단정한 통합은 아니다.
- SPC0028·0029·0030·0033·0035·0038은 큰 평면 포스터/웹 UI·사진형 얼굴/꽃/구름 등의 층이 전체에 섞여 비교0이다. 입체 제품만 따로 추출해 수량을 추가하지 않았다.
- SPC0026의 커튼/식물, SPC0031의 거친 돌은 전체 순수 CG 스타일 확인을 보류했다. 제작 표기나 작가의 3D 표현만으로 사진형 미감을 선정하지 않는다.
- SPC0032는 실제 공개 카드 이미지를 관찰했지만 개별 상세 접근과 전체 CG 확인이 부족해0이다. SPC0033의 혼합 언급 댓글은 작성자 직접 설명과 구분했다.
- 원작의 브랜드·제품 라벨·성분 문구를 효능·브랜드 사업 정보의 근거로 사용하지 않는다. 원작 모델/코드·이미지는 공개 저장소에 복제하거나 재배포하지 않는다.
