# 3D 전용 연구 — 311LABS Substrates

0.5초 간격 프레임 순서를 직접 확인한 작품만 관찰 완료로 기록한다. 컷 경계는 표본 사이 추정이며, 추출기의 0.25초부터의 표기 시각은 관례적 2fps 중심값이다. 정확한 원본 PTS·음향·1초 미만 컷은 확인하지 않았다. 311LABS 공식 프로젝트의 제작 과정과 공개 자체 CDN MP4를 확인했다. Vimeo 일반 다운로드는 로그인 요구로 중단했으며, 인증 없이 공식 페이지에서 로드된 자체 CDN 영상은 별도 공개 출처로 정상 확보했다. 공개 Vimeo의 시각 앞뒤 확인 화면과 자체 CDN의 여러 장면도 교차 관찰했다. 정지 이미지 프로젝트와 같은 원본의 다른 플레이어는 고유 영상 샷으로 추가 집계하지 않는다. 3D 분류는 화면의 시각적 구조에 관한 판단이다. 같은 세트와 카메라에서 재료·인물·색만 교체한 연속 변화는 병합했고 반복 대화 구도·엔드카드는 집계에서 제외했다.
