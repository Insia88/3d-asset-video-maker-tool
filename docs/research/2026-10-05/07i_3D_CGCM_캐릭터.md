# CGCM STUDIO — 귀여운 3D 캐릭터·제품·미니어처 분석

검토일 2026-10-04. [CGCM STUDIO의 공개 원작 포트폴리오](<https://cgcm-studio.artstation.com>)를 정상 브라우저 화면에서 확인하고 83개 작품 페이지를 각각 열었다. 해당 페이지에서 노출된 정지 이미지453장을 38개의 식별자 보드로 전부 직접 관찰했다. 같은 디자인의 회전·크롭·색·표정·재질·복제 배열·제작 화면을 제외한 독립 3D 디자인/제품/디오라마84개를 채택하고369행을 제외했다. 발견한 링크 수·파일 수·관찰한 이미지 수·독립 참고단위 수는 서로 다르다.

## 범위와 1차 제작 근거

이 배치는 AI가 만들었다고 검증된 자료가 아니라 전통 CG 비교자료다. 제작자의 여러 작품 제목과 본문에 Blender 모델링·스컬프팅·텍스처·리깅·셰이딩·렌더링이 명시되고 실제 Blender 솔리드·와이어 화면을 함께 관찰했다. 제목만으로 물성·형태를 추정하지 않았으며, 본문이 비어 있는 작품은 해당 제목의 제작자 표기와 실제 입체 렌더/과정 이미지를 근거로 분리한다. 게시일은 검증하지 않았다. CDN URL의 숫자를 게시일로 환산하지 않는다.

[Lime Buddy](<https://cgcm-studio.artstation.com/projects/YGYaAP>)는 제작자 설명에서 Blender의 모델링·스컬프팅·텍스처·셰이딩을 명시한다. [Luxury Cosmetic Bottle](<https://cgcm-studio.artstation.com/projects/BkeX8z>)는 Blender로 제품을 모델링하고 재질·조명을 렌더했다고 설명한다. [Jake 튜토리얼](<https://cgcm-studio.artstation.com/projects/mA00z9>)은 Blender4.3 박스 모델링과 셰이딩을 설명한다. 연결된 YouTube 튜토리얼 재생은 이 정지 이미지 배치의 관찰 범위에 포함하지 않았다.

일부 작품 제목과 화면 디테일이 다르다. CG039의 Dipper 표기와 실제 모자 없는 붉은 스카프·축구공 소년, CG051의 Anya 표기와 실제 보라 단발·검정 원피스, CG064의 Teddy 표기와 실제 모자를 쓴 주황 콩 모양 몸, CG121의 Sonic 표기와 실제 노랑 몸은 각각 제목 메타와 화면 묘사를 따로 기록했다. 이 차이에서 공식 캐릭터/브랜드의 정확한 모습이나 공식 의뢰를 추정하지 않는다.

## Higgsfield 작업 규칙

아래 규칙은 정지 참고자료에서 도출한 제작 제안이다. 원작의 실제 카메라 움직임·컷 길이·BPM·초점거리를 측정한 결과가 아니다.

1. 형태를 먼저 잠근다. 한 캐릭터의 정면·측면·후면을 한 시트에 정리하고 몸·눈·캡·손잡이 위치를 확정한다.
2. 재질을3개 이내로 줄인다. 예를 들어 매트 몸, 유광 눈, 금속 캡으로만 시작하고 광택과 투명도를 동시에 크게 바꾸지 않는다.
3. 작은 동작 하나를 준다. 눈 깜빡임, 고개 기울임, 손 한 번, 병의 작은 회전 중 하나를 선택하고 몸 형태의 변형을 줄인다.
4. 금융 정보는 편집에서 올린다. 캐릭터는 질문·이동·리액션을 맡고 종목명·수치·비중·출처는 별도 그래픽으로 합성한다.
5. 캐릭터와 제품의 크기를 대비한다. 손바닥 위 컵이나 작은 로봇 옆 큰 병 같은 구조로 미니어처 스케일을 만든다.
6. 원작의 IP 대신 조형 원리를 쓴다. 팬아트의 얼굴·의상·로고를 그대로 복제하지 않고 큰 눈/짧은 몸/재질 대비 같은 독립 원리로 새로운 자산을 설계한다.
