# IconScout 캐릭터 몸통과 변형 제외

공식 Cute Character 3D Icons 검색에서 새로 확인한 실제 미리보기 80장을 직접 개별 관찰하고 2장을 선정했다. 기본 조형이 겹치는 색·자세·작은 소품 변형 77장은 대표 원작으로 묶었고, 현재 뷰티·귀여운 미감의 우선순위가 낮은 1장은 제외했다. 팩 표지는 집계하지 않았으며 여러 도구가 함께 있는 이미지도 한 장이 한 단위다.

선정 원작 2개는 개별 공개 페이지의 제작자와 3D 파일 제공 형식 문구를 직접 확인했다. 이 자료는 공식 3D 디자인 에셋 미리보기이며 원작의 AI 제작/특정 모델은 미확인이다. 사이트의 AI 편집·생성 버튼을 원작 제작의 증거로 사용하지 않았다. 제공 형식 표기는 실제 메시 파일을 열어 검증한 결과와 구분한다.

## 캐릭터를 대표화하는 기준

- 파란 눈/굵은 앞머리/짧은 코트의 인물은 기존 큰 안경 안내자·학교 인형과 다른 눈/머리/몸 비율의 조형이다. 원문 의료 역할은 실제 효능 근거와 구분한다.
- 꽃다발을 함께 든 두 인형은 따뜻한 분홍 의상과 짧은 몸의 관계 구성으로 남겼다. 한 장 안 인물 둘과 꽃 여러 송이는 한 참고 단위다.
- 학교 인형은 같은 큰 얼굴·짧은 몸/가방 구조를 유지하면서 머리/복장/칠판/공/지구/졸업모자만 바뀌어 기존 대표 6369155로 묶었다.
- 큰 안경 안내자의 파란/베이지 복장과 의료 캐릭터의 여러 손짓도 기본 몸통 변형으로 묶었다. 정지 카드의 눕기/달리기 자세를 실제 움직임 관찰로 기록하지 않는다.
