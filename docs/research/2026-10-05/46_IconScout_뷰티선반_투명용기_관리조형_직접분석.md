# IconScout 뷰티 선반·투명 용기·관리 조형

공식 Beauty 3D Icons 검색에서 새로 확인한 실제 미리보기 78장을 직접 개별 관찰하고 9장을 선정했다. 기본 조형이 겹치는 색·자세·작은 소품 변형 63장은 대표 원작으로 묶었고, 현재 뷰티·귀여운 미감의 우선순위가 낮은 6장은 제외했다. 팩 표지는 집계하지 않았으며 여러 도구가 함께 있는 이미지도 한 장이 한 단위다.

선정 원작 9개는 개별 공개 페이지의 제작자와 3D 파일 제공 형식 문구를 직접 확인했다. 이 자료는 공식 3D 디자인 에셋 미리보기이며 원작의 AI 제작/특정 모델은 미확인이다. 사이트의 AI 편집·생성 버튼을 원작 제작의 증거로 사용하지 않았다. 제공 형식 표기는 실제 메시 파일을 열어 검증한 결과와 구분한다.

## 뷰티 세계를 만드는 구성

- 노란 네일 선반은 작은 상품을 공간에 묶고, 컬러 휠은 다양한 품목을 원형 배열에 묶는다. 배열 속 물체 수를 참고 단위로 늘리지 않는다.
- 원반형 향수병, 아랫몸통이 넓은 립글로스는 병의 단면을 크게 달리해 일반 캡/색 변형과 구분된다.
- 두꺼운 도구 상자와 속눈썹 케이스는 얇은 내용물을 큰 닫힌 부피로 정리한다.
- 물방울의 투명 외곽과 내부 내용물은 다른 부피를 겹치는 조형 기준이다. 피부층/방패 원작은 설명 기호이며 제품 효능이나 투자 성과의 증거가 아니다.
