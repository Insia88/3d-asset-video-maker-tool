# Icons8 Fuzzy: 부드러운 봉제형 얼굴과 패키지

[공식 Fuzzy 컬렉션](<https://icons8.com/illustrations/style--fuzzy>)에서 보존 가능한 전체 미리보기 31장을 6개 검토판으로 직접 개별 관찰해 순수3D 시각스타일 대표 9개를 선정했다. 기본 조형 변형 9개는 대표에 묶고 일반 기호 중심 13개는 현재 우선순위에서 제외했다. 전체 원본 한 장을 한 단위로 보았다.

[공식 3D 스타일 목록](<https://icons8.com/illustrations/styles/3d>)에 Fuzzy가 포함되는 사실과 실제 닫힌 조형을 교차 확인했다. 선정 9개는 원작 상세에서 Fuzzy·Icons 8·PNG 제어 표시를 확인했다. PNG 등 형식 표기와 편집 가능한 실제 메시·특정 AI 모델의 확인은 구분한다. 개별 AI 제작 여부는 미확인이다.

## 부피와 적용

곱슬 털 같은 표면을 두꺼운 구체·원뿔·퍼즐 접합부·동물 얼굴·리본 상자에 씌운다. 두꺼운 큰 눈과 단순한 입이 작은 캐릭터의 표정을 읽게 하며, 큰 선글라스가 얼굴을 넓게 덮는 태양 조형은 사용자 기준 이미지의 소품 비율을 비교하기 좋다. 얼굴이나 내용물만 바뀐 둥근 몸과 폴더, 색을 바꾼 태양·리본 상자·자물쇠는 대표에 통합했다.

뷰티 세계로 적용할 때는 포근한 제품 도우미, 상상 속 성분 인형, 작은 선물 패키지라는 분석자 제안으로 사용한다. 원작 폴더를 실제 뷰티 상품으로 바꾸어 출처를 표기하거나 토마토·태양에서 제품 효능을 추론하지 않는다. 정지 원작의 원뿔 띠가 실제로 분출되는 움직임은 관찰하지 않았다. 털·리본·목줄·큰 눈은 짧은 I2V 시험에서 유지되는지 검토해야 한다.

## 관찰 범위

정상 Chrome에서 실제 Load next/last 목록을 펼쳐 원작 카드 126개를 확인했다. 각 실제 렌더링 currentSrc와 원작 href를 대응시켰고 pageAssets가 현재 문서에서 포착한 50개 중 정상 저장된 31개의 전체 이미지만 이 원장에 기록했다. 나머지 95개는 이 묶음에서 픽셀 직접 관찰 완료나 목표 수로 계산하지 않는다. 19개 네이티브 보존 실패는 manifest의 형식 판정 결과로 보존하며 다른 다운로드로 우회하지 않았다. 워터마크를 유지한 미리보기는 조사 근거이며 제작용 라이선스를 확인한 에셋이라는 뜻이 아니다.
