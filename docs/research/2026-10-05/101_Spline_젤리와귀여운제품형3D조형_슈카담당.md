# Spline 젤리와 귀여운 제품형 3D 조형 관찰

SPC0072–SPC0090의 정상 공개 미리보기 **19장** 전체 픽셀과 개별 상세 **19개**를 직접 확인했다. 독립 순수 CG 스타일 전체 조형 **8개**를 선정했다. 가까운 기본형 변형 **5개**, 큰 웹/사진 전경 혼합 **2개**, 미감 우선순위 제외 **3개**, 주 몸통 체적 확인 보류 **1개**는 목표 수량0이다. Spline 누적은 **90장 관찰·33개 선정**이다.

## 기본형 통합과 확인 보류

- SPC0072의 CRT 몸 캐릭터는 **I8S0051**, SPC0086 구름은 **I8S0179**, SPC0088 우편함 한 쌍은 **I8S0435**에 통합했다. 옷/표정·색/기호·두 물체 배치/비례 차이가 별도 새 기본형을 보장하지 않는다. 같은 원작자/메시라는 뜻은 아니다.
- SPC0078 Paper와 SPC0079 Grass는 **SPC0077**의 경로형 필기체 가족으로 통합했다. 실제 보이는 것은 큐브 재질 변형이 아니라 입체 필기체이며 단어/표면 변경과 고리/획 각각은 추가 단위0이다.
- SPC0073·SPC0075는 넓은 웹 문자/UI 또는 사진형 인물이 입체 오브젝트와 섞인 전체 혼합 비교0이다. 입체 부분을 따로 떼어 선정하지 않는다.
- SPC0074 앱 브랜드 아이콘·SPC0076 기본 큐브 반복·SPC0087 음향 기기는 CG 부피가 있어도 이번 뷰티/포근한 조형의 미감 우선순위에서 제외했다.
- SPC0081은 청록 잎의 부피가 보이지만 주 몸통 옆면/윗면이 정면/공개 live 화면에서 확인되지 않았다. 제목 cube, 작가 설명, 그림자만으로 전체 순수3D 판정을 보완하지 않고 확인 보류0으로 남겼다. 뷰어의 다른 프레임은 독립 표본이 아니다.

작가가 설명한 path·Bump map·Matcap/Glass layer·Boolean·hover/Cloner·문 이동·내부 회전은 공개 제작 설명의 범위로만 기록했다. 본 연구에서 실행/측정한 모델 파라미터나 물리 제형의 검증으로 쓰지 않는다. sound 설명은 실제 음원 청취/라이선스·BPM 측정의 근거가 아니다.

## 제작/리믹스와 권리의 확인 범위

SPC0081은 상세에 7sages 원작 연결이 표시되지만 그 원작 전체 이미지를 이 배치에서 별도로 관찰/집계하지 않았다. SPC0083은 levimagony 원작의 리믹스로 표시됐으며 미관찰 원형/메시를 새 참고 수량에 넣지 않았다. SPC0085는 원작 만화 인물을 3D로 옮긴 팬 작업으로 설명돼 일반 조형 비례만 참고한다. 현행 CC BY 4.0 표시가 만화/상표·리믹스 원형·다른 텍스처의 별도 권리까지 확정하지 않는다.

정상 공개 원작 링크와 로컬 연구 관찰만 남겼다. 로그인·Remix 실행·모델/코드 복제·원본 재배포·생성형 AI 요청은 수행하지 않았다. 실제 카메라 키프레임·동작 길이·음향·셰이더 수치·재질 효능도 측정하지 않았다.
