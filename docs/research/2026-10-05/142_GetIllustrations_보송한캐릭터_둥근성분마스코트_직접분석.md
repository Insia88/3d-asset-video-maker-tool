# GetIllustrations: 보송한 캐릭터·둥근 성분 마스코트

[공식 Monster3D 원작 팩](<https://getillustrations.com/illustration-pack/monster-3d>)의 고유 공개 원본25장 전체를5개 관찰판에서 직접 확인하고, 개별 원작 상세25개와 제목/hero·같은 팩/3D 분류를 교차 확인했다. **17개 독립 순수3D 대표**를 선정한다. 가까운 유령/블롭 기본형2개와 공포·분노를 우선하는6개는 제외한다. 같은 모델의 눈/입/색·비례 변경을 독립 원작 수량으로 늘리지 않는다.

## 큰 머리와 작은 제품 친구

GIM001의 큰 머리/짧은 몸·낮은 발, GIM006의 위 눈 구체와 배형 몸, GIM025의 큰 배형 머리/작은 몸은 서로 다른 몸의 연결이다. 이 비례를 제품 옆 작은 안내자로 옮기면 제품 자체보다 크게 튀지 않으면서 표정으로 다음 설명 칸을 가리킬 수 있다. 원작의 실제 동작은 관찰하지 않았다.

GIM010은 실제 확대 원본에서 짧은 미세 외피 결과 넓은 곡면 명암이 확인되는 블롭 대표다. GIM011·017은 큰 둥근 머리/한 몸·짧은 손·물결 하단의 기본 연결이 가까워 대표 하나로 묶었다. 독립 검토자도 세1200px 전체 원본의 색/주름·눈/입·키/폭·팔 방향 변화를 비교해 같은 기본형 변형으로 통합하는 데 동의했다. 실제 메시가 같다는 검증은 아니다.

## 성분을 형태로 구별하는 방법

GIM005의 줄무늬 몸/날개, GIM016의 두 팔 선인장/두꺼운 화분, GIM018의 반구/긴 촉수, GIM024의 넓은 갓/짧은 기둥은 단순한 얼굴 교체보다 큰 외피가 서로 다르다. 성분마다 이런 실루엣을 하나씩 부여하는 방법을 참고한다. 꿀·식물·젤리 같은 연상은 분석자의 제작 제안이며 원작이 실제 화장품 성분이나 효능을 입증하지 않는다.

GIM013의 버튼형 눈/긴 귀, GIM014의 말림 갈기는 보송한 인상을 주는 조형이다. 실제 봉제/섬유 재료나 제작 과정은 확인하지 않았다. 첨부 선호 사진의 따뜻한 역광을 옮길 때는 눈 하이라이트와 큰 외피의 부드러운 명암만 먼저 잠그고 표면 결과 실루엣의 일관성을 확인한다.

## 제품에서 기업별 바구니로

영상 제안: 작은 제품 상자를 닮은 GIM008 안내자가 서로 다른 제품/성분 친구들을 낮은 기업별 단상으로 안내한다. 카메라가 넓어지면 단상들이 하나의 큰 바구니 안에 놓인다. 제품→기업→ETF 관계는 별도 확인한 실제 기업/편입 정보에 맞춰 구성하며 원작 그림에서 금융 사실을 얻지 않는다. 이 연출은 원작 동작 분석이 아니라 제작 제안이다.

## 제작·상품 주장과 실제 확인의 분리

정상 공개 팩은 Human designers, Blender 제작, original OBJ 포함과 transparent PNG/Sketch/Adobe XD/Iconjar 형식을 주장한다. 개별 원작의 File types는25개 모두 비어 있으며 Download Options의 PNG만 직접 확인했다. 일반 상단/홍보 문구의 PNG·AI/SVG·PNG·AI를 개별 원작의 실제 편집 파일 근거로 사용하지 않는다. 개별 인간 작가 이름·AI 생성 모델은 미확인이다. 별도 AI Studio/custom work 광고도 기존 원작의 개별 제작 증거가 아니다.

공개 hero URL과 저장 파일명은 .png지만 실제 native bundle은 **WEBP RGB1200×1200**, 배경/워터마크 포함이다. 상품 PNG의 alpha나 실제 OBJ/메시/편집 가능성을 확인하지 않았다. 실제 모델 다운로드·네이티브 뷰어·생성 실행은0이다. 팩 제목/실제 공개 카드는25개인데 본문은24mascots라고 적혀 있어 원문 충돌을 보존한다. 완료 수는 실제 관찰25장을 기준으로 한다.
