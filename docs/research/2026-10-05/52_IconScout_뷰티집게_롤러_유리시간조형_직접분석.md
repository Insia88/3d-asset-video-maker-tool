> 공개본에는 원본 이미지·영상과 로컬 관찰판을 포함하지 않는다. ‘로컬 관찰 근거’는 저장소에 재배포하지 않는 로컬 관찰 자료를 가리킨다. 공개 출처 링크와 관찰·제작 제안은 보존하며, 문서별 과거 수량보다 [프로젝트 감사 집계](<../../../data/projects/finfluencer-beauty-etf/audit.json>)와 [스냅샷 매니페스트](<../../../manifests/snapshot.json>)의 집계가 최신 기준이다.

# IconScout 뷰티 집게·롤러·유리 시간 조형

공식 Beauty 3D Icons 검색에서 새로 확인한 실제 미리보기 78장을 직접 개별 관찰하고 4장을 선정했다. 기본 조형이 겹치는 색·자세·작은 소품 변형 72장은 대표 원작으로 묶었고, 현재 뷰티·귀여운 미감의 우선순위가 낮은 2장은 제외했다. 팩 표지는 집계하지 않았으며 여러 도구가 함께 있는 이미지도 한 장이 한 단위다.

선정 원작 4개는 개별 공개 페이지의 제작자와 3D 파일 제공 형식 문구를 직접 확인했다. 이 자료는 공식 3D 디자인 에셋 미리보기이며 원작의 AI 제작/특정 모델은 미확인이다. 사이트의 AI 편집·생성 버튼을 원작 제작의 증거로 사용하지 않았다. 제공 형식 표기는 실제 메시 파일을 열어 검증한 결과와 구분한다.

## 뷰티 세계를 만드는 구성

- 굵게 휜 발의 집게는 닫힌 부품 사이의 공간을 보여 주고, 양끝 롤러는 두 헤드의 크기를 비교한다. 단순한 색 변화와 다른 도구의 구조를 기준으로 남겼다.
- 넓은 튜브형 립밤은 일반 원통 립스틱과 몸통/코어의 결합이 달라 독립 형태로 남겼다. 캡의 분리는 실제 동작으로 관찰한 것이 아니다.
- 민트 내용물의 유리 모래시계는 잘록한 외곽과 내용물/화살표를 겹치는 입체 기호다. 노화 지연 효과나 투자 성과를 증명하지 않는다.
- 상점·거울·팔레트·병의 색/캡/작은 장식 조합은 대부분 기존 대표와 겹쳤다. 공개 카드 숫자가 많아도 새로 선정할 원작 숫자를 대신하지 않는다.

## 관찰 범위와 출처

[공식 Beauty 3D Icons 검색](<https://iconscout.com/3d-icons/beauty?page=5>)과 각 항목의 원작 페이지를 이용했다. 실제 관찰물은 450×450의 공개 PNG/WebP 래스터 미리보기이며 전체 형태를 직접 보았다. 정지 이미지에서 카메라/움직임을 관찰했다고 주장하지 않는다. 카메라 제안과 금융·뷰티 적용은 분석자의 해석이다.

`references_visual_iconscout_search5.jsonl`에 원본 URL/ID, SHA256, 실제 이미지/보드, 제작자·형식 확인 수준, 선정·변형 제외를 보존했다. 기존 원본 ID/SHA가 일치한 두 후보는 준비 단계에서 제외했다. 새 78장 중 같은 기본 조형 변형 72장, 현재 미감 우선순위 제외 2장은 추가 집계하지 않았다. 하나의 대표가 선정되지 않았어도 변형을 새로운 단위로 만들지 않는다.
