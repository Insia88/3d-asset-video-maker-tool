# 뷰티 제품 유사 검색의 입체 선별

공식 공개 유사 검색의 새 후보 403개 중 앞 36개를 6개 연락 시트에서 직접 관찰했다. 순수 3D 3개 선정, 33개 제외다. 나머지 367개는 준비 상태로 남겨 실제 분석·완료 수에서 제외했다.

유사 검색에는 3D 유형 필터가 없고 실제 결과에 사진형 제품과 2D 매장이 많이 섞였다. 후속 수집은 3D 유형을 지정할 수 있는 조회로 좁힌다. 이름·설명만으로 3D를 판정하지 않는다. 실제 관찰한 순수 3D 한 장을 한 단위로 세고, 같은 제품 구성의 변형은 대표 하나로 합친다.
