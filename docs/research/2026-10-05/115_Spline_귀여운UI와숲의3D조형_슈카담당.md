## 3D 제작 표시와 순수 CG 시각의 경계

- **SPC0135 개구리 인형:** 작가가 Gaussian Splatting으로 만든 장면이라고 설명했다. 3D 데이터 제작 설명은 확인되지만 인형의 전체 결과는 자연 촬영형 털/천·팔다리로 읽혀 최신 순수 CG 이미지 수량0이다. 실제 캡처 원본/스플랫·메시/리깅이나 생성형 AI 모델은 취득/검증하지 않았다. 위 하트만 분리하거나 다른 회전 화면을 새 단위로 세지 않는다.
- **SPC0136·SPC0145·SPC0150:** 큰 평면 광고 문구/이모지·웹 정보층이 입체 병/털 캐릭터/반사 조형과 전체 화면에 섞여 혼합 비교0이다. 글자를 잘라 물체만 남긴 별도 대표로 세지 않는다.
- **SPC0148·SPC0151:** 기둥/화병·줄기 부피는 보이지만 다면체 반사면/넓은 꽃잎이 사진형 표면인지 전체 CG 조형인지 명확히 구별하기 어려워 보류0이다. 실제 사진/HDR/이미지 맵 사용을 확정하지 않는다. 표면의 일부를 잘라 남은 물체를 새 대표로 만들지 않는다.
- **SPC0154:** 작은 점/밝기 패턴이 곡면처럼 보이지만 닫힌 전체3D 부피와 평면 효과를 정지 미리보기만으로 구별하기 어려워 보류0이다. displacement/animated 태그로 메시/모션을 보완하지 않는다.

## 모델·원형 자산/권리의 확인 범위

SPC0130의 일부 라이브러리 자산·SPC0133/0137의 재질 라이브러리 설명을 기록했다. 라이브러리 원형 모델/재질과 각각의 권리를 취득한 뜻이 아니다. SPC0142/0153의 AI라는 제목/태그와 사이트 공통 AI Prompt 메뉴는 개별 생성형 AI 모델·학습 데이터 사용 근거가 아니다. SPC0147의 Hana 표시를 Spline으로 바꾸지 않는다. 전체27개에서 개별 AI 모델/메시 데이터·리깅·물성/실시간 이벤트·키 입력/충돌·카메라 경로/루프 시간을 직접 검수하지 않았다.
