> 공개본에는 원본 이미지·영상과 로컬 관찰판을 포함하지 않는다. ‘로컬 관찰 근거’는 저장소에 재배포하지 않는 로컬 관찰 자료를 가리킨다. 공개 출처 링크와 관찰·제작 제안은 보존하며, 문서별 과거 수량보다 [프로젝트 감사 집계](<../../../data/projects/finfluencer-beauty-etf/audit.json>)와 [스냅샷 매니페스트](<../../../manifests/snapshot.json>)의 집계가 최신 기준이다.

# Spline 작은 공간과 귀여운 3D 조형 관찰

SPC0001–SPC0024의 공개 원작 미리보기 **24장** 전체를 직접 관찰하고, 각 작품의 정상 공개 상세 페이지에서 작성자·“Made in Spline”·공개 iframe 주소·CC BY 4.0 표기를 확인했다. 이 중 독립 순수 CG 스타일 이미지 **12개**를 선정했다. 기본형 변형 **3개**, 큰 평면 구성/사진형 자료가 섞인 **6개**, 전체 CG 스타일 확인을 보류한 **2개**, 이번 귀여운 뷰티 미감에 적합성이 낮은 **1개**는 목표 수량에서 제외했다.

같은 씬의 각도·상태·회전·소품 분리는 추가 단위가 아니다. 방 안의 책상·화분·의자, 정원의 꽃·구름·아치, 캐릭터의 말풍선은 전체 장면 한 단위에 포함한다. 프로젝트 최신 집계는 [집계와 검증](<06_%EB%B9%84%EC%A3%BC%EC%96%BC_%EC%A7%91%EA%B3%84%EC%99%80_%EA%B2%80%EC%A6%9D.md>), 개별 판정은 [Spline 원장](<../../../data/projects/finfluencer-beauty-etf/references/index.json>)에서 확인한다.

## 공개 원작과 실제 관찰의 연결

[공식 Spline Community](<https://community.spline.design/>)는 공개 3D 디자인을 발견하고 공유하는 갤러리라고 안내한다. 정상 UI의 [cute 검색](<https://community.spline.design/search?query=cute&sort=trending>)과 [plant 검색](<https://community.spline.design/search?query=plant&sort=trending>)에서 작품 링크·작성자 링크·표시 제목·공개 미리보기 주소를 확인했다. 검색 단어는 주제 발견에만 사용했고, 제목이나 태그를 근거로 3D 판정이나 수량을 정하지 않았다.

| 관찰 방식 | 확인한 범위 | 수량 의미 |
|---|---|---|
| 원작 공개 미리보기 | 각 이미지의 전체 픽셀·구도·외곽 두께·접합·앞뒤 면/겹침·그림자·재질 | 실제 관찰 24장; 선정은 별도 12개 |
| 개별 상세의 정상 DOM | 작성자·Made in Spline·iframe 주소·현행 CC BY 4.0 표기 | 24개 제작/권리 출처 확인; 이미지 관찰을 대신하지 않음 |
| 실제 공개 iframe 렌더 | SPC0008 작업방·SPC0020 조형 정원·SPC0022 작은 상점·SPC0024 제품/잎 혼합 장면 | 공개 미리보기와 같은 씬이므로 추가 수량 0 |
| 렌더 일부 표시 | SPC0019 인물 장면은 관찰 시점에 몸/바지 등의 일부 면이 보이지 않음 | 전체 로드/모델 확인을 단정하지 않고 미확인 비교 0 |
| 독립 전체 이미지 교차 검토 | SPC0008·SPC0020의 원본 픽셀을 다른 검토자가 별도 관찰 | 선정 근거를 보강하되 수량 증가 0 |

**“3D 데이터”와 “이번 순수 CG 스타일 시각”은 다른 확인 항목이다.** SPC0014는 작가가 자신의 식물로 Gaussian Splatting을 사용했다고 설명한 3D 자료지만 결과가 사진형 잎/뿌리와 큰 문자 구성으로 보인다. 사진·실사형 수집을 제외하는 이번 목표에서는 비교 자료로만 남겼다. SPC0016은 Spline 제작 표기가 있어도 사실적인 잎 미리보기만으로 전체 순수 CG 스타일을 확정하지 않았다.

개별 상세의 표시 작성자를 기록했으며 실제 법적 저작권 소유자나 원본 모델의 모든 부품 제작자를 검증한 뜻은 아니다. 공개일은 페이지의 **2 years ago·3 years ago·9 months ago** 같은 상대 표시만 확인했다. 미리보기 URL의 시각 문자열은 파일 URL 메타데이터로 보존하고 정확한 작품 공개일로 변환하지 않았다.

SPC0008의 작업방은 책상/의자와 선반이 양쪽 벽에 이어진 구조다. SPC0021은 열린 뒤판 앞 오븐/화분/바구니가 작은 둥근 받침에 밀집한 구조이고, SPC0022는 두 벽 안 탁자·의자·오븐·병 진열을 가진 작은 상점이다. 가구의 색이나 각도 차이가 아니라 **전체 배치·열린 면·주요 체적의 연결 구조**가 달라 독립 공간으로 선정했다.

SPC0020의 얇은 줄기와 꽃잎은 앞뒤 겹침·두께·접지 그림자가 같은 3D 장면에 이어진다. 얇다는 이유만으로 평면으로 판정하지 않았다. 반면 SPC0024는 입체 크림 용기 양옆의 잎 이미지층이 넓게 섞인 경우다. 입체 용기만 따로 추출해 새 대표를 만들지 않았다.

## 기본형 변형과 혼합 비교

- **SPC0007 → SPC0002:** 사각 머리·짧은 연결·받침의 기본형을 유지한 색/조명·받침 단계 변형으로 통합했다.
- **SPC0006 → I8S0051:** CRT형 몸/머리와 관절 팔다리 로봇의 비례·색·귀 부속 차이를 보수적으로 통합했다. 원작자가 같다고 확인한 판단은 아니며 형상 독립성 기준이다.
- **SPC0017 → I8S0091:** 꽃심/방사 꽃잎의 기본형에 줄기·잎을 더한 색·비례/부속 변형으로 통합했다. noise라는 제목/태그를 AI 모델로 해석하지 않았다.
- **SPC0003·0011·0012:** 토끼/기기/게임 세계는 입체 부분이 보이지만 큰 날짜 문자·픽셀 커서·평면 캐릭터 로고가 전체 미리보기에 섞여 비교 자료로 보존했다.
- **SPC0014·0015·0016:** 사진형 식물/지구 표면의 3D 데이터나 제작 표기가 순수 CG 스타일 선정과 같지 않다. 현재 목표 수량은 0이다.
- **SPC0019·0023:** 일부만 표시된 인물 렌더와 너무 작고 어두운 격자 속 사각 인물은 전체 확인 또는 이번 미감의 근거가 부족해 제외했다.
- **SPC0024:** 작가가 제품 제시용 잎 그림자를 연출한다고 설명하며, 실제 공개 렌더에서도 사진형 잎 이미지층과 용기가 함께 보인다. 댓글에서 언급한 이미지층 설명은 작가 직접 설명과 구분했다.

24개 상세의 현행 정상 UI에서 **Made in Spline**과 [CC BY 4.0](<https://creativecommons.org/licenses/by/4.0/>)를 확인했다. SPC0006은 검색 도구의 과거 캐시가 CC0로 반환됐지만 현재 상세 UI는 CC BY 4.0으로 표시됐다. 원장에는 현재 UI 확인을 기록하고 과거 캐시와의 불일치도 남겼다. 실제 이용 전에는 원작의 현재 표시와 개별 상표/캐릭터 권리를 다시 확인해야 한다.

생성형 AI 모델·학습 데이터·모든 부품의 제작 툴·편집 가능한 메시·리깅·원본 코드·정확한 재료 규격은 **미확인**이다. SPC0014의 Gaussian Splatting과 SPC0024의 Figma 플러그인 언급은 해당 작가가 직접 표시한 범위만 기록했다. Spline 페이지의 AI 서비스 메뉴나 작품의 AI 태그를 개별 생성 모델 근거로 쓰지 않았다.

공개 원작의 미리보기 관찰과 링크만 기록했다. Spline 장면 코드·모델·편집 원본을 GitHub에 복제하거나 로그인·Remix·유료 다운로드를 실행하지 않았다. 정지 미리보기와 렌더가 보인 사실로 움직임·BPM·카메라 궤적·모션 타이밍을 측정했다고 쓰지 않는다.
