> 공개본에는 원본 이미지·영상과 로컬 관찰판을 포함하지 않는다. ‘로컬 관찰 근거’는 저장소에 재배포하지 않는 로컬 관찰 자료를 가리킨다. 공개 출처 링크와 관찰·제작 제안은 보존하며, 문서별 과거 수량보다 [프로젝트 감사 집계](<../../../data/projects/finfluencer-beauty-etf/audit.json>)와 [스냅샷 매니페스트](<../../../manifests/snapshot.json>)의 집계가 최신 기준이다.

# 뷰티 ETF 상품 후보: 공식 원문과 3D 설명 연결

핀플루언서 지원용 약 3분 영상의 금융 설명을 위한 상품 후보 기록이다. 소개 상품은 확정 전이다. 조사일은 2026-10-05이며, 아래 두 상품은 동일한 투자대상·구성비를 가진 상품으로 취급하지 않는다. 금융 문서는 3D 참고 개수에 포함하지 않는다.

## 공식 원문에서 확인한 후보

## 상품 페이지 내부 차이와 보류한 수치

HANARO 공식 상품정보는 최초상장일을 2024-04-16으로 표시하지만 같은 페이지의 2026-07-16 관련 콘텐츠는 2024-07-16으로 표시한다. 간이투자설명서의 최초설정일은 2024-04-15이며 설정일과 상장일은 서로 다른 항목이다. 상장일은 거래소 원문 대조 전 대본에서 보류한다. [HANARO 공식 상품 페이지](<https://www.hanaroetf.com/fund/9DBA2CEA9F3E4C36>), [간이투자설명서 p.1](<https://www.hanaroetf.com/_upload/public/fund-new/9DBA2CEA9F3E4C36/JF6910HQBU410WRMN.pdf>)

실시간 페이지의 보유종목 표에는 별도 조회일 입력이 있어, 상단 시장가격의 기준일을 보유종목 표에 자동으로 적용하지 않는다. 이번 기록에는 편입비중·수익률·시장가격을 채택하지 않았다. 같은 페이지 안의 과거 홍보 콘텐츠 비중도 현재 비중으로 전용하지 않는다. [HANARO 공식 상품 페이지의 PDF / 자산구성내역](<https://www.hanaroetf.com/fund/9DBA2CEA9F3E4C36>)

SOL 간이투자설명서 링크는 공개 웹 확인에서 403으로 원문을 읽지 못했다. 상품 페이지의 투자 구조만 후보 설명에 사용하고, 투자설명서 전체 검증 완료로 표시하지 않는다. [공식 문서 링크](<https://www.soletf.com/api/etf/pds/down/policyDescription/211080?type=simple_desc>)

## 3D 설명에 연결하는 편집안

아래는 제작 해석이며 상품 편입 또는 수익률에 관한 사실이 아니다. 브랜드·제조·유통을 각각 화장품 진열대, 제조 장치, 운송 통로로 표현한다. 세 공간이 하나의 투명한 바구니에 연결되면 제품에서 기업과 ETF로 시선이 이어진다.

| 설명 목적 | 입체 연출안 | 숫자·문구 적용 조건 |
|---|---|---|
| 제품과 기업의 관계 | 보송한 안내 캐릭터가 크림 용기의 문을 열면 안에 브랜드 매장·제조 장치·배송 통로가 나타난다. | 기업명을 넣을 때 실제 사업과 최종 상품의 편입 여부를 각각 확인한다. |
| 여러 기업을 묶는 구조 | 서로 다른 기업 토큰이 하나의 바구니로 이동한다. 닫힌 포장과 열린 내부는 서로 다른 설명 컷으로 설계한다. | 토큰 개수·크기는 최종 상품의 실제 구성과 기준일에 맞춘다. 예시 개수에 투자 사실을 부여하지 않는다. |
| 비용의 차이 | 작은 비용 눈금이 바구니 옆에 나타난다. 보수와 그 밖의 비용을 단계별로 설명한다. | 총보수와 총보수·비용을 같은 수치로 부르지 않는다. |
| 집중과 손실 위험 | 바구니가 한 산업 받침 위에 놓인다. 받침이 기울면 여러 토큰도 함께 움직인다. | 단순한 시각 비유다. 실제 하락폭·상관계수·미래 손실률을 뜻하지 않는다. |
| 확인 기준 | 상품 이름, 담는 기업, 큰 비중, 비용, 위험을 다섯 개의 입체 확인창으로 정리한다. | 화면의 기준일과 출처는 최종 상품 원문을 다시 확인해 적용한다. |
