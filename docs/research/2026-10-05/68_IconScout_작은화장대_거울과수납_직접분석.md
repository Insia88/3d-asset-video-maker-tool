# IconScout 작은 화장대·거울과 수납의 입체 구성

공식 Dressing Table 3D Icons 검색에서 새로 확인한 실제 미리보기 74장을 직접 개별 관찰하고 9장을 선정했다. 기본 조형이 겹치는 색·자세·작은 소품 변형 63장은 대표 원작으로 묶었고, 현재 뷰티·귀여운 미감의 우선순위가 낮은 2장은 제외했다. 팩 표지는 집계하지 않았으며 여러 도구가 함께 있는 이미지도 한 장이 한 단위다.

선정 원작 9개는 개별 공개 페이지의 제작자와 3D 파일 제공 형식 문구를 직접 확인했다. 이 자료는 공식 3D 디자인 에셋 미리보기이며 원작의 AI 제작/특정 모델은 미확인이다. 사이트의 AI 편집·생성 버튼을 원작 제작의 증거로 사용하지 않았다. 제공 형식 표기는 실제 메시 파일을 열어 검증한 결과와 구분한다.

## 같은 가구를 늘리지 않는 구조 기준

- 키 큰 닫힌 수납장형·네 긴 다리형·큰 옆판/가운데 빈 공간형·양끝 수납 기둥형·비대칭 수납형은 지지/몸통의 큰 구조를 구분해 남겼다. 서랍 수·다리 길이·색·거울 테두리/작은 의자 변화는 통합한다.
- 세 면 거울의 중앙/양옆 관계와 큰 중앙 세로 면/양옆 깊은 칸은 거울 하나의 앞면 장식과 다르다. 세 면/여러 칸/여러 제품을 각각 원작으로 세지 않는다.
- 통통한 캡슐 몸통과 아주 낮은 노랑 무대/큰 원형 림은 큰 부피 비율의 참고다. 같은 캡/색·작은 병/꽃을 바꾼 가구는 늘리지 않는다.
- 유리 앞면의 흰 반사 띠·원형 조명·열려 보이는 수납칸은 정지 이미지 관찰이다. 실제 거울 반사/조명 점멸·문/서랍 이동·원작 메시나 생성 모델을 확인한 것은 아니다. 미니 뷰티 공간 적용은 분석자의 제안이다.
