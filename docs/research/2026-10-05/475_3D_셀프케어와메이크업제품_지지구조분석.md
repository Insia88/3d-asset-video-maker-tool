# 셀프케어 행동과 메이크업 제품의 지지 구조

Createen의 Unilever 3D Cartoon Movie와 Extension Studio의 Haus Laboratories 공개 이미지 **18개를 전체 화면으로 직접 확인했고 5개를 새 참고로 남겼다.** 원작 관찰판은 5장, 기존 원본 전체 대조판은 8장(32배치)이다. 같은 작품의 확대·색·제품 수를 별도 단위로 늘리지 않았다.

## 제작 공시와 출처

[Createen 원작](<https://createenagency.com/project/3d-cartoon-consumer-story/>)은 Unilever의 보디 보습제 설명용 3D 캐릭터 애니메이션이라고 소개한다. 프로젝트 표기는 2021년 2월이다. 원문의 피부·성분 효능 설명은 이 시각 분석에서 사실 검증한 내용이 아니다. Vimeo 영상은 재생하지 않았으며 이번 관찰은 프로젝트 갤러리의 정지 4개에 한정한다.

[Haus Laboratories 프로젝트](<https://www.extension.studio/work/haus-laboratories/>)는 전체 세계를 CGI로 구성했다고 공시하고 연도는 2025로 표시한다. 페이지의 크레딧은 Studio Shapes & Forms, Creative Director Fabian Garzon이다. 이는 해당 프로젝트 페이지가 제시한 제작 주장이다. Case Study 연결은 Behance 홈페이지로 이어져 별도의 원작 사례 확인 근거로 사용하지 않았다. 실제 툴·메시·AI 생성 여부는 확인하지 않았다.
