## Higgsfield에서 다루기 쉬운 제작 규칙

1. 같은 화장대 미니어처와 같은 ETF 바구니 형태를 기준 이미지로 고정한다. 도자기 화장품 용기, 무광 아크릴 기업 토큰, 반투명 유리 바구니처럼 물성 역할을 구분한다.
2. 한 샷에는 한 동작을 지정한다. 뚜껑 열기, 토큰 세 개 들어오기, 카메라가 정면으로 이동하기 중 하나를 중심 동작으로 둔다. 이 문서에서 보이는 복합 광고 장면을 한 번의 생성으로 모두 재현할 필요는 없다.
3. 짧은 3–5초 생성 단위를 조립하는 것을 제안한다. 이는 관찰 영상의 실제 평균 컷 길이가 아니라 180초 설명 영상에 적용할 제작 설계값이다.
4. 숫자·ETF 이름·편입 비중·보수·추종지수·기준일·출처·유의 문구는 후편집한다. 패키지 인쇄를 생성 모델에 맡겨 정확한 한글을 기대하지 않는다.
5. 입체 장면은 `하나의 소비품 → 여러 기업 → 하나의 ETF 바구니 → 확인할 세 항목` 순서의 설명 도구로 사용한다. 원료 물보라·빛줄기·상향 화살표가 투자 성과를 약속하는 기호가 되지 않도록 맥락을 붙인다.
6. 실제 재생을 하지 않은 배치에서는 음악 BPM·효과음 타이밍·대사 속도·전환 곡선을 추정 수치로 제시하지 않는다. 프리셋 이름의 Beat/Whip-Pan도 측정 근거가 아니다.
7. 갤러리의 브랜드 로고·라벨·카피는 차용하지 않는다. 중립적인 자체 패키지와 금융 교육 문구로 바꾸고 시각 원리만 참고한다.

## 교차 확인과 반례

- **체적이 있는 물체와 3D 설명은 다르다.** M125의 손·잔·붓기, M127의 정물, M139의 상자 근접은 물성이 풍부해도 단순 카메라/제품 참고로 남겼다. M122의 섬유 소품 공간, M103의 개폐, M144의 금고 공간은 실제로 화면의 입체 배치와 동작이 중심이다.
- **큰 타이포를 많이 보여 주는 것과 내용을 이해시키는 것은 다르다.** M142는 단어 카드를 빠르게 바꾸지만 뷰티 ETF에서는 지수·구성·보수라는 정확한 개념에 대응해야 한다. M145의 일상→하나의 물체→여러 물체→결론 구조는 설명 순서 참고에 더 적합하다.
- **일관된 색만으로는 독립 샷이 늘지 않는다.** M119·M134·M139의 색상 변형을 여러 개의 새 시각 원리로 세지 않았다. 제작에서도 색이 아니라 물체의 역할·시점·설명 행동을 바꾸어 장면을 구분한다.
- **제품 라벨의 수치가 ETF 근거가 되지 않는다.** M138의 4g sugar, M147의 0 Cal/330ML, M145의 90 CAPSULES는 관찰 화면 내용이며 금융 숫자로 차용할 대상이 아니다.
- **짧은 프리뷰도 전수 컷 분석은 아니다.** 1초 사이의 빠른 컷이나 모핑 실패는 누락될 수 있다. 예컨대 M106의 기계 컷 후보는 여러 번 급증했지만 관찰한 독립 구성은 9개다. 자동 탐지 후보를 모두 인정하지 않았다.
- **메타데이터와 화면이 어긋날 수 있다.** M136 제목은 Peach Float Drop이지만 직접 보이는 과일은 배 형태다. 제목만으로 재료를 복숭아로 적지 않았다.
- **재등장과 새 정보 추가를 분리한다.** M128의 마지막 타원 포스터는 부가 문구가 추가됐어도 초기 타원 구도와 반복으로 처리했다. 한 장면 안의 문구 증가를 독립 샷으로 늘리지 않았다.

자료의 범위는 해당 48개 공식 프리뷰의 표본 프레임 관찰이다. 음성·음악·정확한 컷 수·카메라 속도·사용 모델·상업 사용 권리·개별 게시일을 확정하는 자료가 아니다. 제작에 선택한 프리뷰는 정상 플레이어에서 전체 재생하며 중간 프레임의 연속성과 실패 여부를 확인하고, 공식 기능·이용 조건을 별도로 검토한다.
