# F59·F60 동일 파일 중복 정정

동일한 원본 파일을 별도 원작으로 선정한 8쌍을 확인해 후속 ID를 기존 대표에 병합했다. 전체 파일 SHA·크기와 직접 바이트 비교가 일치하며, 이 중복 선정은 F59에서 F60으로 계승됐다.

정정된 선정 집계는 F59 11,617개, F60 11,737개다. 이전 v1 기록의 11,625개·11,745개는 정정 이전 수량이며, 해당 기록과 원본 증거는 이력으로 보존한다. F60 신규 선정 120개는 이번 정정 대상에 포함되지 않는다.

|---|---|
| F485A0001-I001 | F441A0001-I002 |
| F493A0001-I001 | F433A0001-I008 |

원본 전체 이미지·모델시트·주요 독립 장면을 한 단위로 세고, 동일 파일·카메라·색상·재질 변형은 추가하지 않는다. 이번 검증은 지정된 8쌍의 정확 파일 중복을 확인한 것으로, 과거 전체 자료의 모든 시각적 유사성을 새로 검증한 것은 아니다. 원본 이미지·영상은 재배포하지 않는다.
