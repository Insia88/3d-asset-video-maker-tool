# 뷰티·귀여운 3D 참고: F36 집계

직접 관찰·선정한 고유 3D 참고는 **10,232개**다. 이전 10,210개에 독립 전체 이미지 **22개**를 더했으며, 목표 25,000개까지 **14,768개**가 남아 있다.

화장품 용기와 투명 외피, 연속 리본과 부드러운 쿠션의 지지 관계를 읽고, 작은 창가·캐릭터·꽃 조형의 크기 대비를 비교했다. 이 관찰은 2030 뷰티 산업 관심 투자자를 위한 핀플루언서 지원 영상의 시각 설명을 돕는다. 화면의 제품 수와 배치를 실제 ETF 편입 기업·비중·수익률로 해석하지 않는다.

각 선정은 작성자와 별도 검수자가 전체 원본 및 가까운 기존 대표와 비교했다. 새 원본 22개의 파일·치수·RGBA를 다시 확인했고, 기존 원장 32,428행의 ID·URL·기재 해시를 대조했다. 과거 선정의 유효 픽셀 대조는 7,451파일·행이며, 나머지 2,759행은 메타데이터 범위다. 통합 담당자는 새 22개를 잘리지 않은 전체 이미지 비교판 6장에서 관찰했다. 전체 라이브러리의 모든 의미상 조합을 다시 본 것은 아니다.

배경 전체층의 CG 근거가 부족한 이미지와 실사·2D·혼합 이미지, 같은 작품의 작은 색·각도 변경은 추가하지 않았다. 불확실한 CG 배경을 사진 혼합이 입증된 것으로 표현하지 않는다. 비교판 패널·보조 클레이·다운로드·생성 제작 에셋도 추가하지 않는다.

기존 32,428행과 선정 10,210개를 보존했다. 독립 기술 감사에서 새 113개 원본 복사의 SHA와 422개 원자 패킷 파일, 출처 문서의 상대 연결을 확인했다. 작성자의 원본 제안·범위 설명은 동결 보존하고 통합 집계 플래그만 루트 판정에 맞췄다.

원문 CGI 표기, 실제 편집 메시·리그 확보, AI 모델 실행, 상업 재사용 권리는 서로 다른 확인 사항이다. 아래 팬·줌·전환 설명은 독자 에셋의 제작 제안이다.
