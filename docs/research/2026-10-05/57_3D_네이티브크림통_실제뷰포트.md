# 실제 3D 뷰포트: 작은 크림 통과 윗면

[Jozsef Hocza의 원작](<https://sketchfab.com/3d-models/cosmetic-jar-f924e9dfd0eb42409ca63ac635b9e8ff>)에서 실제 로딩된 3D 뷰포트 한 구도를 직접 관찰했다. 고유 참고 **1개**다. 두 개의 제품, 인쇄 라벨, 주변 추천 썸네일은 추가 단위로 집계하지 않는다.

## 조형·재질

낮은 원통 몸통과 두꺼운 흰 뚜껑, 민트 테두리, 얇은 금색 띠가 제품을 구성한다. 앞쪽 통은 몸통 인쇄를, 뒤쪽 통은 둥근 윗면을 드러낸다. 부드러운 회색 바닥에 접지 그림자가 생기며 둥근 표면의 하이라이트가 형태를 읽게 한다. 흰색 면적을 크게 두고 민트·금색을 적게 사용하는 패키지 구성이 뷰티 에셋에 적합하다.

## 제작 적용

Higgsfield의 M03 크림 제품에서는 몸통 높이·뚜껑 두께·테두리 띠를 먼저 고정한다. 정면과 윗면을 파생하더라도 동일 제품의 비례를 유지한다. 원작의 브랜드 라벨을 복제하지 않고 독자 제품 디자인을 사용한다. 정지 원작에서 움직임을 관찰한 것은 아니며, 이 시점 파생은 제작 제안이다.

## 출처 교차 확인

원작 공개 상세는 제작자 Jozsef Hocza, 발행일 2022-10-31, `Uploaded with Blender`, [CC Attribution 4.0](<https://creativecommons.org/licenses/by/4.0/>) 링크를 표시한다. 제작자는 제품 촬영 대신 이 통을 직접 만들었다고 설명한다. 플랫폼의 70.1k triangles·35.5k vertices는 공개 화면의 반올림 표기다. 모델 파일의 다운로드·메시·재질·리깅 검수와 개별 생성형 AI 사용 확인은 하지 않았다. 실제 네이티브 3D 뷰포트 관찰과 3D 스타일 이미지만 관찰한 자료를 구분한다.
