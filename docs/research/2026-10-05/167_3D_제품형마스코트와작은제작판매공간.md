# 3D 제품형 마스코트와 작은 제작·판매 공간

공식 공개 3D 검색 고유 후보 428개 중 기존 원본 ID·해시 중복 345개를 뺀 새 이미지 83개를 14개 관찰판에서 모두 직접 관찰했다. 순수 3D 41개 선정, 그 외 42개 제외다. 실제 정지 이미지 한 장을 한 단위로 기록했다.

## 제작에 옮길 구조

작은 이발 매장·관리 제품·실험 탁자는 뷰티 소재를 직접 보여주는 후보다. 제품 외피·돌출 뚜껑·작은 선반의 좌표를 먼저 고정하고 화면 안의 브랜드·제품명은 후반 편집에서 확인된 정보로 붙인다.
두꺼운 바닥판·두 벽·작은 작업 인물로 닫힌 공간을 만들면 겨울돔의 반복 세트 문법을 제품의 제조·판매 흐름에 적용하기 쉽다. 공장·작업실 이미지가 실제 ETF 편입기업의 설비를 증명하는 것은 아니다.
큰 얼굴·짧은 사지·돌출 손과 도구의 비율은 독자 제품 마스코트를 설계하는 참고다. 기존 캐릭터의 이름·얼굴을 생성 지시로 사용하지 않고, ETF 바스켓과 개별 기업의 차이를 묻는 역할을 부여한다.
투명 두꺼운 외피·안쪽 면과 다면 단면은 금융 구조의 관계를 보여주는 조형 제안이다. 보석·금빛 공정은 실제 수익·보유금·수익률의 표현으로 사용하지 않는다.
실사형 방·자연 재질이 불명확한 장면과 넓은 평면 선형 그래프·윤곽선 인물은 3D 전용 집계에서 제외했다. 전체 이미지 한 장을 한 단위로 읽었으며 내부 장식·부품은 추가하지 않았다.
가까운 원본 36쌍·비교판 9개를 실제 관찰해 23개를 추가 통합했다. 같은 주제라는 이유만으로 다른 공간·행동·주요 실루엣까지 자동 중복 처리하지 않았으며, 유지한 구성 차이는 개별 교차 검토에 기록했다.
기존 선정 이미지 5,184장과 픽셀 후보를 대조해 12개 후보·관찰판 3개를 실제 확인했다. 강아지 기본형 1개를 추가 통합했고 나머지는 앞선 기본형 결정 또는 실제 다른 주체/공간임을 확인했다. 별도 경계 전체 4장은 독립 담당이 직접 교차 관찰했다.

약 180초 핀플루언서 지원용 뷰티 ETF 소개 영상의 기초 조형 조사다. 정지 이미지에서 움직임을 관찰했다고 쓰지 않으며 모델·메시·리깅은 별도 미확인이다. 제작 적용은 제안이고 실제 ETF 상품·편입비중·비용은 공식 운용사 원문 검증 후 채운다.
