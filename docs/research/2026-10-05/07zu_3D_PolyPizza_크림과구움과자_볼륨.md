# Tiny Treats: 크림과 구움과자의 귀여운 3D 볼륨

[Poly Pizza 공개 묶음](<https://poly.pizza/bundle/Baked-Goods-gzJE55OWCR>)의 실제 원본 렌더 32개를 3개 보드에서 관찰했다. 최종 선별은 독립 기본형 6개다. 절단면·부분 조각·코팅·토핑·쌓기·색 변형 26개는 같은 기본형 또는 이전 대표로 합쳤다. 카드 수 32개를 완료 수로 환산하지 않았다.

## 제작 출처

[원작자 공식 포트폴리오](<https://www.isalousberg.com/game-assets/>)가 연결하는 [Tiny Treats 원문](<https://tinytreats.itch.io/baked-goods>)은 low-poly 3D, OBJ·FBX·GLTF, gradient atlas, Blender 소스 제공, 생성 AI 미사용을 명시한다. 메시와 소스 파일은 열지 않았고 프로그램 설정·제작 과정을 직접 검증하지 않았다. 전통 CG로 분류하며 AI 생성 참고와 구분한다. 공개 묶음의 업데이트 표기는 2024-09-19이며 개별 기본형 최초 공개일은 미검증이다.

## 구조별 관찰

| 대표 | 실제 관찰 | 뷰티 영상으로 옮길 규칙 |
|---|---|---|
| PP00420 | 긴 둥근 빵 위의 얕고 짧은 홈 | 납작한 스트로크 대신 두꺼운 곡면과 작은 홈을 가진 독자 패키지/마스코트 조형 |
| PP00422 | 둥근 덩어리에 두꺼운 세모 갈라짐 | 큰 실루엣과 소수의 굵은 면으로 작게 보여도 읽히는 조형 |
| PP00430 | 낮은 원형 껍질과 겹친 내부 조각 | 작은 화장품 바스켓을 깊이 있는 그릇으로 표현하되 파이 자체의 재현은 피하기 |

식품이므로 직접 뷰티 분류가 아니다. 작은 제품의 두께·크림의 무광 볼륨·따뜻한 토이 질감을 참고하는 제품 미감 자료다. 속도·애니메이션·렌즈·BPM은 정지 렌더에서 측정하지 않았다.

## 중복을 줄인 방식

기존 PP00181 컵케이크, PP00207 와플, PP00208 도넛, PP00224 식빵, PP00229 크루아상 원본을 직접 대조했다. 새 토핑이나 색을 추가한 컵케이크·와플·도넛과 유사한 식빵·크루아상은 이전 대표로 통합했다. 사과/체리 파이는 충전물·격자·절단에 따라 늘리지 않고 한 낮은 원형 파이로 묶었다. 초콜릿·딸기·생일 케이크도 공통 원형 몸체를 하나로 기록했다. 이는 같은 원본 파일이라는 주장과 구분되는 보수적인 기본형 통합이다.

원장: [shots_plus_poly_pizza.jsonl](<../../../data/projects/finfluencer-beauty-etf/references/index.json>). 실제 근거는 `evidence/3d_images/plus/poly_pizza/pp019/`의 원본·보드·관찰 기록에 연결되어 있다. 공개 표기 CC0는 원문 주장으로 기록했고, 구매·메시 다운로드·API 키·생성 작업은 수행하지 않았다.

SHA·dHash·aHash로 이전 선별 710개와 새 원본 32개를 교차 비교해 파이 부분형/냄비 1쌍이 후보로 나왔다. 두 원본을 직접 관찰하여 낮은 닫힌 충전물과 깊은 열린 내부/양손잡이의 구조 차이를 확인했고, 해시 오검출로 기록했다.
