# IconScout 열린 판매대와 둥근 막대 소품의 입체 구성

[공식 팩](<https://iconscout.com/3d-icons/cosmetic-store>)의 공개 미리보기 66장을 직접 개별 관찰해 2개 대표를 선정했다. 기본 조형의 색/각도/작은 부품 변형 52개는 대표에 묶고 우선순위가 낮은 12개는 제외했다. 팩 표지는 집계하지 않고 원본 이미지 한 장을 한 단위로 보았다.

공식 Cosmetic Store 검색의 실제 원작80개 링크/PNG 관계를 DOM에서 확인했다. 정상 공개 자산74개 중 기존8개를 제외한 새66장의 전체 이미지를11개 보드에서 직접 개별 관찰했다. 미로드6개는 실제 관찰/선정에 포함하지 않았다. 선정2개 원작의 제작자·제공 형식을 개별 원작 본문에서 교차 확인했다.

공식 3D 분류 및 제공 형식과 실제 메시 검증은 구분한다. 원작 AI 제작/특정 모델은 미확인이며 AI 편집·생성 버튼이나 범위가 불명확한 About 문단 표기로 원작 제작 모델을 추정하지 않는다.

## 구성과 적용

두 굵은 기둥 아래 작은 제품을 놓은 판매대는 지지 구조와 제품의 크기 관계가 열린 공간으로 읽힌다. 타원 머리의 큰 막대 둘/열린 통/분리 캡은 여러 소품의 앞뒤 관계를 단순한 부피로 보여준다. 후자는 공식 Toy Mallet With Base라는 제목과 면봉 같은 시각 인상이 다르므로 실제 용도를 단정하지 않는다. 기존 작은 살롱의 차양/문·창 변형, 일반 병·캡·라벨, 반복되는 거친 전시 무대는 새 단위로 늘리지 않았다.
