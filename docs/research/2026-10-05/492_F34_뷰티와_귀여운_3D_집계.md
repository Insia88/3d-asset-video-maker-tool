# 뷰티·귀여운 3D 참고: F34 집계

2026-10-06 기준, 직접 관찰하고 선정한 고유 3D 참고는 **10,177개**다. 이전 10,134개에 새로운 전체 이미지 **43개**를 더했다. 목표 25,000개까지 **14,823개**가 남아 있다.

새 43개는 후보 작성자와 별도 검수자가 전체 원본과 가까운 기존 대표를 직접 비교했다. 원장 전체의 ID·URL·기재 해시와 후보 내부 중복을 대조했고, 새 원본의 파일·치수·디코딩 픽셀도 확인했다. 통합 전 기존 픽셀 비교는 유효 캐시가 연결된 선정 7,454행에 한정했으며, 나머지 2,680행은 메타데이터 범위였다. 전체 라이브러리의 모든 의미상 조합을 사람이 전수 비교했다는 뜻은 아니다.

색·각도·표정과 같은 작은 변형은 기존 대표로 묶었다. 사진·평면 레이어의 혼합 여부가 불명확한 장면과 주요 구조 차이가 부족한 장면은 보류하거나 제외했다. 새 선정 43개와 기존 선정 집합의 일치 여부는 최종 원장 감사에서 다시 확인했다.
