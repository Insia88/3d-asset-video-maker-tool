# Icons8 3D Kindy: 깊은 곡면의 포근한 좌석

[공식 3D Kindy 컬렉션](<https://icons8.com/illustrations/style--3d-kindy>)의 35개 원작 카드 가운데 정상 보존된 16개 전체 미리보기를 3개 검토판으로 직접 관찰했다. 독립 곡면 좌석 1개를 선정하고 기본형 변형 5개·현재 우선순위에 약한 10개는 제외했다. 원본 한 장을 한 단위로 보며 인물의 자세·신발·노트 색·캔 높이 변형을 수량으로 늘리지 않는다.

[공식 3D 스타일 목록](<https://icons8.com/illustrations/styles/3d>)의 분류와 실제 닫힌 좌석 부피를 교차 확인했다. 선정 원작의 개별 상세 페이지에서 3D Purple Chair illustration·3D Kindy·Icons 8·PNG 제어 표시를 확인했다. 개별 AI 제작 여부와 특정 모델·툴·편집 가능한 실제 메시 여부는 미확인이다.

## 곡면과 적용

넓은 보라 달걀 좌석의 안쪽은 깊게 들어가며 테두리는 두꺼운 하나의 둥근 곡면으로 닫힌다. 아래 크림색 돔 받침은 짧고 넓어 큰 좌석을 받친다. 보라색과 따뜻한 크림색의 단순한 두 부피가 포근한 공간 소품으로 읽힌다. 스파/화장대 세계의 작은 휴식 좌석으로 옮기는 것은 분석자의 적용 제안이다. 원작에 실제 뷰티 상품·효능·공간을 표시한 것은 아니다.

짧은 I2V 카메라 이동을 적용할 때는 좌석 안쪽 깊이, 두꺼운 테두리, 받침의 원형 홈을 유지하는지 검토한다. 원작은 정지 이미지이며 움직임을 직접 관찰하지 않았다. 일반 제품·문구·업무 인물을 계속 추가하기보다 큰 곡면·포근한 기본 조형을 우선했다.
