# 관리 제품 마스코트·두꺼운 꽃과 작은 CG 공간의 실제 관찰

공식 공개 3D 검색 고유 후보 219개 중 기존 원본 ID·해시 중복 141개를 뺀 새 이미지 78개를 13개 관찰판에서 모두 직접 관찰했다. 순수 3D 39개 선정, 그 외 39개 제외다. 실제 정지 이미지 한 장을 한 단위로 기록했다.

## 제작에 옮길 구조

- 치아·컵/티백 같은 제품형 머리와 짧은 몸을 결합해 원본 캐릭터의 비례만 독자 뷰티 마스코트에 적용한다. 형태와 표정의 정체성을 먼저 고정한다.
- 두꺼운 복셀 꽃잎·구형 과일과 돌출 잎은 원료 설명의 입체 토큰으로 옮길 수 있다. 자연 식품 사진과의 경계가 약한 매끈한 이미지에는 기대어 순수 3D를 단정하지 않는다.
- 작은 작업대·가판대·카페/관리 방은 벽·바닥과 큰 가구의 위치를 고정하고 같은 공간의 시점을 파생한다. 화면 안의 물건/인물을 분할해 세지 않는다.
- 같은 큰 머리와 귀/몸 구조의 포즈·표정·액세서리 변형은 전체 원본을 나란히 비교한 후 대표 하나로 통합한다. 원작 번호나 픽셀 거리만으로 대표를 정하지 않는다.
- 입체 소품의 작은 표면 표시와 별도의 넓은 사진·기능 UI를 구별한다. CG 주체가 앞에 있어도 큰 자연형/공예 촬영 배경이 미확정이면 전체 한 단위의 순수 3D를 보류한다.

13개 관찰판의 새 원본 78장을 전체 화면으로 직접 관찰하고 9개 전체 기본형 비교판과 1개 픽셀 근접 후보판을 직접 확인했다. 새 기본형 변형 19개를 기존 대표로 통합하고 형태가 다른 후보는 유지했다. 선정은 실제 화면의 스타일화 CG 시각 판정이며 개별 생성 모델·메시·리깅과 정지 이미지의 움직임은 미확인이다. 원본 전체 한 장을 한 단위로 유지한다.
