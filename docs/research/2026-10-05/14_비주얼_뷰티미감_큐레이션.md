> 공개본에는 원본 이미지·영상과 로컬 관찰판을 포함하지 않는다. ‘로컬 관찰 근거’는 저장소에 재배포하지 않는 로컬 관찰 자료를 가리킨다. 공개 출처 링크와 관찰·제작 제안은 보존하며, 문서별 과거 수량보다 [프로젝트 감사 집계](<../../../data/projects/finfluencer-beauty-etf/audit.json>)와 [스냅샷 매니페스트](<../../../manifests/snapshot.json>)의 집계가 최신 기준이다.

# 귀엽고 아름다운 3D — 직접 관찰 큐레이션

최신 범위는 명확한 3D 캐릭터·미니어처·입체 조형이며, 뷰티 제품과 따뜻하거나 말랑한 재질을 우선한다. 아래 23행은 기존 직접 관찰 원장 중 엄격한 3D 판정을 통과한 장면을 다시 선별한 것이며 새로운 참고 단위로 더하지 않는다. 제품의 실제 산업성/효능/투자매력과 연출 적용 판단은 분리한다.

## 제작근거를 비교하는 방법

Higgsfield 공식프리셋은 재현을 시작하기 편한 미리보기이지만 개별 원작의 정확한 생성모델/CG비율/편집가능3D모델은 미확인이다. Runway 공식큐레이션도 개별 모델 사용의 증거와 구별한다. Diffuse의Made with/PROCESS는 제작자의 공개 신고로 기록한다.

[DF0793 공개공정](<https://diffuse.runway.com/project/6183d88d-3004-4cef-b395-a0288ae499e9>)은 실촬영 마네킹을AI합성으로 바꾸고2D폰이미지로360회전을 만든 사례다. [DF0659 공개공정](<https://diffuse.runway.com/project/619abcca-6469-4907-8edf-c6abf5546a90>)은 큰조형·내부미니어처·2D직물을 별도레이어로 움직여 재합성한다. [DF0722 공개공정](<https://diffuse.runway.com/project/bae4bddf-238f-40a0-aac5-b570dc2d6345>)은 얼굴/번호/로고/경기동작을 함께 유지하며 참조 보조T2V·로컬애니메이션·후반수정을 적용했다고 설명한다. 서로다른공정을 모두 한프리셋 실행으로 재현한다고 보지 않는다.

모든 선택은 해당 원작의 전체1fps 순서 프레임을 직접 검토한 기록에 연결된다. 정확한 컷 프레임·속도·오디오·프레임간 보간은 별도 실시간 재생/확대 검토가 필요하다.18채널 설치 발췌는 공개본의6개3분할 구도로,5초 연속 모핑은1단위로 유지했다. 신규 정지 3D 이미지는 고유 원본 한 장=1단위로 기록하며 각 오브젝트/각도 패널을 따로 세지 않는다. 발견 목록·다운로드수·생성된 초수는 완료 집계가 아니다.
