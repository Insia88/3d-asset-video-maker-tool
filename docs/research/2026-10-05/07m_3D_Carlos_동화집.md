# Carlos Carvajal — 동화 집·캐릭터·입체 공간 분석

검토일 2026-10-04. [원작자 포트폴리오](<https://carloscarvajal.artstation.com/projects>)의 5개 상세 페이지를 직접 확인했다. 4개 페이지에서 공개 정지 이미지 21장을 2개 보드로 전부 관찰해 독립3D 디자인/환경 3개를 채택했다. 회전·과정·콘셉트·선화 중심 완성판 18장은 제외했다. Pau는 공개 동영상/Sketchfab만 있는 페이지로 이 정지 배치에서는 실제 영상 미관찰 0이다.

## 제작 근거

[Pau](<https://carloscarvajal.artstation.com/projects/DYvaKo>)는 Blender·Ucupaint·TexTools와 수동 리깅/핸드페인트를 명시하며 José A. Pérez 콘셉트를 별도로 밝힌다. [사원](<https://carloscarvajal.artstation.com/projects/98ymgQ>)은 Infinity27/Samsara용 기존 사원 자산을 허락 받아 재구성하고 외부 Epic Marketplace 환경을 혼합했다고 설명한다. 3Ds Max·RizomUV·ZBrush·Substance Painter와 Unreal의 렌더·빛·파티클 도구를 명시한다. 제작자가 전체 환경의 모든 자산을 만들었다고 확장하지 않는다.

[동화 집](<https://carloscarvajal.artstation.com/projects/JvADGz>)은 Charlène Le Scanff 콘셉트 기반 Animum 3D 과정, [Cartoon 인물](<https://carloscarvajal.artstation.com/projects/lVlL1e>)은 Anna Cattish 콘셉트 기반 Animum 캐릭터 모델링 과정의 결과다. [모카포트](<https://carloscarvajal.artstation.com/projects/Bkx2JD>)는 Isaac Jadraque 스케치 기반 로우폴리 메시 위 Blender5 Grease Pencil/EEVEE를 명시한다. AI 사용은 모두 미확인 전통 CG 비교자료로 구분한다. 게시일은 미검증이다.

## Higgsfield 적용 제안

집의 바닥·문·지붕과 캐릭터의 얼굴·몸·신발을 각각 잠근 정지 자산으로 시작한다. 광원/색 대비를 차용하고 작은 카메라 전진이나 문이 열리는 한 동작부터 시험한다. 이는 정지 자료에서 도출한 제안이며 실제 컷·이동속도·BPM·초점거리를 측정한 값이 아니다. 원작 모델이나 콘셉트의 동일 재현 권한은 확인하지 않았으므로 새 형태로 설계한다.
