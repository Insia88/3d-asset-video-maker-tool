> 공개본에는 원본 이미지·영상과 로컬 관찰판을 포함하지 않는다. ‘로컬 관찰 근거’는 저장소에 재배포하지 않는 로컬 관찰 자료를 가리킨다. 공개 출처 링크와 관찰·제작 제안은 보존하며, 문서별 과거 수량보다 [프로젝트 감사 집계](<../../../data/projects/finfluencer-beauty-etf/audit.json>)와 [스냅샷 매니페스트](<../../../manifests/snapshot.json>)의 집계가 최신 기준이다.

# 25,000개 장면·샷 조사 기준

목표는 원본 영상 수가 아니라 서로 다른 장면·샷 25,000개다. 분석 단위 확대는 2026-10-04 사용자 요청을 반영한다.

## 최신 우선순위

최신 사용자 요청에 따라 **새 수집은 3D만**, 미감이 뛰어나거나 귀엽고 뽀짝한 오브젝트·캐릭터·미니어처·공간을 우선한다. 뷰티 소재는 계속 우선하되 실사형 AI·2D 비교 자료 수집은 중단한다. 꽃·유체·크림·파우더·유리·금속의 입체 물성, 조명, 색채, 둥근 비례, 작은 세트의 규모, 형태의 일관성을 실제 화면에서 확인한다. 기존 실사·2D 기록은 과거 비교 자료로 보존하고 최신 25,000개 3D 목표에 합치지 않는다.

사용자가 제공한 3D 캐릭터 이미지와 최신 3D 이미지 요청을 반영해 정지 이미지도 참고 단위에 포함한다. 실제 관찰한 고유 3D 정지 이미지 또는 영상의 독립 3D 장면·샷만 센다. 캐릭터 시트 한 장은 한 단위이며 여러 각도 패널 수를 샷 수처럼 합치지 않는다.

## 완료로 집계하는 항목

원본 URL 또는 사용자가 제공한 로컬 파일, 관찰한 프레임 순서, 시간 범위, 장면별 설명, 3D·혼합·카메라·2D 분류, 뷰티 ETF 적용 판단이 모두 있는 독립 단위만 완료로 센다. 생성형 제작 여부는 게시자·제작자·공식 도구의 표기를 따로 기록한다. 3D처럼 보인다는 이유로 제작 방식까지 확정하지 않는다.

시간 범위는 실측 컷 경계와 관찰 프레임 사이의 추정 경계를 구분한다. 전체 영상에서 1초 간격으로 추출한 프레임을 관찰한 경우 `sampled_frame_sequence`로 표기한다. 해당 관찰로 소리·빠른 중간 컷·정확한 전환 곡선을 확인했다고 쓰지 않는다.

## 제외·병합 규칙

- 같은 연속 샷의 시간만 다른 캡처는 한 단위다.
- 다른 프리셋 이름·주소·인코딩으로 올라온 동일 영상은 대표 원본으로 병합한다.
- 리포스트와 원작은 별도 작품으로 세지 않는다.
- 자동 장면 탐지 결과, AI 분석의 구간 수, 갤러리 항목 수는 직접 분석 완료 수에 넣지 않는다.
- 재료·세트·행동·구도가 실질적으로 다른 독립 설명 장면은 한 작품 안에서도 각각 기록할 수 있다.
- 검은 화면, 로딩 화면, 동일 엔드카드 반복, 확인하지 않은 중간 구간은 제외한다.
- 2D·실사형 AI 카메라 샷은 비교 자료로 기록하되 3D 핵심 샷 수와 분리한다.

## 집계 열

`shot_id`, `source_id`, `source_url`, `start_seconds`, `end_seconds`, `boundary_basis`, `observed_frames`, `visual_description`, `materials`, `composition`, `camera_or_change`, `class`, `generative_provenance`, `beauty_etf_application`, `selection`, `duplicate_of`, `observation_status`.

`selection`은 적용 후보 / 보조 비교 / 제외의 세 가지다. 비교용 샷을 핵심 3D 후보처럼 제시하지 않는다. 수집 목록과 완료 원장을 별도로 유지한다.

## 앞선 범위와 최신 변경

앞선 사용자 응답은 3D 중심에 실사형 AI·2D 비교를 포함한 10,000샷이었으며 이후 25,000개로 확대됐다. 최신 요청이 이 범위를 **3D만**으로 변경했다. 목표 수는 `core3D`만 합산한다. 사진 배경·평면 전경이 섞인 `hybrid`는 명확한 입체 물체가 있어도 비교 기록으로 보존하며 25,000 목표에서는 제외한다. 앞선 혼합 포함 집계와 비교하면 범위 변경만으로 수치가 줄 수 있다.
