# 뷰티 ETF 영상에 사용할 입체 장면의 방향

누적 선정 장면은 **10,897개**이며, 이번 묶음에서는 57개 원본 중 26개를 선정했다. 나머지 31개는 중복, 화면 잘림, 배경 표현의 근거 부족 등으로 보류하거나 제외했다.

욕조와 소품을 갖춘 캐릭터는 익숙한 뷰티 루틴으로 시선을 모은다. 화장품 카트와 진열 공간은 여러 제품이 함께 놓이는 모습을 보여 주며, ETF가 여러 기업을 담는 바구니라는 설명으로 자연스럽게 이어질 수 있다. 작은 집과 정원은 장면 전환에 활용하되, 실제 산업 규모나 투자 수익을 대신하는 그림으로 사용하지 않는다.

정지 이미지에서 확인한 색, 재질과 공간 구성을 모션의 출발점으로 삼는다. 카메라 이동과 오브젝트 동작은 새 영상의 연출로 설계하며, 원작에서 해당 움직임을 관찰했다고 표현하지 않는다. 외부 원작의 AI 사용 표기만으로 제외하지 않으며, 전체 장면의 입체 표현과 독립 장면 기준을 확인한다. 창작자의 제작 설명, 편집 가능한 메시, 모델 실행과 사용 권리는 각각 확인해야 한다.
