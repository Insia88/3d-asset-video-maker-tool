# 공개 3D 캐릭터 원작 — NEON 3D 포트폴리오

검토일 2026-10-04. 원작 프로젝트 34개를 실제 공개 페이지에서 확인하고 정지 이미지 93개를 직접 관찰했다. 중복 크롭·같은 캐릭터 턴어라운드·제작 UI·모델 단계 등을 제외해 독립 3D 디자인/디오라마 42개를 채택했다. 제목이나 다운로드 수를 분석 완료 수로 대신하지 않는다.

## 출처와 관찰 범위

[NEON 3D 공개 포트폴리오](<https://neon3d.artstation.com/projects>)의 실제 링크를 따라 각 원문을 확인했다. 원작자 설명에는 Fusion360 T-spline/Solid 모델링, Zbrush 디테일, Blender Cycles 렌더, 실제 모델링/타임랩스 영상과 CAD 증거가 다수 명시된다. 순돌·한복·몰랑 인트로·젤리동물 등은 Blender 제작 근거가 확인된다. AI 사용 근거는 확인되지 않아 이 묶음은 전통 CGI 비교자료로 구분한다. 모델링 영상의 타임코드나 동작을 실제 재생하지 않은 채 분석했다고 쓰지 않았다.

작품에 표시된 2018~2019년 월은 제작자의 작업월이다. 웹페이지 공개일과 동일한 것으로 취급하지 않는다. Molang은 Hayanori/Millimages, RanRan은 HARI, 펭수는 fanart, Ryan은 Kakao Friends 캐릭터라는 원작 크레딧을 분리한다. 이후 제작 키 이미지는 이들의 캐릭터 디자인을 그대로 가져오지 않고 미감·구조를 참고해 고유 디자인으로 만든다.

## 귀여운 3D 미감의 공통 구조

둥글고 큰 머리 또는 타원형 몸, 짧은 팔다리, 작은 점 눈과 최소한의 입, 볼 색이 기본이다. 옷은 큰 외곽 실루엣 하나를 만들고 모자·단지·삽·컵 같은 소품은 1~2개만 둔다. 매트 고무 몸에 니트·털·분말·유리 같은 다른 표면을 붙여 촉감을 만든다. 배경은 파스텔 단색 또는 소규모 미니어처 세트이며, 그림자는 부드럽고 접지 관계가 명확하다.

순돌의 오렌지 방, 아이스크림 가게, 눈 캠핑섬은 winter-dome의 미니어처 공간 구성과 맞는다. 얼음섬·마트료시카·젤리접시는 ETF 바구니 구조를 입체로 설명하기 좋다. 단순 귀여움과 금융 의미를 연결할 때는 한 장면에 기업/ETF/성장 등 한 설명 단위만 둔다. 캐릭터가 많아지면 각 기업을 기억하는 데 방해가 되므로 주요 역할 3개 안팎으로 제한하는 제작 설계를 제안한다.

## Higgsfield 키 이미지와 I2V 적용

- 캐릭터 키 시트: 정면·3/4·측면을 한 시트에 정리하되 수집 원장에서는 같은 캐릭터 1단위로 취급한다. 머리/몸 비율·눈 간격·볼 색·소품 위치·재질을 고정한다.
- 공간 키 이미지: 오렌지 홈카페나 파스텔 아이스크림숍처럼 벽 두 면을 잘라 보여주는 작은 세트를 먼저 만든다. 캐릭터가 매 컷 새 방으로 바뀌지 않도록 책상·주광 방향·팔레트를 유지한다.
- 동작: 한 번의 작은 고개 기울임, 토큰 한 개 놓기, 단지 안 조각 한 개 넣기처럼 3~5초 안에 끝나는 행동을 우선한다. 정지 자료만 본 사례에 원작의 카메라 속도나 BPM을 부여하지 않는다.
- 재질: matte toy-like body, soft knit fabric, translucent jelly, glass bubbles, pastel miniature room, soft contact shadows 등의 물성 지시를 역할별로 제한한다. 고무 몸+니트 의상+투명 유리처럼 큰 재질 차이 2~3개로 읽히게 한다.
- 금융 텍스트·비중·상품명은 후편집에서 넣는다. 생성 이미지 안의 글자나 특정 원작 로고에 의존하지 않는다.

## 집계와 중복 확인

93개 원본 이미지가 42개 독립 참고 단위로 줄어든 주요 이유는 동일 장면의 PC/스마트폰 크롭, 같은 캐릭터의 단독/그룹·앞/뒤·여러 방향 시트, 텍스트 추가, 동일 캐릭터 복제 배열, CAD/모델링 단계다. 개별 관찰 행의 duplicate_of와 제외 사유를 보존한다. 여러 의상 컨셉은 외곽 조형과 소품이 실제로 다른 독립 디자인만 남기고, 동일 겨울 패딩 디자인의 색·패턴 변경은 제외했다.

공개 CDN 다운로드는 일반 비인증 요청으로 HTTP200을 확인했다. 포트폴리오 페이지에 대한 일반 HTTP 요청의403은 우회하지 않고 정상 브라우저 UI로 확인했다. 브라우저 자산 번들의 CORS fetch 실패는 로그인 차단이 아니며, 동일 공개 이미지 URL의 일반 HTTP200 응답으로 저장했다. 비공개 제작 영상은 열지 않았다.

각 관찰의 실제 증거는 evidence_contact_sheets에 저장한 11개 리뷰 보드와 원본 이미지다. 전체 이미지 원장 shots_plus_3d_images.jsonl은 앞선 Dior/Florals 34행과 이 묶음93행을 합쳐127행, 독립3D50개다. 앞선65표본과 이 묶음93정지를 합쳐 실제 직접 관찰158표본이다. 표본 수는 완료 단위 수가 아니다.
