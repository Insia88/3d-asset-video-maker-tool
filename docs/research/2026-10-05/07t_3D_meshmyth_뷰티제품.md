# meshmyth: 뷰티 제품 구조와 입체 광고 세트

확인일: 2026-10-04. 공개 [원작자 포트폴리오](<https://meshmyth8.artstation.com/>)에 실제로 표시된 16개 프로젝트의 완성 이미지와 과정 이미지를 교차 관찰했다. 정상 공개 CDN 원본 80장을 확보하고 7개 접촉 시트의 모든 이미지를 직접 확인했다. 독립 제품·진열 세트 13개를 채택하고 67장은 같은 제품의 각도·크롭·색·재질 변형 또는 와이어/클레이/재질 과정으로 제외했다.

모든 채택 단위는 **core3D**, 출처는 **전통 CG 비교·AI 사용 미확인**이다. Blender 및 Cycles는 제작자 원문이고, 와이어와 클레이는 입체 모델의 추가 근거다. 작가의 도구 설명은 AI 부재를 증명하지 않는다. 게시일은 미검증이며 CDN 숫자에서 추정하지 않았다. 정지 이미지에서 카메라 이동, 컷 속도, BPM을 측정하지 않았다.

## 교차 검증과 생성 준비에 유용한 판단

CG451은 완성 2장과 와이어·클레이·재질뷰 각 2장으로, 닫힌 케이스와 열린 립의 동일 기본형을 확인했다. CG457은 CG456 세럼의 재사용이 분명하지만 유리 문·프레임·망치·사슬로 새 공간을 만들었다. 병 한 개의 색 변형과 구분되는 이유다.

CG452와 CG454는 나선 띠/돌 받침이 달라도 같은 원통 향수 제품이므로 한 번만 포함했다. CG458과 CG460 역시 물 막/매크로의 연출 차이를 비교 원장에 남기되 제품 디자인 추가 수에는 포함하지 않았다. CG461은 라벨·유리 색·용도가 바뀌지만 기본형 차이가 확실하지 않아 보수적으로 제외했다. 반면 CG463의 직선 긴 병·낮은 원통 캡과 CG464의 사각 병·짧은 목·납작한 금속 캡은 형태 차이가 명확하다.

가장 우선할 형태는 **CG451 둥근 분홍 립스틱 → CG456 보라 사각 세럼 → CG462 노란 튜브**다. 기본 형태가 충분히 달라 여러 기업·품목을 묶는 ETF 바구니를 읽히기 쉽다. CG457의 유리함과 CG452의 띠는 제품 위에 덧붙는 설명 공간으로 참고할 수 있다. 이는 관찰 기반의 새 제작 방향이며 원작의 복제 자산을 의미하지 않는다. 정지 원본의 읽힌 면·곡률·물성을 잠근 뒤 움직임을 별도 설계한다.

브랜드·성분·SPF와 광고 효능 문구는 원작의 라벨이다. 실제 고객 계약, 효능, 특정 ETF 편입 기업 또는 투자 수익률을 검증한 증거가 아니다. 원문 “commercial-style” 표현을 실제 유료 고객 광고로 바꾸어 적지 않았다.

검색에서 발견한 이전 샴푸/세럼 페이지 [oJgvRJ](<https://meshmyth8.artstation.com/projects/oJgvRJ>)는 정상 원작자 페이지에서 404가 확인되어 CG465 후보의 실제 관찰 수는 0이다. 정상 접근 없이 이미지나 개수를 추정하지 않았다.
