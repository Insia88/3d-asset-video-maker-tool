# IconScout 향 받침·큰 꽃과 곡선 조형의 입체 구성

공식 Aromatherapy 3D Icons 검색에서 새로 확인한 실제 미리보기 70장을 직접 개별 관찰하고 7장을 선정했다. 기본 조형이 겹치는 색·자세·작은 소품 변형 56장은 대표 원작으로 묶었고, 현재 뷰티·귀여운 미감의 우선순위가 낮은 7장은 제외했다. 팩 표지는 집계하지 않았으며 여러 도구가 함께 있는 이미지도 한 장이 한 단위다.

선정 원작 7개는 개별 공개 페이지의 제작자와 3D 파일 제공 형식 문구를 직접 확인했다. 이 자료는 공식 3D 디자인 에셋 미리보기이며 원작의 AI 제작/특정 모델은 미확인이다. 사이트의 AI 편집·생성 버튼을 원작 제작의 증거로 사용하지 않았다. 제공 형식 표기는 실제 메시 파일을 열어 검증한 결과와 구분한다.

## 큰 제품 조형과 향 소품의 공간 관계

- 낮고 넓은 민트 향 접시/작은 중앙 받침과 긴 목의 납작한 병은 열린 공간과 닫힌 외피의 비율을 구분한다. 실제 메시·향/연소나 내용물 효능을 확인한 결과는 아니다.
- 제품 밖으로 크게 감긴 녹색 나선 줄기/노랑 꽃과 두꺼운 감귤 단면/투명 방울은 제품→큰 자연 세계의 관계를 만든다. 원작 이미지 하나의 꽃·마디·방울 수를 단위로 늘리지 않는다.
- 각진 윗컵/허리가 좁은 받침의 금색 향로는 단순 원형 향병과 다른 실루엣을 만든다. 복잡한 삼각 무늬는 관찰되지만 실제 관통 메시 구조로 단정하지 않는다.
- 독립 금색 기둥 셋/초 배열과 한 기둥에서 갈라지는 큰 곡선 팔/나선은 서로 다른 지지 구조다. 정지 원작에서 반사/불꽃의 움직임이나 실제 재질을 확인했다고 주장하지 않는다.
