> 공개본에는 원본 이미지·영상과 로컬 관찰판을 포함하지 않는다. ‘로컬 관찰 근거’는 저장소에 재배포하지 않는 로컬 관찰 자료를 가리킨다. 공개 출처 링크와 관찰·제작 제안은 보존하며, 문서별 과거 수량보다 [프로젝트 감사 집계](<../../../data/projects/finfluencer-beauty-etf/audit.json>)와 [스냅샷 매니페스트](<../../../manifests/snapshot.json>)의 집계가 최신 기준이다.

# Icons8 작은 3D 공간과 분리 소품 관찰

공개 원작 I8S0118–I8S0156의 39장을 직접 관찰해 독립 순수 3D 시각 참고 6개를 선정했다. 같은 공간의 분리 가구·구성물 24개는 대표에 묶었다. 사진·별도 일러스트가 섞인 독립 공간 7개와 포근한 뷰티 미감에 맞지 않는 독립 공간 2개는 목표 수량에서 제외했다. 한 방의 가구 개수와 관찰판의 패널 개수는 추가 수량이 아니다. 전체 프로젝트의 최신 수량은 [집계와 검증](<06_%EB%B9%84%EC%A3%BC%EC%96%BC_%EC%A7%91%EA%B3%84%EC%99%80_%EA%B2%80%EC%A6%9D.md>)에서 확인한다.

## 공식 분류와 실제 관찰의 구분

[Icons8 공식 3D styles](<https://icons8.com/illustrations/styles/3d>)에서 3D Rooms 분류를 확인한 뒤 [3D Rooms 공개 원작 목록](<https://icons8.com/illustrations/style--3d-rooms>)의 개별 원작 URL·공개 미리보기 주소·공식 스타일명을 읽었다. 공개 목록의 총수는 발견 메타데이터이며, 이 문서의 39장 수는 실제 픽셀을 직접 관찰한 기록이다.

정상 공개 미리보기 전체를 순서대로 보며 절단 벽·받침·가구의 두께와 곡면, 재질, 접지 그림자, 창 밖의 배경, 액자·화면 안의 사진과 그림을 확인했다. I8S0120·0128·0142·0148·0153은 원본 이미지도 확대 관찰했다. 세부 목재·돌·직물 텍스처는 입체 물체의 표면으로 구분했다. 별도 사진 액자와 넓은 게임 일러스트 면이 함께 보이는 자료는 혼합 비교로 보존했다.

I8S0142 개별 상세에서 작가 [Julia Buzatti](<https://icons8.com/illustrations/author/cj62pzCRUq1N>)를 실제 확인했다. 다른 원작의 개별 작가는 미확인으로 남겼다. 공개 3D 스타일 분류와 원본 픽셀의 체적 판단은 생성형 AI·제작툴·렌더러·편집 가능한 메시의 확인 근거와 구분한다. 이 자료에서는 해당 제작 스택과 실제 모션을 확인하지 않았다. 출판자 워터마크는 관찰 표식이며 작품의 새 오브젝트로 계산하지 않았다.
