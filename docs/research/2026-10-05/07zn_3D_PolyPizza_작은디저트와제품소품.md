# Poly Pizza — 작은 디저트와 제품 소품

[Quaternius의 Ultimate Food Pack](<https://poly.pizza/bundle/Ultimate-Food-Pack-h3WC1gyRb4>)에서 실제 공개 렌더 **50개를 보드 5개에서 모두 직접 관찰**했다. 독립 순수 3D 기본형 **29개**를 선택했고, 부분/색/내용물/높이 변형 8개와 미감 방향이 약한 일반 조리 자료 13개를 제외했다. PP00181–PP00230에 기록했다. Poly Pizza 누적은 **실제 관찰 230개 / 선택 기본형 131개**다.

이 원작은 화장품이 아닌 음식·음료용 소품이다. 직접 뷰티로 분류하지 않고 귀여운 제품 미감의 비교 자료로 기록했다. 원문은 over 50 food and drink models, FBX/GLB, CC0를 설명하며 업데이트 날짜 2023-05-16을 표시한다. 실제 제작 프로그램과 생성AI 사용 여부, 개별 최초 공개일은 미검증이다. 모델 총수 표시는 완료 수가 아니며, 실제 원본 50개를 모두 본 뒤 기록했다.

삼각 피자 조각 PP00189는 전체 PP00230에, 토마토 단면 배열 PP00197은 전체 PP00196에, 식빵 단면 PP00213은 전체 PP00224에 통합했다. 갈색/분홍 막대 아이스크림, 버거의 치즈 층수/채소 내용물, 병 색과 길이, 냄비 높이 변화도 각각 대표 하나로 합쳤다. 메시가 정확히 같다는 주장과 관찰한 기본 구조 통합은 구별했다.

계란·버섯 단면·접시·숟가락·스테이크·프라이팬·베이컨·닭다리·냄비·갈색 막대 음식·부분 촉수·젓가락은 실제 3D로 확인한 사실을 남기고 선택 수량에서 제외했다. 특히 단순 기본 난형이나 얇은 일반 조리물을 귀여운 뷰티 참고 수량으로 늘리지 않았다.

Higgsfield 자산 설계에는 컵케이크의 위·아래 비율, 도넛의 두꺼운 구멍, 와플/초콜릿의 홈과 돌출, 작은 컵의 뚜껑·빨대처럼 장면에서 명확히 읽히는 구조를 참고할 수 있다. 재료나 향의 이미지로 사용하더라도 실제 화장품 성분·효능을 이 참고 이미지에서 추론하지 않는다. 제작에서는 독자 무표기 용기와 마스코트 형태로 재설계하며, 원작은 정지 렌더이므로 실제 카메라 이동과 변형 동작을 관찰했다고 기록하지 않았다.

근거는 `shots_plus_poly_pizza.jsonl`과 `evidence/3d_images/plus/poly_pizza/pp011/`의 원본 50개·실제 관찰 보드 5개다. 기존 선택 기본형 617개와 교차한 해시 후보 네 쌍은 실제 원본을 모두 대조했다. 숟가락/여우, 베이컨/여우, 긴 목의 일반 병/잘록한 두 구간의 장식 병은 서로 다른 조형이다. 검은 일반 병은 별도로 초록 병 기본형에 이미 통합되어 수량 0이다. 정상 공개 UI 렌더만 확인했고 API·로그인·키 생성·메시 다운로드·구매·이미지/영상 생성은 모두 0이다.
