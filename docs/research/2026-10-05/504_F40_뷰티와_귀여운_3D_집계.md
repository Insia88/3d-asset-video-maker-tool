# F40 · 뷰티 공간과 제품을 잇는 3D 참고

직접 관찰한 고유 3D 참고는 **10,270개**다. 앞선 10,266개에 전체 이미지 **4개**를 더했으며, 목표 25,000개까지 **14,730개**가 남아 있다. 이번에는 전체 이미지 38개를 관찰해 4개를 선정하고 34개를 제외하거나 보류했다.

생활 속 세면 공간에서 보송한 작은 무대로, 다시 용기와 재질의 세계로 시선을 옮긴다. 벽돌과 목재의 거친 표면, 토끼의 부드러운 털, 튜브와 유리 구조의 반사, 금속 잎과 투명 방울의 가림 관계를 살폈다. 뷰티 제품에 대한 관심이 제품을 만드는 사업과 ETF 바구니의 개념으로 이어지도록 활용할 수 있는 참고다.

선정한 네 장은 각각 별도 검수자가 원본 전체와 가까운 기존 대표를 대조했다. 통합 전 네 후보를 다시 관찰해 내부 여섯 쌍을 비교하고 파일·픽셀 검사를 더했다. 기존 32,823개 기록과 선정 항목은 보존했다. 과거 라이브러리의 모든 이미지 쌍을 다시 관찰했다는 뜻은 아니다.

원작 전체 이미지 한 장이 한 단위다. 패널·소품·작은 변형·비교판·다운로드·제작용 생성 에셋을 새 수량으로 더하지 않는다. 시각적 입체 표현, 제작자의 CG 설명, 생성 모델의 실행, 편집 가능한 메시, 재사용 권리는 각각 구분한다.
