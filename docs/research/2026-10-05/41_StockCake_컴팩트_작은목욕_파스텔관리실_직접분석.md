# StockCake — 컴팩트·작은 목욕·파스텔 관리실 조형

[StockCake 공식 공개 MCP 안내](<https://stockcake.com/info/mcp>)의 read-only 검색으로 clay vanity cabinet / kawaii makeup bag / clay bubble bath / cute compact mirror / pastel bathroom를 확인했다. 주제별 공개 페이지1–5, 페이지당12개 제한을 지켰다. 같은 원본 ID는 준비 단계에서 하나로 묶었다. 원본 이미지를 직접 관찰한 뒤 명확한 순수 core3D 조형/디오라마와 미감·귀여움을 기준으로 선정한다. 사진/평면 혼합형은 비교 기록만 남기고 선정 수량에서 제외한다.

현재 고유 후보 1개 중 **실제 개별 관찰 1개, 3D 선정 0개, 제외 1개**다. 남은 0개는 미관찰이며 집계하지 않는다. 이미지 한 장은 한 단위이며 캐릭터 수/패널 수로 늘리지 않는다.

이미지는 원본의 미리보기이며 특정 생성 모델/편집 가능한 3D 메시 제작은 미확인이다. 별도 원작 메타데이터를 확인한 항목은 JSONL에 official_individual_metadata로 표시했다. 영상 모션은 분석자의 제안이고 실제 영상 관찰을 뜻하지 않는다.
