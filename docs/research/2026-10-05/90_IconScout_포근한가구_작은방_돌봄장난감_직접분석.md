# IconScout 포근한 가구·작은 방·돌봄 장난감

[공식 검색](<https://iconscout.com/3d-icons/cute-room>)의 공개 미리보기 69장을 직접 개별 관찰해 15개 대표를 선정했다. 기본 조형의 색/각도/작은 부품 변형 47개는 대표에 묶고 우선순위가 낮은 7개는 제외했다. 팩 표지는 집계하지 않고 원본 이미지 한 장을 한 단위로 보았다.

정상 Chrome의 cute-room 첫 페이지와 실제 Next Page 링크를 따라 두 번째 페이지의 원작 카드 160개를 확인했다. 첫 페이지에서 pageAssets로 전체 공개 PNG 70장을 보존했고 기존 이미지 1장을 제외한 새 69장을 12개 관찰 보드로 모두 직접 보았다. 첫 페이지 10개와 두 번째 페이지 80개의 전체 미리보기는 보존하지 못해 미관찰로 분리하고 수량 0으로 남겼다. 선정 15개 원작은 개별 상세의 제작자·제공 형식을 확인했다.

공식 3D 분류 및 제공 형식과 실제 메시 검증은 구분한다. 원작 AI 제작/특정 모델은 미확인이며 AI 편집·생성 버튼이나 범위가 불명확한 About 문단 표기로 원작 제작 모델을 추정하지 않는다.

## 구성과 적용

귀여운 방이라는 검색어는 독립 공간 외에 아동 인형·서 있는 태블릿 인물·단품 침대·선인장·의자도 섞어 보여주었다. 실제 벽·바닥·큰 가구를 기준으로 따뜻한 아기방과 두꺼운 갈색 코너 방을 남겼고, 단품 가구는 둥근 캡슐 소파·큰 홈의 원통·높은 트레이 의자처럼 주인공 부피가 다른 경우에만 남겼다. 침대의 이불 색, 소파 인형의 자세, 같은 모자 인형의 손 동작, 화분 선인장의 꽃·가지 수는 대표에 묶었다.

뷰티 적용 우선순위는 세 단의 관리 선반·둥근 소파/스탠드·포근한 노트북 인형·작은 나무 방이다. 병·장갑은 공식 원작 용도가 반려동물 돌봄이며 일반 화장품 기능으로 기록하지 않는다. 작은 유령·호박 방은 향수/포션 색과 연결하는 상상 장면의 제안으로만 사용한다. 모빌은 별·구름·무지개가 여러 부품으로 구성되어도 전체 이미지 한 장이며 부품 수를 참조 수로 늘리지 않는다.

원본 정지 이미지가 보여주는 것은 닫힌 입체 외형·재질 표현·광원의 관계다. 이미지 기반 작업에서는 큰 가구·머리·모자부터 고정하고 가는 모빌 끈·의자 바퀴·거울 반사·작은 도구의 유지 여부를 따로 확인해야 한다. 실제 움직임·편집 가능한 메시·제작 도구·AI 모델은 확인하지 않았고 현재 생성 호출은 없다.
