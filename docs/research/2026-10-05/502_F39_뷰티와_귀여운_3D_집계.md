# F39 · 뷰티 제품과 재질을 읽는 3D 참고

직접 관찰한 고유 3D 참고는 **10,266개**다. 앞선 10,262개에 전체 이미지 **4개**를 더했으며, 목표 25,000개까지 **14,734개**가 남아 있다. 이번에는 전체 이미지 15개를 관찰해 4개를 선정하고 11개를 제외하거나 보류했다.

세럼 전시의 층진 곡면, 향수와 꽃잎의 가림 관계, 욕실의 서로 다른 표면 재질, 과일 조각 사이에 떠 있는 튜브를 살폈다. 뷰티 제품에서 출발해 제품을 만드는 사업의 역할과 ETF 바구니의 개념으로 시선을 이어 주는 장면에 활용할 수 있다. 화면 속 브랜드와 제품을 복제하거나 소품의 수와 크기를 실제 투자 비중으로 읽지는 않는다.

선정한 네 장은 별도 검수자가 전체 원본과 가까운 기존 대표 12개를 비교했다. 후보끼리의 여섯 쌍도 살폈으며, 파일과 픽셀 검사를 더했다. 기존 32,808개 기록과 선정 항목은 그대로 보존했다. 전체 라이브러리의 모든 이미지 쌍을 다시 관찰했다는 뜻은 아니다.

원작 전체 이미지 한 장이 한 단위다. 패널·소품·작은 변형·비교판·다운로드·제작용 생성 에셋은 새 수량으로 더하지 않는다. 화면의 입체 표현, 제작자의 CG 설명, 생성 모델의 실제 실행, 편집 가능한 메시, 재사용 권리는 서로 구분한다.
