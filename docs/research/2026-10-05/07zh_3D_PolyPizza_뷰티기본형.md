# Poly Pizza — 로고 없는 low-poly 뷰티 기본형

[Poly Pizza 공개 검색](<https://poly.pizza/search/cosmetics>)에서 화장품 전용 원작을 찾고 [MilkAndBanana의 Makeup Assets](<https://poly.pizza/bundle/Makeup-Assets-sOm4U07WCB>)를 직접 열었다. 원작자는 이를 3D low-poly 화장품 묶음으로 설명하며 FBX/GLB 지원, 하나의 texture atlas와 세 가지 재질을 명시한다. 이는 실제 메시나 프로그램 파일을 검사한 결과가 아니라 공개 제작자 설명이다. 생성AI 사용 여부는 미확인으로 유지한다.

묶음의 실제 개별 공개 렌더 43개를 네 개의 보드에서 모두 직접 관찰했다. 서로 다른 기본형 **34개**를 선택하고 색·소재·크기·열림/닫힘·팬 행수 변형 9개를 통합했다. 사이트 전체의 10,700+ 모델 수, 검색 결과 수, 묶음 카드의 43 모델 표시를 자동으로 완료 수로 삼지 않았다. 선택 단위는 독립 제품 렌더이며, 같은 이미지 안 여러 부품을 분리해 추가하지 않았다.

## 접근과 근거의 범위

[공식 API v1.1 문서](<https://poly.pizza/docs/api/v1.1>)는 앱 생성과 `x-auth-token` API 키를 요구한다. 따라서 API 요청, 앱 생성, 키 생성, 로그인을 하지 않았다. 정상 공개 검색 UI와 원작 묶음 화면을 사용했고, 본문에 표시된 이미지 URL만 근거로 저장했다. 메시 다운로드 버튼이나 외부 유료 광고 카드도 사용하지 않았다.

향수 항목은 공개 상세 대화상자에서도 열어 3D 뷰어가 로딩되는 상태를 확인했다. 다만 뷰어의 삼각형 수·광원·렌즈·움직임을 측정하지 않았으며, 전체 43개 각각의 메시를 검사했다고 기록하지 않았다. 실제 관찰한 공개 렌더는 모두 709×418 정지 이미지다. 묶음에 표시된 업데이트 날짜는 2022-07-11이며 개별 모델의 최초 게시일은 확인하지 않았다.

## 뷰티 ETF 영상의 자체 조형으로 적용하기

이 묶음의 강점은 브랜드 인쇄와 사실적인 피부 없이도 제품군이 읽히는 단순 실루엣이다. 처음 등장하는 장면에서는 펌프·컴팩트·브러시·향수를 같은 무표기 화장대 위에 두면 뷰티 산업의 범위가 빨리 전달된다. ETF의 구성 종목 설명은 같은 팔레트 틀 안 여러 팬을 배치하는 구조로, 단일 기업과 바스켓의 차이는 하나의 용기와 여러 소품을 담은 작은 수납장으로 표현할 수 있다. 투자 수치 자체는 별도 공식 근거를 확인한 자막으로 설명해야 하며 이 조형만으로 수익이나 위험이 보장되는 인상을 만들지 않는다.

Higgsfield용 기초 이미지에서는 다면체 경계를 유지하되 실제 사용자 취향에 맞춰 모서리를 조금 더 둥글게 하고, 큰 머리·짧은 몸의 자체 마스코트와 같은 파스텔 소재 체계에 맞춘다. 기존 원작의 색을 바꾼 복제물 대신 용기의 비례·캡·받침 구조를 독자적으로 설계한다. 이번 단계에서 새 이미지·영상 생성은 수행하지 않았다.
