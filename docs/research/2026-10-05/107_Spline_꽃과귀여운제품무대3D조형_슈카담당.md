> 공개본에는 원본 이미지·영상과 로컬 관찰판을 포함하지 않는다. ‘로컬 관찰 근거’는 저장소에 재배포하지 않는 로컬 관찰 자료를 가리킨다. 공개 출처 링크와 관찰·제작 제안은 보존하며, 문서별 과거 수량보다 [프로젝트 감사 집계](<../../../data/projects/finfluencer-beauty-etf/audit.json>)와 [스냅샷 매니페스트](<../../../manifests/snapshot.json>)의 집계가 최신 기준이다.

# Spline 꽃과 귀여운 제품 무대 3D 조형 관찰

Elif öztürk의 정상 공개 Work UI에 보이는 신규 원작 **20장** 전체 미리보기와 개별 상세 **20개**를 직접 확인했다. 독립 순수 CG 스타일 전체 조형 **13개**를 선정했다. 가까운 기본형 변형 **3개**, 큰 평면 그래픽 혼합 **1개**, 미감 우선순위 제외 **2개**, 넓은 달 영역 체적 확인 보류 **1개**는 목표 수량0이다. Spline 누적은 **110장 관찰·46개 선정**이다.

프로필의 Work **61** 표시를61장 관찰로 바꾸지 않았다. 정상 화면에서 실제 링크/미리보기가 노출된20원작만 이번 배치의 직접 관찰/개별 검증 대상이다. 이미 기록한 SPC0051의 같은 작가 표기는 그 한 원작의 앞 관찰이며 이번20개 URL과 별도로 구분했다. [Spline 원장](<../../../data/projects/finfluencer-beauty-etf/references/index.json>), [앞 젤리/제품형 배치](<101_Spline_%EC%A0%A4%EB%A6%AC%EC%99%80%EA%B7%80%EC%97%AC%EC%9A%B4%EC%A0%9C%ED%92%88%ED%98%953D%EC%A1%B0%ED%98%95_%EC%8A%88%EC%B9%B4%EB%8B%B4%EB%8B%B9.md>), [앞 작은 방/유리 정원](<99_Spline_%EC%9E%91%EC%9D%80%EB%B0%A9%EA%B3%BC%EC%9C%A0%EB%A6%AC%EC%A0%95%EC%9B%903D%EC%A1%B0%ED%98%95_%EC%8A%88%EC%B9%B4%EB%8B%B4%EB%8B%B9.md>), [최신 합산/검증](<06_%EB%B9%84%EC%A3%BC%EC%96%BC_%EC%A7%91%EA%B3%84%EC%99%80_%EA%B2%80%EC%A6%9D.md>)에 연결한다.

## 원작 출처와 실제 시각

[Elif öztürk의 공개 Work 포트폴리오](<https://community.spline.design/@elif>)의 정상 UI에서 카드 원작 링크·작성자·공개 미리보기 주소를 읽었다. 각20개 상세에서 작성자·**Made in Spline**·공개 iframe·**CC BY 4.0** 링크·실제 상대 날짜를 확인했다. 로그인/Remix 실행이나 원작 모델/코드 취득은 하지 않았다.

| 직접 확인 | 범위 | 수량/해석 |
|---|---|---|
| 전체 미리보기20장 | 큰 외피·옆면/닫힌 연결·기둥/받침·꽃/잎/용기의 부피·전체 배경 | 실제 관찰20, 독립 선정13 별도 |
| 개별 공개 상세20개 | 표시 작성자·Made in Spline·현재 CC BY4·iframe | 도구/권리 표시 출처, 순수3D 전체 시각/AI 모델/메시 자동 확인 아님 |
| 원본 별도 교차2개 | SPC0093 헤어 빗/꽃·SPC0096 전화부스/꽃 수레 | 독립 검토 보강, 추가 단위0 |
| 기본형 대조 | SPC0054 카운터 주방·I8S0392 스노볼·SPC0101 음식 진열 | 가까운 배치/소품/표면 변경0, 동일 메시나 저작자 주장 아님 |

공개일은 SPC0091의 `2 years ago`, 나머지19개의 `3 years ago` 현행 상대 표시로 저장했다. 미리보기 URL 시각은 원작의 정확한 공개일로 변환하지 않았다. animation·cute·3d 태그와 댓글을 재생 관찰/동작 길이·BPM·카메라 키프레임·생성 모델의 검수로 가져오지 않는다. 모든 개별 생성형 AI 모델·학습 데이터·원본 메시/리깅은 미확인이다.

## 변형·평면 혼합·확인 보류

- SPC0098은 카운터/앞 스툴/뒤 수납의 기본 주방 **SPC0054**에 통합했다. L자 방향·스툴 수/색·기기/벽 부속 변경은 추가 단위0이다.
- SPC0102는 둥근 받침·큰 그릇/두 부푼 음식·옆 작은 진열의 가족 **SPC0101**에 통합했다. 음식 종류/그릇 높이·표면 링을 바꿔 수량을 늘리지 않았다.
- SPC0103은 투명 구/내부 겨울 나무·층진 받침의 **I8S0392** 스노볼에 통합했다. 내부 집/나무 수·썰매/색과 눈 입자가 추가 단위가 아니다.
- SPC0100은 입체 캔에 넓은 평면 그래픽 배경이 섞여 혼합 비교0이다. 캔 부피만 추출한 새 대표를 만들지 않았다.
- SPC0095·SPC0105는 CG 부피와 귀여운 꽃/잎 장식이 있어도 큰 검/총 실루엣이 이번 포근한 뷰티/제품 조형의 미감 우선순위에 낮아 제외했다.
- SPC0107은 작은 유령/호박의 부피가 보이지만 넓은 뒤 달의 전체 체적이 정지 이미지에서 확정되지 않아 확인 보류0이다. 제목/제작 표시로 달을3D 구체라고 보완하지 않는다.
