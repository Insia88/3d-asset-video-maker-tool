# 반복 가능한 3D 영상 조사·제작 순서

## 1. 범위와 형식 정하기

프로젝트마다 대상 채널·영상 길이·설명할 질문·최종 매체·선정 미감을 기록한다. 현재 뷰티 ETF 프로젝트는 PLUS KR와 슈카친구들·머니코믹스의 A–Z 분석을 같은 기준으로 비교하고, 작은 화장대에서 제품→기업→ETF 바스켓으로 공간을 확장한다.

## 2. 원작을 발견하고 실제 화면 관찰하기

공식 채널·작가 포트폴리오·공개 갤러리에서 원작 URL과 개별 이미지·영상 출처를 확인한다. 다운로드·검색 결과 수는 준비 수로 관리한다. 실제 원본 또는 읽을 수 있는 관찰판을 열고 주체 비례, 앞뒤 면·두께, 재질, 조명, 공간 배치, 제작에 옮길 구조를 기록한 뒤 관찰 완료로 바꾼다.

정지 화면에서 움직임을 추정하지 않는다. 영상은 확인한 타임라인 범위·순서·샷 경계를 기록하고, 정지 프레임 분석과 실시간 재생·음성 청취를 구분한다. AI 표기·모델 표시·다운로드 가능한 3D 파일·실제 메시 확인도 각각 구분한다.

## 3. 선별하고 중복 합치기

3D 전용 프로젝트에서는 실사·2D·혼합 화면과 입체 미확인 후보를 제외한다. 전체 장면의 일관된 3D 조형과 프로젝트 미감을 실제 화면에서 판단한다. 원본 ID, 파일 해시, 디코딩 픽셀을 대조하고 같은 기본 조형의 미세 변형은 대표를 직접 지정한다. 경계 사례는 다른 검토자가 원본을 열어 판단과 이유를 남긴다.

원작 전체 이미지·모델 시트·독립 장면은 각각 한 단위다. 시트의 패널·한 장면의 소품·연속 변형 중간 프레임을 수량으로 분할하지 않는다.

## 4. 감사하고 저장소에 가져오기

로컬 원장에서 관찰·근거·선정 조건을 확인한 뒤 고유 완료 수와 남은 수를 갱신한다. 감사 시점의 선정 원장과 문서를 `tools/import_research.py`로 가져오고 `tools/validate_library.py`로 확인한다. 내보낸 행 수와 감사 수가 일치해야 한다.

수집 목표가 충족되지 않으면 상태를 진행 중으로 유지한다. 발견 수·준비 수·제외 수는 완료 수와 함께 별도 기록한다. 원작의 라이선스가 변경되거나 기존 선정이 잘못됐음을 확인하면 실제 근거를 재검토하고 대표·상태·감사를 갱신한다.

## 5. 마스터 에셋 고정하기

수집 완료 뒤 핵심 캐릭터·제품·공간의 수와 좌표를 먼저 정한다. [Higgsfield 세팅 순서](higgsfield-foundation.md)에 따라 단일 전신 마스코트→Element→각도·표정 파생, 공간 사선 마스터→탑뷰, 제품·바스켓 독립 마스터를 만든다. 실제 결과를 열어 비례·손발·소품 수·재질·조명·여백을 확인한 항목만 재사용한다.

## 6. 영상으로 옮기고 검증하기

잠긴 이미지에서 I2V로 한 번에 하나의 행동을 만든다. 컷 길이·제품 근접과 전체 공간의 교대·연결 형태로 속도감을 설계한다. 숫자를 읽는 구간은 안정된 카메라와 정확한 편집 자막을 사용한다. 영상 결과의 캐릭터·제품·세트 일관성, 자막 정확성, 실제 재생 길이와 지원 규정을 확인한다.
