# 반복 가능한 3D 영상 조사·제작 순서

## 1. 범위와 형식 정하기

프로젝트마다 대상 채널·영상 길이·설명할 질문·최종 매체·선정 미감을 기록한다. 현재 프로젝트의 최종 산출물은 **핀플루언서 지원용 약 3분짜리 뷰티 ETF 소개 영상**이다. PLUS KR와 슈카친구들·머니코믹스의 A–Z 분석은 금융 설명의 명료함·예시·호흡·유머·전환을 설계하는 근거로 사용한다.

영상은 뷰티에 대한 관심에서 관련 기업·사업과 선택한 ETF의 구성으로 연결한 뒤, 확인할 기준·위험과 한 줄 결론으로 이어지도록 설계한다. 작은 화장대에서 제품→기업→ETF 바스켓으로 확장하는 3D 공간도 이 설명 흐름을 지원한다. 약 3분은 현재 제작 목표이며 실제 지원 규정은 따로 확인한다.

## 2. 원작을 발견하고 실제 화면 관찰하기

공식 채널·작가 포트폴리오·공개 갤러리에서 원작 URL과 개별 이미지·영상 출처를 확인한다. 다운로드·검색 결과 수는 준비 수로 관리한다. 실제 원본 또는 읽을 수 있는 관찰판을 열고 주체 비례, 앞뒤 면·두께, 재질, 조명, 공간 배치, 제작에 옮길 구조를 기록한 뒤 관찰 완료로 바꾼다.

최종 영상에 채택할 참고에는 뷰티 ETF 설명에서 맡을 역할을 기록한다. 뷰티 관심을 여는 장면, 제품과 사업을 연결하는 장면, ETF 구성을 읽히는 장면, 기준·위험을 설명하는 장면, 결론을 기억하게 하는 장면으로 우선순위를 판단한다. 금융 내용을 읽는 구간에는 자막과 숫자를 이해할 시간을 배정한다.

정지 화면에서 움직임을 추정하지 않는다. 영상은 확인한 타임라인 범위·순서·샷 경계를 기록하고, 정지 프레임 분석과 실시간 재생·음성 청취를 구분한다. AI 표기·모델 표시·다운로드 가능한 3D 파일·실제 메시 확인도 각각 구분한다.

## 3. 선별하고 중복 합치기

3D 전용 프로젝트에서는 실사·2D·혼합 화면과 입체 미확인 후보를 제외한다. 전체 장면의 일관된 3D 조형과 프로젝트 미감을 실제 화면에서 판단한다. 원본 ID, 파일 해시, 디코딩 픽셀을 대조하고 같은 기본 조형의 미세 변형은 대표를 직접 지정한다. 경계 사례는 다른 검토자가 원본을 열어 판단과 이유를 남긴다.

원작 전체 이미지·모델 시트·독립 장면은 각각 한 단위다. 시트의 패널·한 장면의 소품·연속 변형 중간 프레임을 수량으로 분할하지 않는다.

## 4. 감사하고 저장소에 가져오기

로컬 원장에서 관찰·근거·선정 조건을 확인한 뒤 고유 완료 수와 남은 수를 갱신한다. 감사 시점의 선정 원장과 문서를 `tools/import_research.py`로 가져오고 `tools/validate_library.py`로 확인한다. 내보낸 행 수와 감사 수가 일치해야 한다.

수집 목표가 충족되지 않으면 상태를 진행 중으로 유지한다. 발견 수·준비 수·제외 수는 완료 수와 함께 별도 기록한다. 원작의 라이선스가 변경되거나 기존 선정이 잘못됐음을 확인하면 실제 근거를 재검토하고 대표·상태·감사를 갱신한다.

## 5. 마스터 에셋 고정하기

핵심 캐릭터·제품·공간의 수와 좌표를 먼저 정한다. 현재 프로젝트는 사용자의 지시에 따라 25,000개 수집이 끝나기 전에 공유용 기획안을 8페이지로 구체화하고, 기초 이미지 5종과 추가 장면 10종을 채택했다. 누적 생성 성공 16개 중 초기 S07 한 개를 제외한 15개이며, [추가 제작 기록](production/beauty-etf-expansion/README.md)에 실제 작업·참조·해시와 선택 이유를 보존한다. [Higgsfield 세팅 순서](higgsfield-foundation.md)에 따라 단일 전신 마스코트에서 각도별 모습을 파생하고, 제품·바스켓 독립 마스터와 이들을 참조한 화장대를 만든다. 모델이 지원하는 이미지 참조 또는 Element 방식을 사용한다. 실제 결과를 열어 비례·손발·소품 수·재질·조명·여백을 확인한 항목만 재사용한다. 제작 에셋은 참고 수에 더하지 않는다.

## 6. 영상으로 옮기고 검증하기

잠긴 이미지에서 I2V로 한 번에 하나의 행동을 만든다. 컷 길이·제품 근접과 전체 공간의 교대·연결 형태로 속도감을 설계한다. 숫자를 읽는 구간은 안정된 카메라와 정확한 편집 자막을 사용한다. [CAGR 근거](production/beauty-etf-expansion/research/beauty_cagr_primary.md)와 [ETF 구성 근거](production/beauty-etf-expansion/research/etf_composition_primary.md)의 시장 범위·기준일·산식에 맞춰 후편집하고, 산업 성장률을 ETF 수익률로 바꾸지 않는다. 영상 결과의 캐릭터·제품·세트 일관성, 자막 정확성, 실제 재생 길이와 지원 규정을 확인한다.
