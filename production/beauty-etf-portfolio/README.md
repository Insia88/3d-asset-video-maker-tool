# 화장대에서 시작하는 투자 이야기

20~30대 뷰티 관심 시청자를 위한 핀플루언서 지원용 180초 무내레이션 영상이다. 보송한 모아와 작은 화장대에서 시작해 한국 뷰티의 수출 실적, 세계 시장의 성장 전망, 제품 뒤의 사업 역할과 ETF 개념으로 이어진다. 산업의 가능성을 소개하면서도 구성·집중도·비용과 위험을 판단 기준으로 남긴다.

문어체 자막 v4를 적용한 Higgsedit 편집본 v1.4는 9:16, 1080×1920, 30fps, 180초다. 전체 장면을 세로 화면에 채우고 93개 영상 구간 사이에서 40개 자막을 유지한다. 같은 원본의 연속 구간을 이어 붙이고, 최대 6프레임의 짧은 전환과 완만한 카메라 이동을 적용했다. 밝은 132BPM 자체 연주곡과 항공·캐릭터 동작은 유지했다. 특정 ETF·기업명과 실제 또는 가상의 투자비중은 표시하지 않는다.

## 180초의 흐름

| 구간 | 설명 |
|---|---|
| 0–18초 | 화장품의 취향에서 투자 질문으로 |
| 18–29초 | 한국 뷰티의 항공 장면·2025년 화장품 수출액 세계 2위·114억 달러 |
| 29–50초 | 세계 뷰티 시장 전망·CAGR·가상 시장 지수 |
| 50–78초 | 브랜드·제조·유통·용기와 포장의 사업 역할 |
| 78–118초 | ETF 바구니의 개념·거래소 거래·상품별 구성의 차이 |
| 118–152초 | 산업 공통 위험·집중·손실·비용 |
| 152–180초 | 사업·집중도·비용과 위험의 확인 기준 |

‘세계 2위’는 화장품 수출액 순위다. 세계 소비시장 규모나 시장 점유율 순위와 혼동하지 않도록 측정연도와 기준을 붙인다. 연평균 약 5%는 세계 시장 규모 전망이며, 100→약 128은 5년 복리의 가상 지수로 ETF 수익률이 아니다. 장면의 블록과 사업 모듈도 실제 편입비중을 나타내지 않는다.

## 파일과 재현 기준

[동결 파일 목록](script/frozen_manifest.json)은 현재 자막 JSON·원고·SRT와 공개 컷 구성의 해시를 기록한다. 자막 JSON은 실제 제작에 사용한 동일 바이트다. 공개 컷 구성은 개인 경로와 내부 작업 메모를 제외한 버전이며 네이티브 제작 계획의 해시를 별도로 남긴다. 이전 v2·v3 원고는 이력에 보존한다.

[원본 15개 에셋](approved_asset_manifest.json)은 보존하고, [항공 장면용 추가 키 이미지 두 개](additional_asset_manifest.json)와 검수한 새 동작 영상 8개를 사용한다. 원래 마을 영상의 사용은 34.2초에서 총 5.1초로 줄였고, 같은 소스 시간 구간의 재사용과 루프는 없다. 이전 v1.3의 105컷은 영상 소스 35컷과 정지 이미지 70컷이었다. v1.4에서는 같은 원본에서 이어지는 9개 묶음을 연결해 93개 구간으로 구성했다. 정지 인서트의 확대나 컷 변화를 새 생성 동작으로 세지 않는다.

원본 미디어와 편집 파일은 구글 드라이브에 보관한다. 이 저장소에는 자막·컷 구성·출처·해시·검수 기록을 남긴다. 생성 에셋과 편집 프레임은 [연구 라이브러리](../../README.md)의 25,000개 참고 집계에 추가하지 않는다.

가로 원본도 종횡비를 유지하면서 화면을 채우도록 확대·이동한다. 따라서 한 프레임에서 원본의 모든 주변부를 볼 수는 없다. 세 역할 비교 장면은 팬 구간 전체에서 브랜드·제조·유통을 차례로 보여준다. [v1.3 이전판](history/v1.3/README.md) · [v1.4 재현 해시](script/revision_v5_manifest.json)
