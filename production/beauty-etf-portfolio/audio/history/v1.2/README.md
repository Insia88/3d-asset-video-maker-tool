# 자체 배경음악

“Moa Felt Garden”은 이 작품을 위해 만든 절차적 작곡이다. 외부 음원·목소리·보컬은 사용하지 않았다. 116BPM·180초·48kHz 스테레오로, 따뜻한 패드·감쇠 마림바와 짧은 발현음·둥근 저음·부드러운 박자를 사용한다.

시장 설명 18–50초와 위험 118–152초에서는 밀도를 낮추고 도입·사업 역할·ETF·결론을 서로 다른 구절로 연결한다. 모티프 5개·화음 보이싱 5개·옥타브/구절 변화를 사용하며 하나의 짧은 루프를 180초 반복한 구성이 아니다.

WAV/MP3 기술 측정은 -19.20LUFS, true peak -5.32dBTP, LRA 6.70이다. 원본 WAV의 길이·48kHz·stereo와 두 파일 SHA를 대조했다. 전곡 청취 검수를 완료했다는 의미는 아니다. 최종 영상의 AAC mux·전체 음량·페이드 확인은 완성 영상 검수에 따른다.
