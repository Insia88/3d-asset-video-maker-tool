# 입체 장면과 자막의 제작 규칙

보송한 모아, 따뜻한 역광, 작은 화장대와 제품 마을을 하나의 세계로 유지한다. 제품에서 산업, ETF 바구니, 판단 기준으로 옮겨 갈 때 공간과 행동도 함께 바뀌어야 한다.

- 원본 15개 이미지의 캐릭터 비례·베레모·안경·신발과 제품 기본형을 보존한다. 추가 항공 키 이미지도 크림·라벤더·민트·피치·목재의 재질과 조명을 따른다.
- 크림통·립스틱·향수의 기본형과 바구니의 다섯 블록을 유지한다. 소품 수·색·크기는 투자비중이나 시장 점유율이 아니다.
- 항공 장면은 한국 산업 캠퍼스에서 수출 항구로 연결된다. K201·K202는 개념 장면이며 정확한 GIS 지도나 국가별 비율 그림이 아니다.
- 같은 영상의 시작을 반복하지 않는다. 소스별로 겹치지 않는 시간 구간을 선택하고, 제품·사업·캐릭터·바구니의 전체와 근접 장면을 교대한다.
- 40개 본문은 105컷 사이에서도 유지한다. 본문 56px, 핵심 수출 순위 120px, 각주 28px를 기본으로 사용한다. 실제 배치는 [좌표와 숫자판 설정](script/render_layout_overrides.json)을 따른다.
- 정확한 한글과 금융 숫자는 생성 영상에 맡기지 않고 네이티브 텍스트로 제작한다. ‘2위’에는 2025년 화장품 수출액 기준을 붙이고, 100→약 128에는 가상 지수·ETF 수익률 아님을 지속 표시한다.
- V305 후반의 임의 글자는 제품과 건축물을 가리지 않는 상단 400px 불투명 크림판으로 제거했다. 선택 소스 3.5–5.7초에서 지붕·붓·수출 장면과 정확한 자막의 보존 여부를 실제 인코딩 표본으로 확인한다. 다른 문제가 생긴 V5·V6·V8은 제외한다.
- 132BPM 무보컬 원곡은 구간마다 밀도를 바꾸고 수치를 읽을 때 주선율을 덜어 낸다. 음악의 기술 검증과 실제 청취 판단을 구분한다.
- 정지 이미지의 ROI·contain·하드컷과 카메라 이동은 실제 캐릭터 행동이나 새 독립 장면으로 설명하지 않는다. 메시·리깅을 확인했다는 주장도 하지 않는다.

생성 이미지·동작 영상·편집컷은 25,000개 연구 참고 집계에 더하지 않는다.
