# 완성본의 형식과 전달 상태

문어체 자막 v3을 적용한 최종 Higgsedit 편집본 v1.2의 기술 정보는 실제 제작 기록과 공유 파일 대조에 따른다.

| 항목 | 확인 결과 |
|---|---|
| 길이·해상도 | 180.000초, 1080×1920, 9:16 |
| 프레임 | 30fps, 5,400프레임 |
| 영상·음악 | H.264 + AAC 48kHz 스테레오, 무내레이션, 자체 116BPM 음악 |
| 구성 | 실제 미디어 컷 66개: 영상 53개·정지 13개, 지속 자막 38그룹 |
| 시각 기준 | 승인 15개 시각군 유지, V5/V6/V8 제외·보완 V13/V14/V15 사용 |
| 자막 | 문어체 v3 본문 38개와 보조 각주, 기존 컷·초 단위 시간 유지 |
| 기술 검증 | 전체 5,400프레임 디코딩 성공, 자막 그룹 중간 화면 38개·최종 인코딩 표본 10개 직접 검수 |
| 파일 | 89,419,591바이트 |
| SHA-256 | `376232ab375ec30289bb85d751865704c2583377849acecd94f8cfde23fc36bb` |

영상의 음악은 이전 편집본과 동일하다. 최종 제작 기록의 약 -19.2LUFS/-5.3dBFS peak는 음악 원본의 true-peak 측정과 구별한다. 정지 표본 검수와 전체 기술 디코딩을 전편 연속 시청·전곡 청취로 표현하지 않는다.

## 공유 파일

- [문어체 자막 v3의 180초 최종 MP4 v1.2](https://drive.google.com/file/d/1lsCMVUakZQ2YZMoHtxNZerGaX-A-A6Dv/view)
- [이전 원고의 180초 After Effects AEP 프로젝트](https://drive.google.com/file/d/1rFHV53faEN48DjT5UDOL_zffQHKYR0uh/view)
- [이전 원고의 실제 12초 AE 자체 렌더 프리뷰](https://drive.google.com/file/d/1CeuuQzRnmb_iw0h61cK-pHk6EkNMkhjo/view)

공유 MP4는 동일 링크에서 v1.2로 교체하고 파일 정보를 다시 대조했다. 위 AEP·12초 프리뷰 링크는 이전 자막 제작본이며, 문어체 v3 AEP의 최종 전달 정보는 아직 확정되지 않았다. 이전 AEP는 2,915,337바이트로 180초 구성을 담고, 이전 프리뷰는 1080×1920/30fps·360프레임의 12초 영상이다. 새 v3 AE 렌더의 실제 정지 6개와 인코딩 프리뷰 9개는 별도로 관찰했다.

Higgsedit 편집 복구 자료는 4개 ZIP의 실제 콘텐츠 37개를 CRC·SHA로 대조하고 빈 폴더에서 복구해 정상 상태를 확인했다. v1.2의 1·2번 묶음과 바이트가 같은 기존 3·4번 묶음을 함께 사용한다. 이미지·영상·글꼴·음악은 이전 편집본과 같으며 최신 외부 파일 목록을 복구 기준으로 삼는다.

실제 파일 형식·해시·검수 범위는 [구조화 전달 정보](delivery_status.json)에 있다. 이 저장소에는 문서·출처·타임라인·SRT·해시를 보관하며 원본 미디어와 편집 파일은 별도로 보관한다.
