# 화장대에서 시작하는 투자 이야기 — v1.2 이력

이 문서는 당시 v1.2의 제작 기록이다. 같은 공유 영상 URL은 현재 버전으로 업데이트될 수 있으며, 자막과 검수 수치는 아래의 v1.2 이력에 해당한다.

20~30대 뷰티 관심 시청자를 위한 핀플루언서 지원용 180초 무내레이션 영상이다. 보송한 마스코트 모아와 작은 화장대에서 출발해 제품 뒤의 사업 역할, 뷰티 ETF 바구니, 구성·집중도·비용과 위험을 설명한다.

문어체 자막 v3을 적용한 최종 Higgsedit 편집본 v1.2는 9:16, 1080×1920, 30fps, 180초로 내보냈다. 승인된 15개 시각군을 66컷과 38개 지속 자막으로 구성하고, 검수한 이미지 기반 영상과 자체 180초 연주곡을 사용했다. 특정 ETF·기업명과 실제 또는 가상의 투자비중은 표시하지 않는다.

## 180초의 흐름

| 구간 | 설명 |
|---|---|
| 0–18초 | 화장품의 취향에서 투자 질문으로 |
| 18–50초 | 세계 코어 뷰티 시장 전망·CAGR·가상 시장 지수 |
| 50–78초 | 브랜드·제조·유통·용기와 포장의 사업 역할 |
| 78–118초 | ETF 바구니의 개념·거래소 거래·구성의 차이 |
| 118–152초 | 산업 공통 위험·집중·손실·비용 |
| 152–180초 | 사업·집중도·비용과 위험의 확인 기준 |

연평균 약 5%는 시장 규모 전망이다. 100→약 128은 5년 복리를 설명하는 가상 시장 지수이며 ETF 수익률이 아니다. 토큰 5개와 사업 역할 3개 모듈은 개념 소품이며 실제 종목 수나 편입비중이 아니다.

## 파일과 재현 기준

[최종 문어체 자막 v3의 동결 파일 목록](../../script/history/v3/frozen_manifest.json)은 원본 66컷 JSON·자막 원고·SRT의 동일 바이트 해시를 기록한다. 이전 v2 원고는 변경 없이 별도 이력에 보존했다. 렌더에서 머리와 제품을 가리지 않도록 바꾼 자막 좌표는 [별도 오버라이드](../../script/history/v3/render_layout_overrides.json)에 있다. [승인 에셋 목록](../../approved_asset_manifest.json)은 15개 원본의 해시와 크기를 포함한다.

이미지·클립·WAV·AEP 바이너리와 개인 계정 정보는 이 저장소에 포함하지 않는다. 최종 MP4·AEP·실제 AE 12초 프리뷰의 공유 링크는 [delivery.md](delivery.md)에서 확인한다. 정지 표본 검수와 전체 기술 디코딩을 전편 연속 시청이나 전곡 청취 완료로 표현하지 않는다.

이 영상의 생성 에셋과 편집컷은 [연구 라이브러리](../../../../README.md)의 25,000개 참고 수에 추가하지 않는다. 수집 진척은 해당 감사 원장으로 확인한다.
