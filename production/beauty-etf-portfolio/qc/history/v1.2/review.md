# 실제 관찰 범위와 보완 내역

승인 15개 이미지는 해시·크기·시각 잠금 자료와 일치했다. 66컷/38그룹의 30fps 스크립트는 0–5,400프레임을 연속 구성한다. 본문은 최대 2줄이고 최소 그룹 3초이며, 52px Noto Sans KR 기준 가장 긴 줄 717px/허용 864px로 확인했다. 문자량 최고 6.832자/유효초는 설계 비교 지표로 모든 시청자의 읽기 속도를 측정한 값이 아니다.

자막 v3의 본문과 각주 38그룹을 모두 읽고 평서형 문장과 자연스러운 단어 연결을 확인했다. 금융 출처·자막 시간·66컷·180초는 v2와 같다. 이전 원고 검수와 문어체 v3의 실제 렌더 검수를 구분해 기록한다. v3 AE 자체 정지 렌더 6개와 실제 인코딩된 프리뷰 표본 9개를 직접 확인했고, 최종 Higgsedit v1.2의 38개 자막 그룹 중간 화면·인코딩 10개는 제작자 검수 기록에 따른다. [v3 문체·글자량 검수](caption_v3_check.json)

## 발견한 문제와 조치

- 시장 마을 S02의 낮은 자막은 모아 뒤머리를 가릴 수 있어 G05–12를 상단으로 옮겼다. 위험 S09의 G29–31도 상단으로 이동했다. 실제 AE 14.5/16.5/132초 정지 결과에서 머리·구름·토큰 5개 가림을 줄인 배치를 확인했다.
- V5 브랜드는 큰 임의문자, V6 유통은 임의문자와 닫힌 큰 상자 변형, V8 위험은 긴 영문 문단이 생겼다. 승인 원본을 대체용으로 보존하고 보완 V13/V14/V15를 만들었다.
- 보완 3클립의 PTS 1/4/8과 각 승인 원본 전체를 대조했다. 관찰 표본에서 임의 타이포가 사라지고 13/14의 제품 3종·15의 토큰 5개와 바구니가 유지된다. 세 클립 1–4초를 보수적 전체 장면 후보로 전달했다. 후반 카메라 접근에 따른 잘림은 짧은 부분 장면에 한정한다.
- S05의 두 높이 목재 받침이 승인 원본의 일부임을 재확인하고, 열린 상자·제품·접지 관계에 맞춰 검수 기준을 정리했다.
- 시장 숫자 구간은 100→약 128을 가상 시장 지수로 표시하고 ETF 수익률 아님을 함께 표시했다. AE 44.5초에서도 그 구분을 확인했다.
- AE 175초 하단 흰 출처는 밝은 배경과 대비가 약해 짙은 회갈색으로 보완했다. 수정된 35/132/175초 결과를 다시 360px 전체로 열어 출처 대비·시장 각주·단어가 쪼개지지 않은 개념 소품 문구를 확인했다.
- G01 그룹판 라벨 0초는 그룹 시작이며 실제 표본은 1초라는 편집자 설명을 기록했다. .4초 M03→1.27초 S01→2.33초 M04 중간 프레임은 편집자가 확인했으며, 이 작성자가 그 판을 직접 본 것은 아니다.

문어체 v3의 직접 관찰 표본에서 본문·각주의 음절 분리, 잘림, 한글 글리프 누락은 발견하지 못했다. 44.5초 가상 지수, 132초 개념 소품, 175초 위험과 출처 표시의 의미도 유지된다.

## 실제 앱 실행 경로의 구분

Adobe Express는 연결된 기능으로 디자인 검색·텍스트 교체·애니메이션 옵션 반환과 실제 저장 화면을 확인했다는 제작 기록이 있다. 이 사실만으로 Premiere/After Effects 직접 제어·구독권한·영상 내보내기가 검증되지는 않는다.

이번 제작 환경에는 전용 After Effects 도구 경로가 노출되지 않았지만, 연결된 로컬 MCP 서버를 검증된 SDK 클라이언트로 호출하는 별도 경로를 사용했다. 제작 기록에 프로젝트 JSON 가져오기 성공과 초기 10개 앱 자체 렌더 프레임의 실제 출력 성공이 기록되어 있고 그 정지 결과를 독립 확인했다. 전용 네임스페이스가 없음을 “AE 연결이나 편집 가능한 프로젝트가 없음”으로 확대하지 않는다.

## 완성 편집본의 별도 기술 검증

제작자의 최종 제작 기록은 180초, 5,400프레임, 1080×1920/30fps, H.264+AAC 48kHz 스테레오와 전체 5,400프레임 기술 디코딩 성공을 기록한다. 실제 미디어 컷은 영상 53개와 정지 13개이며 승인된 15개 시각군을 유지한다. 보완 13/14/15는 원본 1–4초를 필요한 컷에서 3.5초로 늘린 파생 입력이다.

v1.2에서 제작자는 38개 자막 그룹의 실제 중간 화면과 최종 인코딩 대표 10프레임을 직접 확인했고, 주 검토자도 그 인코딩 10개 화면을 확인했다. 본문 38개·그룹 각주 26개·지속 계산 각주를 최종 원고와 대조했다. G05/G08/G26은 56px로 렌더되며 가장 긴 줄 약 778px가 허용 폭 864px 안에 들어간다. 앞의 52px/717px 설계 측정과 실제 렌더 값을 구분한다. 이 문서 작성자가 완성본을 전편 연속 시청하거나 전곡을 청취한 것으로 표시하지 않는다. [완성본의 형식과 전달 상태](../../../history/v1.2/delivery.md)

최종 공유 링크·AEP 의존파일은 전달 검증에 따른다. 생성 15이미지·생성 클립·66편집컷의 연구 참고 가산은 0이며 25,000개 수집 완료로 표시하지 않는다.
